# E4022

> closure functions cannot be used as template values

Raised during **validation**, from `ValidateErrorMessage::CLOSURE_TEMPLATE_LAMBDA` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A closure was passed as a template value. A closure carries an environment
allocated at run time, so it has no compile-time value a template could be
specialized on.

## How to fix it

Pass a plain function, or take the closure as an ordinary parameter instead
of a template one.

# E4037

> creating an instance of map <> on the stack is prohibited

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::CTOR_MAP_STACK` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A map was created on the stack. Like classes, maps are reference types.

## Example

`test_resources/lit_map/test3.yr`:

```ymir
fn main () {
    let dmut _ = [1 => 2];
    let dmut _ = ["foo" => copy [1, 2, 3]];

    let dmut _ = ["foo" => [1, 2], "bar" => [1]];
    let dmut _ = ["foo" => 1, 2 => 3];
}
```

```text
Error[E4037] : creating an instance of map mut [i32 => mut i32] on the stack is prohibited
 --> test_resources/lit_map/test3.yr:(2,18)
 2  ┃     let dmut _ = [1 => 2];
    ╋                  ^  note: did you mean to enclose it within a copy?
    ┗━━━━━━━
```

## How to fix it

Construct it with `copy`, cf. [E4034](E4034.md).

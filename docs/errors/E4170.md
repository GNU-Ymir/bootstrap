# E4170

> type <> is an entity, but has no default ctor self()

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::NO_DEFAULT_CTOR_MOVE_STRUCT` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

An entity is used in a context requiring a default constructor, and it declares
none.

## How to fix it

Add a `self ()` constructor to the entity.

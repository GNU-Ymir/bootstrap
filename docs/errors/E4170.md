# E4170 (retired)

> type <> is an entity, but has no default ctor self()

**This code is retired.** It is no longer raised, and it is never reallocated.

It was raised during **validation**, from
`ValidateErrorMessage::NO_DEFAULT_CTOR_MOVE_STRUCT`, when the compiler failed to
synthesize the empty ctor it gave every entity so that `move` had something to
reset the moved value with.

## What replaced it

The `move` operator now names the ctor it resets with, and passes it arguments,
so the compiler no longer manufactures one. An entity is an ordinary class in
that respect: it gets the ctors it declares, and nothing else.

```ymir
let mut b = move (42) a;   // a is reset with self (42)
let mut d = move c;        // c is reset with self ()
```

An entity declaring no ctor callable that way now raises
[E4168](E4168.md) at the `move` itself, naming the candidates it rejected,
rather than failing at the declaration of the entity.

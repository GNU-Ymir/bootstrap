# E4216

> pattern <> only matches tuple values, not <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::TUPLE_PATTERN` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A pattern that only matches tuples was applied to another type.

## How to fix it

Same as [E4215](E4215.md).

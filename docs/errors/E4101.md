# E4101

> the base class <> is marked as final

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::INHERIT_FINAL_CLASS` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A class inherits from a class marked `final`. `final` says the class is a leaf
of its hierarchy.

## How to fix it

Remove `final` from the base class, or inherit from one of its ancestors.

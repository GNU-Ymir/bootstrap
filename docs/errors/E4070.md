# E4070

> the value cannot be computed, as it depends on a forward reference

**Retired.** The message this code named was deleted from the compiler: no
code raised it any more. Nothing produces E4070 today.

The code is not reused and not reassigned to another diagnostic, so an E4070
printed by an older compiler still means what is quoted above. This page stays
as its record.

It was raised during **validation**, from `ValidateErrorMessage::FORWARD_REFERENCE_VALUE`.

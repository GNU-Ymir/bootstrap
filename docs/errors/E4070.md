# E4070

> the value cannot be computed, as it depends on a forward reference

Raised during **validation**, from `ValidateErrorMessage::FORWARD_REFERENCE_VALUE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A value the compiler must know at this point depends on something not defined
yet.

## How to fix it

Move the definition it depends on earlier, or break the cycle.

# E4102

> the base of a class must be a class, not a <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::INHERIT_NO_CLASS` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

The base of a class is not a class -- a record, a trait or a plain type was
named instead.

## Example

`test_resources/diagnostics/test46.yr`:

```ymir
record R { let x: i32; }

class B over R { pub self () {} }

fn main () { let _ = copy B (); }
```

```text
Error[E4102] : the base of a class must be a class, not a test46::R
 --> test_resources/diagnostics/test46.yr:(3,14)
 3  ┃ class B over R { pub self () {} }
    ╋              ^
    ┗━━━━━━━
```

## How to fix it

Inherit from a class. To reuse a trait, use an `impl` block; to reuse a
record, hold it as a field.

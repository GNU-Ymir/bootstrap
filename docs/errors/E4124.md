# E4124

> reached the maximum number of cte iterations <> > <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::MAX_LOOP_ITERATIONS` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

Compile time execution ran past the iteration limit. Both the count reached and
the limit are in the message. This is the guard against a compile time loop that
never terminates.

## Example

`test_resources/diagnostics/test113.yr`:

```ymir
// a compile time loop running more iterations than allowed
fn main () {
    cte for i in 0 .. 100000 {
        let _ = i;
    }
}
```

```text
Error[E4124] : reached the maximum number of cte iterations 100000 > 1024
 --> test_resources/diagnostics/test113.yr:(3,9)
 3  ┃     cte for i in 0 .. 100000 {
    ╋         ^^^
    ┃
    = when validating test113::main -- (test_resources/diagnostics/test113.yr:(2,4))
    ┗━━━━━━━
```

## How to fix it

Check the termination condition of the loop being evaluated at compile time.
If the computation is genuinely that long, it belongs at run time.

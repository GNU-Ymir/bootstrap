# E3029

> unexpected declaration inside an extern block

Raised during **declaration**, from `DeclareErrorMessage::UNEXPECTED_IN_EXTERN` (`src/ymirc/semantic/declarator/errors.yr`).

## What it means

A declaration appeared inside an `extern` block that such a block does not
accept. An `extern` block declares symbols defined elsewhere, so it takes
prototypes and variable declarations, not definitions.

## How to fix it

Move the declaration out of the block.

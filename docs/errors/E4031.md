# E4031

> cte assertion failed <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::CTE_ASSERT_WITH_MSG` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A `cte assert` evaluated to false during compile time execution; its message is
reported.

## Example

`test_resources/regressions/assert_bool_type/test3.yr`:

```ymir
fn main () {
    cte assert (false, "Must fail");
}
```

```text
Error[E4031] : cte assertion failed "Must fail"s8
 --> test_resources/regressions/assert_bool_type/test3.yr:(2,9)
 2  ┃     cte assert (false, "Must fail");
    ╋         ^^^^^^
    ┗━━━━━━━
```

## How to fix it

Fix the condition, or the values it tests.

# E4268

> conditional test is always evaluated to true, branch is always entered

Raised during **validation**, from `ValidateErrorMessage::USELESS_COND_TRUE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A condition the compiler could evaluate is always true, so the branch it guards
always runs and the test says nothing.

## Example

`test_resources/control_flow/test15.yr`:

```ymir
fn main () {
    let a = [1, 2, 3];
    if (a.len <= 3) { // error, len of /a/ is /cte/
        println (a [2]);
    }

    if (a.len >= 4) {
        println (a [3]); // error, dead code
    }
}
```

```text
Error[E4268] : conditional test is always evaluated to true, branch is always entered
 --> test_resources/control_flow/test15.yr:(3,15)
 3  ┃     if (a.len <= 3) { // error, len of /a/ is /cte/
    ╋               ^^
    ┗━━━━━━━
```

## How to fix it

Remove the condition, or fix it.

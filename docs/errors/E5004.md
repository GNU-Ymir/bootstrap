# E5004

> failed to write YIL byte file <>, permission denied

where `<>` stands for a value the diagnostic fills in.

Raised during **lowering (YIL)**, from `SerializeYILErrorMessage::FAILED_TO_WRITE_BYTE_FILE` (`src/ymirc/lint/serialize/errors.yr`).

## What it means

The compiler could not write the `.yil` file of a compiled module. The path is
reported in the message.

## How to fix it

Check the permissions of the output directory, and that the disk is not
full.

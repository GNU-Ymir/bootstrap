# E4194

> field <> from type <> has no default value

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::PRAGMA_FIELD_NO_DEFAULT` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A `__pragma` asked for the default value of a field that has none.

## How to fix it

Give the field a default value, or ask about a field that has one.

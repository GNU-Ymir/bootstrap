# E4194

> field <> from type <> has no default value

**Retired.** The message this code named was deleted from the compiler: no
code raised it any more. Nothing produces E4194 today.

The code is not reused and not reassigned to another diagnostic, so an E4194
printed by an older compiler still means what is quoted above. This page stays
as its record.

It was raised during **validation**, from `ValidateErrorMessage::PRAGMA_FIELD_NO_DEFAULT`.

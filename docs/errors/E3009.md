# E3009

> core module is malformed

Raised during **declaration**, from `DeclareErrorMessage::MALFORMED_CORE` (`src/ymirc/semantic/declarator/errors.yr`).

## What it means

The `core` module the compiler needs does not have the shape it expects: a
symbol the compiler relies on is missing or has the wrong kind. This is an
installation problem rather than a problem with the code being compiled.

## How to fix it

Check that the standard library found on the include path matches the compiler
version. A `core` from another release is the usual cause.

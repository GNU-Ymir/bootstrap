# E3015

> a record cannot be both overlaid and packed

Raised during **declaration**, from `DeclareErrorMessage::OVERLAID_AND_PACKED` (`src/ymirc/semantic/declarator/errors.yr`).

## What it means

A record is declared both overlaid and packed. Overlaying places every field at
the same offset; packing removes the padding between successive fields. There is
no layout satisfying both.

## Example

`test_resources/diagnostics/test8.yr`:

```ymir
@overlaid @packed
record Foo {
    let x: i32;
    let y: i32;
}

fn main () { let _ = Foo (1, 2); }
```

```text
Error[E3015] : a record cannot be both overlaid and packed
 --> test_resources/diagnostics/test8.yr:(1,12)
 1  ┃ @overlaid @packed
    ╋            ^^^^^^
    ┃ Note :
    ┃  --> test_resources/diagnostics/test8.yr:(1,2)
    ┃  1  ┃ @overlaid @packed
    ┃     ╋  ^^^^^^^^
    ┃     ┗━━━━━━━
    ┃ Note :
    ┃  --> test_resources/diagnostics/test8.yr:(2,1)
    ┃  2  ┃ record Foo {
    ┃     ╋ ^^^^^^
    ┃     ┗━━━━━━━
    ┗━━━━━┻━
```

## How to fix it

Keep whichever describes the layout wanted. A union-like type is overlaid; a
type mirroring a wire format is packed.

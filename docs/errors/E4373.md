# E4373

> type <> has no methods

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::TYPE_HAS_NO_METHOD` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

`__pragma!method` accesses a method of an object named by a string, and
`__pragma!method_infos`, `__pragma!method_has_tag`, `__pragma!method_tag` and
`__pragma!method_tags` read the methods a type declares. Only a class, a record
or an entity declares methods, and `__pragma!method` also reaches those a union
answers to; any other type has none.

## Example

`test_resources/pragma/test32.yr`:

```ymir
/*
 * `__pragma!field` never reads a method, nor `__pragma!method` a field, a
 * mutable method is only reached through an aliased object, and a type that
 * is neither a class nor a union has no methods.
 */

in test32;

class Counter {
    pub let mut count: i32 = 0;

    pub self () {}

    pub fn get (self)-> i32 { self.count }

    pub fn incr (mut self) { self.count += 1; }
}

record A {
    pub self () {}

    pub fn name (self)-> [c8] { "a" }
}

union AB
| A;

fn a () { let c = Counter (); let _x_ = __pragma!field (c, "get"); }

fn b () { let c = Counter (); let _x_ = __pragma!method (c, "count"); }

fn c () { let dmut c = copy Counter (); __pragma!method (c, "incr") (); }

fn d () { let _x_ = __pragma!method (1, "get"); }

fn e () { let c = Counter (); let _x_ = __pragma!method (c, "nothing"); }

fn f () { let u: AB = A (); let _x_ = __pragma!field (u, "name"); }

fn g () { let u: AB = A (); let _x_ = __pragma!method (u, "typeid"); }

fn h () { let c = Counter (); let _x_ = __pragma!method (c); }

fn main () {
    a ();
    b ();
    c ();
    d ();
    e ();
    f ();
    g ();
    h ();
}
```

## How to fix it

Give the pragma an instance, or the type, of a class, a record or an entity, or
an instance of a union for `__pragma!method`.

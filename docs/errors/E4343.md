# E4343

> the main function cannot be async

Raised during **validation**, from `ValidateErrorMessage::ASYNC_MAIN` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

The program starts by calling `main`, and nothing would drive an async `main`
to completion.

## Example

`test_resources/async/test17.yr`:

```ymir
// main cannot be async.

async main () {}
```

```text
Error[E4343] : the main function cannot be async
 --> test_resources/async/test17.yr:(3,1)
 3  ┃ async main () {}
    ╋ ^^^^^
    ┃
    = when validating test17::main -- (test_resources/async/test17.yr:(3,7))
    ┗━━━━━━━
```

## How to fix it

Declare `main` as a function, and run the async from it: `work ().run ()`.

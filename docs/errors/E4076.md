# E4076

> cannot create a function pointer from the throwing function <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::FUNCTION_TO_FPTR_THROWING` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A function pointer was created from a function that can throw. A function
pointer has no place to declare what it throws, so a caller could not know it
has to handle an exception.

## Example

`test_resources/function/test11.yr`:

```ymir
fn foo ()
    throws AssertError
{
    assert (false);
}

fn main () {
    let a = &foo;
    a ();
}
```

```text
Error[E4076] : cannot create a function pointer from the throwing function test11::foo ()-> void
 --> test_resources/function/test11.yr:(8,13)
 8  ┃     let a = &foo;
    ╋             ^
    ┃ Note : throwing core::exception::assertion::AssertError
    ┃  --> test_resources/function/test11.yr:(2,12)
    ┃  2  ┃     throws AssertError
    ┃     ╋            ^^^^^^^^^^^
    ┃     ┗━━━━━━━
    ┗━━━━━┻━
```

## How to fix it

Wrap the call in a lambda that catches the exception, or use a delegate that
carries the throw information.

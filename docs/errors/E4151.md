# E4151

> not a lvalue

Raised during **validation**, from `ValidateErrorMessage::NOT_A_LVALUE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

An expression was used where storage is required -- the left of an assignment,
the target of a `ref`, the operand of an address-of -- and it has no storage of
its own.

## Example

`test_resources/lit_tuples/test20.yr`:

```ymir
fn foo ()-> (i32, i32);

fn main () {
    let mut a = 0;

    (a, 1) = foo ();
}
```

```text
Error[E4151] : not a lvalue
 --> test_resources/lit_tuples/test20.yr:(6,9)
 6  ┃     (a, 1) = foo ();
    ╋         ^  ^
    ┗━━━━━━━
```

## How to fix it

Bind the value to a variable and use that. The more specific diagnostics
E4152 to E4157 say why a particular value has no storage.

# E4219

> temporary type <> has no type information

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::TYPE_HAS_NO_TYPEINFO` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

Type information was asked of a temporary type, which carries none at run
time.

## How to fix it

Ask it of a concrete type instead.

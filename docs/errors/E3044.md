# E3044

> not supported in version ymir <>

where `<>` stands for a value the diagnostic fills in.

Raised during **declaration**, from `DeclareErrorMessage::NOT_SUPPORTED_IN` (`src/ymirc/semantic/declarator/errors.yr`).

## What it means

The declaration parses, but this version of the compiler cannot declare it. The
version is in the message.

Tags are what raise it today: a tag declaration, `tag name (params) { ... }`,
and a declaration written after a tag list, `#[name (args)] fn foo`, are read
into the syntax tree, but nothing declares them yet.

## Example

`test_resources/diagnostics/test164.yr`:

```ymir
// a tagged declaration, tags are not supported yet
#[route ("/f")]
fn foo () {}

fn main () {}
```

```text
Error[E3044] : not supported in version ymir 1.10
 --> test_resources/diagnostics/test164.yr:(2,1)
 2  ┃ #[route ("/f")]
    ╋ ^^
    ┗━━━━━━━
```

## How to fix it

Remove the tags and the tag declarations, or compile with a version that
implements them.

# E3044

> <> is not supported in version ymir <>

where `<>` stands for a value the diagnostic fills in.

Raised during **declaration**, from `DeclareErrorMessage::NOT_SUPPORTED_IN` (`src/ymirc/semantic/declarator/errors.yr`).

## What it means

The declaration parses, but this version of the compiler cannot declare it. The
message names what is not supported, and the version.

Tags are what raise it today. A tag can be put on a function, a class, a record,
an enum, a union, or a template of one of them. Put on any other declaration --
a global variable, a `def`, a trait, a module, a unit test, a macro, a tag, or a
declaration of an `extern` block -- it is refused, the declaration being noted
under the error.

## Example

`test_resources/diagnostics/test164.yr`:

```ymir
// a tag on a global variable, not supported in this version
tag route (path: [c8]) {}

#[route ("/f")]
lazy X: i32 = 0;

fn main () {}
```

```text
Error[E3044] : a tag on a global variable is not supported in version ymir 1.10
 --> test_resources/diagnostics/test164.yr:(4,1)
 4  ┃ #[route ("/f")]
    ╋ ^^
 5  ┃ lazy X: i32 = 0;
    ╋ ----
    ┗━━━━━━━
```

## How to fix it

Remove the tags from the declaration, or compile with a version that supports
them on it.

# E4176

> option of type <> has no value

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::OPTION_HAS_NO_VALUE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

The value side of an option was read on an option that never holds one.

## Example

`test_resources/diagnostics/test117.yr`:

```ymir
// the value of an option known to be empty
fn main () {
    let x : (i32)? = none;
    let _ = x.value;
}
```

```text
Error[E4176] : option of type (i32)? has no value
 --> test_resources/diagnostics/test117.yr:(4,14)
 4  ┃     let _ = x.value;
    ╋              ^
    ┃
    = when validating test117::main -- (test_resources/diagnostics/test117.yr:(2,4))
    ┗━━━━━━━
```

## How to fix it

Read the error instead, or build the option from a computation that can
succeed.

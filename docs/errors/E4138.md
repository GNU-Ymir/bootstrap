# E4138

> a parameter cannot be mutable, if it is not a reference or does not borrow mutable data

Raised during **validation**, from `ValidateErrorMessage::MUTABLE_CONST_PARAM` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A parameter is declared mutable while it neither is a reference nor borrows
mutable data, so the mutation would be invisible to the caller.

## Example

`test_resources/lazyness/test11.yr`:

```ymir
fn foo (lazy mut a : i32) {}
```

```text
Error[E4138] : a parameter cannot be mutable, if it is not a reference or does not borrow mutable data
 --> test_resources/lazyness/test11.yr:(1,14)
 1  ┃ fn foo (lazy mut a : i32) {}
    ╋              ^^^
    ┗━━━━━━━
```

## How to fix it

Drop the `mut`, or declare the parameter `ref` if the caller's value is to be
modified.

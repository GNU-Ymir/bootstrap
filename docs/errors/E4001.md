# E4001

> a name alias cannot be created to alias class ctors

Raised during **validation**, from `ValidateErrorMessage::AKA_CLASS_CTOR` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A name alias (`def`) was made to point at the constructors of a class. A
constructor is not a symbol that can be referred to on its own: it is reached
through the class it belongs to.

## Example

`test_resources/aka/test14.yr`:

```ymir
class A {
    pub self new () {}
}

def B = A::new;
def C = A;
```

```text
Error[E4001] : a name alias cannot be created to alias class ctors
 --> test_resources/aka/test14.yr:(5,5)
 5  ┃ def B = A::new;
    ╋     ^    ^^  note: maybe a type name alias was meant (i.e. using the token : instead of =)
    ┗━━━━━━━
```

## How to fix it

Alias the class instead and construct through the alias.

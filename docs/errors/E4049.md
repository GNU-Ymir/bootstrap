# E4049

> array inner type cannot be <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::EMPTY_ARRAY_INNER` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

An array was declared with an inner type that cannot be stored in an array --
a type with no size, such as `void`.

## How to fix it

Use a type with values. If the element type came from a call, check what the
call returns.

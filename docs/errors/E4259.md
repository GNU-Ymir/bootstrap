# E4259

> matcher expression is never evaluated

Raised during **validation**, from `ValidateErrorMessage::UNREACHABLE_MATCHER` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A pattern in a `match` is covered by an earlier one, so it can never run.

## How to fix it

Remove it, or move it before the pattern that shadows it.

# E4110

> validation of macro call failed

Raised during **validation**, from `ValidateErrorMessage::MACRO_CALL_VALIDATION_FAILED` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A macro call was expanded and validating the result failed.

## Example

`test_resources/lit_macro/test25.yr`:

```ymir
/*
 * A macro call made on a symbol that is not a macro
 */

fn notAMacro ()-> i32 {
    12
}

fn foo () {
    let x = notAMacro#{ 1 };
    x;
}
```

```text
Error[E4110] : validation of macro call failed
 --> test_resources/lit_macro/test25.yr:(10,22)
10  ┃     let x = notAMacro#{ 1 };
    ╋                      ^^  error: macro call is undefined for test25::notAMacro ()-> i32
    ┗━━━━━━━
```

## How to fix it

Read the errors reported under this one: they come from the expansion, and
point either at the macro definition or at the arguments it was given.

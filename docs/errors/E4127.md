# E4127

> cannot copy an expand value, maybe copy and expand keywords are inverted?

Raised during **validation**, from `ValidateErrorMessage::MISMATCH_COPY_EXPAND` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

`copy` was applied to an `expand` value; the keywords are inverted.

## Example

`test_resources/diagnostics/test139.yr`:

```ymir
// copy and expand written the wrong way round
fn take (_ : i32, _ : i32) {}

fn main () {
    let x = [1, 2];
    take (copy expand x);
}
```

```text
Error[E4127] : cannot copy an expand value, maybe copy and expand keywords are inverted?
 --> test_resources/diagnostics/test139.yr:(6,11)
 6  ┃     take (copy expand x);
    ╋           ^^^^ ------
    ┃
    = help: invert the two keywords
    ┃
 6  -     take (copy expand x);
 6  +     take (expand copy x);
    ┃
    = when validating test139::main -- (test_resources/diagnostics/test139.yr:(4,4))
    ┗━━━━━━━
```

## How to fix it

Swap them: `expand copy v`.

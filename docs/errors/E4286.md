# E4286

> a unit test taking parameters must produce them with the @parameters attribute

Raised during **validation**, from `ValidateErrorMessage::UNITTEST_PARAMS_NO_PROVIDER` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

Nothing calls a unit test but the test runner, so a test taking parameters has no
caller to fill them. The values it is run with come from the `@parameters`
attribute, and a test declaring parameters without one could never run.

## Example

`test_resources/unittest/test5.yr`:

```ymir
__test (value: i32) {
    assert (value > 0);
}
```

```text
Error[E4286] : a unit test taking parameters must produce them with the parameters attribute
 --> test_resources/unittest/test5.yr:(2,9)
 2  ┃ __test (value: i32) {
    ╋         ^^^^^
    ┗━━━━━━━
```

## How to fix it

Add `@parameters (...)` above the test, giving it the slice of parameter sets --
calling the function producing them if that is where they come from -- or drop the
parameters.

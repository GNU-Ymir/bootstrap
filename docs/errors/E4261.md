# E4261

> unresolved template

Raised during **validation**, from `ValidateErrorMessage::UNRESOLVED_TEMPLATE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A template was used without being resolved to a concrete instantiation.

## Example

`test_resources/templates/explicit/test6.yr`:

```ymir
trait X {}
class A {
    pub self () {
        ;
    }
}

fn foo {Z impl X} (a : Z) {
    a;
}

fn foo {Z impl X} () {
    ;
}

fn main () {
    let a = copy A ();
    foo (a);
    foo!{&A} ();
}
```

```text
Error[E4261] : unresolved template
 --> test_resources/templates/explicit/test6.yr:(12,9)
12  ┃ fn foo {Z impl X} () {
    ╋         ^
    ┗━━━━━━━
```

## How to fix it

Give the template its arguments, explicitly or in a form the compiler can
deduce them from.

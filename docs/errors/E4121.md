# E4121

> the type <> cannot be used as a key, it is not comparable

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::MAP_KEY_NOT_COMPARABLE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A type is used as a map key and defines no comparison, so the map could not
tell two keys apart.

## How to fix it

Define the comparison operator on the type, or key the map on something that
already has one.

# E3014

> module should be located in <>, but no such file exists or access is denied

where `<>` stands for a value the diagnostic fills in.

Raised during **declaration**, from `DeclareErrorMessage::NO_SUCH_FILE_ONE` (`src/ymirc/semantic/declarator/errors.yr`).

## What it means

A module was imported but the single file that could define it does not exist
or cannot be read.

## Example

`test_resources/diagnostics/test95.yr`:

```ymir
// a child module with no file in the directory of the importing module
mod ::nothere;

fn main () {}
```

```text
Error[E3014] : module should be located in /bootstrap/test_resources/diagnostics/test95/nothere.yr, but no such file exists or access is denied
 --> test_resources/diagnostics/test95.yr:(2,5)
 2  ┃ mod ::nothere;
    ╋     ^^-------
    ┗━━━━━━━
```

## How to fix it

Same as [E3013](E3013.md), with only one candidate path.

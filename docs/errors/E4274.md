# E4274

> template specialization expected a value not the type <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::USE_AS_VALUE_TEMPLATE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A template parameter declared as a value was given a type.

## How to fix it

Pass a value, or declare the parameter as a type parameter.

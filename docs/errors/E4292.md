# E4292

> a yield statement must yield a value of type <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::YIELD_NO_VALUE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A `yield` without a value hands nothing to the consumer of the generator. The
type in the message is the one the generator declares.

## Example

`test_resources/generators/test7.yr`:

```ymir
// a yield without a value
yield gen ()-> i32 {
    yield;
}
```

```text
Error[E4292] : a yield statement must yield a value of type i32
 --> test_resources/generators/test7.yr:(3,5)
 3  ┃     yield;
    ╋     ^^^^^
    ┃
    = when validating test7::gen -- (test_resources/generators/test7.yr:(2,7))
    ┗━━━━━━━
```

## How to fix it

Give the `yield` a value. To end the generator early, use `return;`.

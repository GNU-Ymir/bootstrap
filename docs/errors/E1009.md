# E1009

> invalid numeric value formatted in hexadecimal

Raised during **lexing**, from `LexingErrorMessage::INVALID_HEX_NUMBER` (`src/ymirc/lexing/errors.yr`).

## What it means

A literal introduced by `0x` contains a character that is not a hexadecimal
digit. Hexadecimal digits are `0` to `9`, `a` to `f` and `A` to `F`, plus `_` as
a separator.

## Example

`test_resources/lexing/test23.yr`:

```ymir
let x = 0xZ1;
```

```text
Error[E1009] : invalid numeric value formatted in hexadecimal
 --> main.yr:(1,9)
 1  ┃ let x = 0xZ1;
    ╋         ^^^^
    ┃ Note :
    ┃  --> main.yr:(1,11)
    ┃  1  ┃ let x = 0xZ1;
    ┃     ╋           ^
    ┃     ┗━━━━━━━
    ┗━━━━━┻━
```

## How to fix it

Remove the offending character. If it was meant to be a type suffix, check its
spelling: a suffix the lexer does not know is read as part of the number.

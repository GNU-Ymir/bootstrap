# E4354

> <> cannot be used, its value of type <> was moved out

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::USE_AFTER_MOVE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A generator or an async handle has one owner. Once it is moved out of its variable,
`move g`, the variable does not hold it anymore, and any later use of it, a `for`
loop, a call, another move, is rejected. After a conditional or a `match`, a
variable is moved if a branch that does not return or break moved it.

## Example

`test_resources/movable_handles/test11.yr`:

```ymir
// a generator cannot be used once it is moved out of its variable
yield gen (n: i32)-> i32 {
    for i in 0 .. n { yield i; }
}

fn main () {
    let g = gen (3);
    let h = move g;
    for x in g {
        let _: i32 = x;
    }
    for x in h {
        let _: i32 = x;
    }
}
```

## How to fix it

Use the variable the handle was moved to, or assign the variable a new handle
before using it again: an assignment makes it hold a value again.

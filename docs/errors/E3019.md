# E3019

> custom attribute <> is not valid on classes

where `<>` stands for a value the diagnostic fills in.

Raised during **declaration**, from `DeclareErrorMessage::UNDEFINED_ATTRIBUTE_FOR_CLASS` (`src/ymirc/semantic/declarator/errors.yr`).

## What it means

A custom attribute was applied to a class, and the attribute does not accept
classes.

## Example

`test_resources/data_record/attrs/test2.yr`:

```ymir
@data
class Foo {
    pub self () {}
}

fn main() {}
```

```text
Error[E3019] : custom attribute data is not valid on classes
 --> test_resources/data_record/attrs/test2.yr:(1,2)
 1  ┃ @data
    ╋  ^^^^
    ┃ Note :
    ┃  --> test_resources/data_record/attrs/test2.yr:(2,1)
    ┃  2  ┃ class Foo {
    ┃     ╋ ^^^^^
    ┃     ┗━━━━━━━
    ┗━━━━━┻━
```

## How to fix it

Remove the attribute, or apply it to a declaration it accepts. The
declarations an attribute accepts are stated where the attribute itself is
declared.

# E4300

> copying a generator comprehension has no effect

Raised during **validation**, from `ValidateErrorMessage::UNECESSARY_GENERATOR_COPY` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A generator comprehension, `(yield x for x in it)`, builds no list: it creates a
generator, which computes each value when it is iterated. There is nothing for
`copy` to duplicate, unlike a list comprehension, where `copy` builds a slice
instead of an array.

Only a `copy` applied to the comprehension itself is reported. A `dcopy` of a
value merely holding one, `dcopy [(yield x for x in it) for _ in 0 .. 2]`, does
copy the slice, and simply leaves its generators alone.

## Example

`test_resources/generators/test57.yr`:

```ymir
// a generator comprehension allocates its own frame, there is nothing to copy
fn main () {
    let _ = copy (yield x for x in 0 .. 3);
}
```

```text
Error[E4300] : copying a generator comprehension has no effect
 --> test_resources/generators/test57.yr:(3,18)
 3  ┃     let _ = copy (yield x for x in 0 .. 3);
    ╋                  ^
    ┃
    = when validating test57::main -- (test_resources/generators/test57.yr:(2,4))
    ┗━━━━━━━
```

## How to fix it

Drop the `copy`. To collect the values into a slice, use a list comprehension
over the generator, `copy [x for x in (yield x for x in it)]`.

# E4148

> <> is not an array type

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::NOT_AN_ARRAY` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

An operation defined only on arrays was applied to something else.

## How to fix it

Use an array, or the operation defined for the type at hand. A slice is not a
static array: the two differ in whether the length is part of the type.

# E4233

> no constructor is callable with the parameters <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::UNDEFINED_REDIRECT_CALL_CTOR` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A constructor redirection names no constructor callable with the arguments
given.

## Example

`test_resources/diagnostics/test76.yr`:

```ymir
class Foo {
    let x: i32;
    pub self () with self (1, 2) {}
    pub self (x: i32) with x = x {}
}

fn main () { let _ = copy Foo (); }
```

## How to fix it

Match the parameters of an existing constructor; the candidates are listed
under the diagnostic.

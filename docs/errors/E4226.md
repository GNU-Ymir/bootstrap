# E4226

> the call operator is not defined for <> and <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::UNDEFINED_CALL_OP` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A value was called with arguments no candidate accepts. The value and the
arguments are in the message, and the candidates are listed under it.

## Example

`test_resources/diagnostics/test48.yr`:

```ymir
fn main () {
    let x = 1;
    x ();
}
```

```text
Error[E4226] : the call operator is not defined for x: i32 and {}
 --> test_resources/diagnostics/test48.yr:(3,7)
 3  ┃     x ();
    ╋       ^
    ┃ Error[E4107] : call operator is not defined for value 1
    ┃  --> test_resources/diagnostics/test48.yr:(2,13)
    ┃  2  ┃     let x = 1;
    ┃     ╋             ^
    ┃     ┗━━━━━━━
    ┗━━━━━┻━
```

## How to fix it

Match one of the listed candidates, cf. [E4107](E4107.md).

# E4098

> the type <> is not complete due to previous errors

**Retired.** The message this code named was deleted from the compiler: no
code raised it any more. Nothing produces E4098 today.

The code is not reused and not reassigned to another diagnostic, so an E4098
printed by an older compiler still means what is quoted above. This page stays
as its record.

It was raised during **validation**, from `ValidateErrorMessage::INCOMPLETE_TYPE_CLASS`.

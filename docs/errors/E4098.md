# E4098

> the type <> is not complete due to previous errors

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::INCOMPLETE_TYPE_CLASS` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A type could not be completed because validating it raised errors of its own.
This diagnostic is the consequence; the cause is reported separately.

## How to fix it

Fix the errors reported on the type itself.

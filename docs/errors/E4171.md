# E4171

> no parameter is named <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::NO_PARAMETER_NAMED` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A named argument at a call site names a parameter the callee does not have.

## Example

`test_resources/default_ctor/test3.yr`:

```ymir
// A field that is not public is not nameable at the call site, it is not part of
// the signature of the generated ctor.
class Foo {
   pub {
     let x: i32;
     let mut y: i32;
   }

   let mut z: i32 = 98;

   pub self;
}

fn main () {
    let a = copy Foo (y-> 2, 1, z-> 3);
    a.x;
}
```

```text
Error[E4171] : no parameter is named z
 --> test_resources/default_ctor/test3.yr:(15,34)
15  ┃     let a = copy Foo (y-> 2, 1, z-> 3);
    ╋                                  ^^
    ┗━━━━━━━
```

## How to fix it

Check the spelling against the prototype. Note that a parameter with a
default value can only be passed by name, so an unnamed parameter cannot be
reached this way.

# E4207

> the method might throw an exception of type <>, but that is not covered by the method of the ancestor class

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::THROWS_NOT_DECLARED_OVER` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

An overriding method throws an exception the ancestor method does not declare,
cf. [E4186](E4186.md).

## Example

`test_resources/diagnostics/test67.yr`:

```ymir
class A {
    pub self () {}
    pub fn foo (self) {}
}

class B over A {
    pub self () {}
    pub over foo (self) throws AssertError {
        throw copy AssertError ("x");
    }
}

fn main () { let _ = copy B (); }
```

```text
Error[E4207] : the method might throw an exception of type core::exception::assertion::AssertError, but that is not covered by the method of the ancestor class
 --> test_resources/diagnostics/test67.yr:(8,32)
 8  ┃     pub over foo (self) throws AssertError {
    ╋                                ^^^^^^^^^^^
    ┗━━━━━━━
```

## How to fix it

Catch it in the overriding method, or declare it on the ancestor.

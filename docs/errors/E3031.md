# E3031

> unexpected declaration inside a macro

**Retired.** The message this code named was deleted from the compiler: no
source could reach it. The parser only hands a macro body rules, constructors and `use` declarations.

The code is not reused and not reassigned to another diagnostic, so an E3031
printed by an older compiler still means what is quoted above. This page stays
as its record.

It was raised during **declaration**, from `DeclareErrorMessage::UNEXPECTED_IN_MACRO`.

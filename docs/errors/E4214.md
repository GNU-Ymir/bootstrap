# E4214

> tuple access out of bound(<>), tuple arity is <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::TUPLE_ARITY_OVERFLOW` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A tuple element was accessed beyond the arity of the tuple. Both the index and
the arity are in the message.

## Example

`test_resources/diagnostics/test71.yr`:

```ymir
fn main () {
    let t = (1, 2);
    let _ = t._5;
}
```

```text
Error[E4214] : tuple access out of bound(5), tuple arity is 2
 --> test_resources/diagnostics/test71.yr:(3,14)
 3  ┃     let _ = t._5;
    ╋              ^
    ┗━━━━━━━
```

## How to fix it

Correct the index; tuple elements are numbered from zero.

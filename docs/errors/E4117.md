# E4117

> malformed float literal <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::MALFORMED_FLOAT_LITERAL` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A floating-point literal cannot be represented: it is malformed, or outside
what its type can hold.

## Example

`test_resources/diagnostics/test110.yr`:

```ymir
// a float literal whose exponent does not fit
fn main () {
    let _ = 1.0e99999999999999999999;
}
```

```text
Error[E4117] : malformed float literal 1.0e+99999999999999999999
 --> test_resources/diagnostics/test110.yr:(3,13)
 3  ┃     let _ = 1.0e99999999999999999999;
    ╋             ^
    ┃
    = when validating test110::main -- (test_resources/diagnostics/test110.yr:(2,4))
    ┗━━━━━━━
```

## How to fix it

Correct the literal, or widen the type.

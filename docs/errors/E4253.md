# E4253

> the field <> has no initial value

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::UNINIT_FIELD` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A field has no initial value where one is required -- a type whose values can
be created without naming every field needs every field to have a default.

## Example

`test_resources/lit_class/ctors/test2.yr`:

```ymir
class A {
    let i : i32;
    pub self () {}
}
```

```text
Error[E4253] : the field i has no initial value
 --> test_resources/lit_class/ctors/test2.yr:(2,9)
 2  ┃     let i : i32;
    ╋         ^
    ┗━━━━━━━
```

## How to fix it

Give the field an initial value, or construct the type through a constructor
that sets it.

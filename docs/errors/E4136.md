# E4136

> context is already unsafe

Raised during **validation**, from `ValidateErrorMessage::MULTIPLE_UNSAFE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

An `unsafe` block was opened inside another one, so it adds nothing.

## Example

`test_resources/diagnostics/test54.yr`:

```ymir
fn main () {
    unsafe {
        unsafe {
        }
    }
}
```

```text
Error[E4136] : context is already unsafe
 --> test_resources/diagnostics/test54.yr:(3,9)
 3  ┃         unsafe {
    ╋         ^^^^^^
    ┃ Note :
    ┃  --> test_resources/diagnostics/test54.yr:(2,5)
    ┃  2  ┃     unsafe {
    ┃     ╋     ^^^^^^
    ┃     ┗━━━━━━━
    ┗━━━━━┻━
```

## How to fix it

Remove the inner block.

# E4209

> throw statement is not within a function

Raised during **validation**, from `ValidateErrorMessage::THROW_NO_FUNCTION` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A `throw` was written outside any function.

## Example

`test_resources/diagnostics/test70.yr`:

```ymir
lazy X : i32 = { throw copy AssertError ("x"); 1 };

fn main () { X; }
```

```text
Error[E4209] : throw statement is not within a function
 --> test_resources/diagnostics/test70.yr:(1,18)
 1  ┃ lazy X : i32 = { throw copy AssertError ("x"); 1 };
    ╋                  ^^^^^
    ┗━━━━━━━
```

## How to fix it

Move it into the function it belongs to.

# E4279

> cannot create a variable of type void

Raised during **validation**, from `ValidateErrorMessage::VOID_VAR` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A variable was declared of type `void`, cf. [E4039](E4039.md).

## How to fix it

Remove the declaration, or give the variable a type with values.

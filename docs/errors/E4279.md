# E4279

> cannot create a variable of type void

**Retired.** The message this code named was deleted from the compiler: no
code raised it any more. Nothing produces E4279 today.

The code is not reused and not reassigned to another diagnostic, so an E4279
printed by an older compiler still means what is quoted above. This page stays
as its record.

It was raised during **validation**, from `ValidateErrorMessage::VOID_VAR`.

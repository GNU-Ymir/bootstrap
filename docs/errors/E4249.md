# E4249

> the construction of a lazy value has no effect

Raised during **validation**, from `ValidateErrorMessage::UNECESSARY_LAZY` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

`lazy` was applied where the value is used immediately, so nothing is
deferred.

## Example

`test_resources/lazyness/test16.yr`:

```ymir
fn main () {
    match (lazy 12) {
        x => { x; }
    }
}
```

```text
Error[E4249] : the construction of a lazy value has no effect
 --> test_resources/lazyness/test16.yr:(2,12)
 2  ┃     match (lazy 12) {
    ╋            ^^^^
    ┗━━━━━━━
```

## How to fix it

Drop the `lazy`.

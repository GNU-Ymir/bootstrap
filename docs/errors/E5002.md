# E5002

> failed to read YIL byte file <>, file not found or permission denied

where `<>` stands for a value the diagnostic fills in.

Raised during **lowering (YIL)**, from `SerializeYILErrorMessage::FAILED_TO_READ_BYTE_FILE` (`src/ymirc/lint/serialize/errors.yr`).

## What it means

The compiler could not read a `.yil` file it needs. The file is part of an
already compiled package the current one imports; it is either absent from the
include path or not readable.

## How to fix it

Check that the package providing the module has been compiled, and that its
output directory is on the include path. A permission error on an existing file
points at the file mode rather than at the path.

# E4232

> macro call is undefined for <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::UNDEFINED_MACRO_CALL` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A macro was called in a form no rule of it defines.

## How to fix it

Check the call against the rules of the macro, cf. [E4111](E4111.md).

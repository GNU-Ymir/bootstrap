# E1007

> escape character found at end of string literal

Raised during **lexing**, from `LexingErrorMessage::ESCAPE_AT_END_OF_STRING` (`src/ymirc/lexing/errors.yr`).

## What it means

The string literal ends on a backslash: the escape sequence it starts has
nothing to escape, because the closing quote is the next character.

## Example

`test_resources/lexing/test17.yr`:

```ymir
let x = "abc\
```

```text
Error[E1007] : escape character found at end of string literal
 --> main.yr:(1,9)
 1  ┃ let x = "abc\
    ╋         ^   ^
    ┗━━━━━━━
```

## How to fix it

Write `\\` if a literal backslash is wanted, or complete the escape sequence
with the character it applies to.

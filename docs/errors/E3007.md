# E3007

> the ctor built from the fields is implicit in a data record

Raised during **declaration**, from `DeclareErrorMessage::DEFAULT_CTOR_IN_DATA` (`src/ymirc/semantic/declarator/errors.yr`).

## What it means

A `data` record generates its field constructor implicitly, and this
declaration writes it out again.

## Example

`test_resources/default_ctor/test10.yr`:

```ymir
// A `@data` record asks for the ctor by its attribute, the request is implicit
// and is not redeclarable.
@data
record Foo {
    let x: i32;

    pub self;
}

fn main () {
    let a = Foo (1);
    a.x;
}
```

```text
Error[E3007] : the ctor built from the fields is implicit in a data record
 --> test_resources/default_ctor/test10.yr:(7,9)
 7  ┃     pub self;
    ╋         ^^^^
    ┃ Note : declared here
    ┃  --> test_resources/default_ctor/test10.yr:(4,8)
    ┃  4  ┃ record Foo {
    ┃     ╋        ^^^
    ┃     ┗━━━━━━━
    ┗━━━━━┻━
```

## How to fix it

Remove the explicit constructor: a `data` record always has it.

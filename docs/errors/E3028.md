# E3028

> unexpected declaration inside a class

**Retired.** The message this code named was deleted from the compiler: no
source could reach it. The parser only hands a class body the declarations it accepts.

The code is not reused and not reassigned to another diagnostic, so an E3028
printed by an older compiler still means what is quoted above. This page stays
as its record.

It was raised during **declaration**, from `DeclareErrorMessage::UNEXPECTED_IN_CLASS`.

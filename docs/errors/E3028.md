# E3028

> unexpected declaration inside a class

Raised during **declaration**, from `DeclareErrorMessage::UNEXPECTED_IN_CLASS` (`src/ymirc/semantic/declarator/errors.yr`).

## What it means

A declaration appeared inside a class that a class body does not accept.

## How to fix it

Move it out of the class. A class body takes fields, methods, constructors, a
destructor, `impl` blocks and protection blocks.

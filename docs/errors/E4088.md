# E4088

> implicit move of type <> is prohibited

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::IMPLICIT_MOVE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A value would be moved implicitly. A move leaves its source unusable, so it is
always written out.

## Example

`test_resources/diagnostics/test106.yr`:

```ymir
// an entity bound to a second variable without a move
entity Counter {
    pub self () {}
}

fn main () {
    let c = Counter ();
    let _d_ = c;
}
```

```text
Error[E4088] : implicit move of type test106::Counter is prohibited
 --> test_resources/diagnostics/test106.yr:(8,9)
 8  ┃     let _d_ = c;
    ╋         ^^^   -
    ┃
    = when validating test106::main -- (test_resources/diagnostics/test106.yr:(6,4))
    ┗━━━━━━━
```

## How to fix it

Write `move` before the value, or pass a copy instead.

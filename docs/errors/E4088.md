# E4088

> implicit move of type <> is prohibited

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::IMPLICIT_MOVE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A value would be moved implicitly. A move leaves its source unusable, so it is
always written out.

## How to fix it

Write `move` before the value, or pass a copy instead.

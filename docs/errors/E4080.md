# E4080

> local global variable must be declared with a value

Raised during **validation**, from `ValidateErrorMessage::GLOBAL_NO_VALUE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A global variable local to this module was declared without a value. Unlike an
`extern` one, it is defined here and must be initialized.

## Example

`test_resources/diagnostics/test38.yr`:

```ymir
lazy X : i32;

fn main () { X; }
```

## How to fix it

Give it an initial value, or declare it `extern` if it is defined
elsewhere.

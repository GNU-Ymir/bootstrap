# E4161

> <> is not an entity type

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::NOT_AN_ENTITY` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

An operation defined only on entities was applied to something else.

## How to fix it

Use an entity value.

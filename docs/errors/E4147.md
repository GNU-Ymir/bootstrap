# E4147

> <> is not an ancestor type of <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::NOT_ANCESTOR` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A type is used where an ancestor of another type is required, and it is not one
of its ancestors.

## Example

`test_resources/regressions/throws_without_ampersand/test3.yr`:

```ymir
fn main ()
    throws i32
{}

fn foo () {
    throw 12;
}
```

```text
Error[E4147] : mut &(mut core::exception::Exception) is not an ancestor type of i32
 --> test_resources/regressions/throws_without_ampersand/test3.yr:(6,5)
 6  ┃     throw 12;
    ╋     ^^^^^
    ┗━━━━━━━
```

## How to fix it

Name a class the other one actually derives from.

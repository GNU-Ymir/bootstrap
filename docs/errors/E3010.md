# E3010

> a class may only define one destructor

Raised during **declaration**, from `DeclareErrorMessage::MULTIPLE_DESTRUCTOR` (`src/ymirc/semantic/declarator/errors.yr`).

## What it means

A class declares more than one destructor. A destructor takes no parameter, so
there is nothing to overload on.

## Example

`test_resources/diagnostics/test6.yr`:

```ymir
class Foo {
    pub self () {}
    __dtor (mut self) {}
    __dtor (mut self) {}
}

fn main () {}
```

```text
Error[E3010] : a class may only define one destructor
 --> test_resources/diagnostics/test6.yr:(4,5)
 4  ┃     __dtor (mut self) {}
    ╋     ^^^^^^
    ┃ Note :
    ┃  --> test_resources/diagnostics/test6.yr:(3,5)
    ┃  3  ┃     __dtor (mut self) {}
    ┃     ╋     ^^^^^^
    ┃     ┗━━━━━━━
    ┗━━━━━┻━
```

## How to fix it

Keep one destructor and merge the bodies.

# E4221

> attribute <> is not usable in this context

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::UNDEFINED_ATTRIBUTE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

An attribute is valid in general but not where it was written.

## How to fix it

Move it onto a declaration that accepts it.

# E3025

> custom attribute <> may only be applied to classes

where `<>` stands for a value the diagnostic fills in.

Raised during **declaration**, from `DeclareErrorMessage::UNDEFINED_ATTRIBUTE_NO_CLASS` (`src/ymirc/semantic/declarator/errors.yr`).

## What it means

The attribute may only be applied to classes, and it was written on something
else.

## How to fix it

Move the attribute onto the class it was meant for, or remove it.

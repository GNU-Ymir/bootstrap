# E4073

> cannot create a function pointer, entities are not copiable

Raised during **validation**, from `ValidateErrorMessage::FUNCTION_TO_FPTR_ENTITY` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A function pointer would have to capture an entity, and entities are not
copiable, so there is no way to store one in the closure environment.

## How to fix it

Pass the entity as a parameter of the function rather than capturing it.

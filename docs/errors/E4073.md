# E4073

> cannot create a function pointer, entities are not copiable

Raised during **validation**, from `ValidateErrorMessage::FUNCTION_TO_FPTR_ENTITY` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A function pointer would have to capture an entity, and entities are not
copiable, so there is no way to store one in the closure environment.

## Example

`test_resources/diagnostics/test103.yr`:

```ymir
// a function pointer made from the method of an entity
entity Counter {
    pub self () {}
    pub fn get (self)-> i32 { 1 }
}

fn main () {
    let c = Counter ();
    let _ = &c.get;
}
```

```text
Error[E4073] : cannot create a function pointer, entities are not copiable
 --> test_resources/diagnostics/test103.yr:(9,13)
 9  ┃     let _ = &c.get;
    ╋             ^
    ┃
    = when validating test103::main -- (test_resources/diagnostics/test103.yr:(7,4))
    ┗━━━━━━━
```

## How to fix it

Pass the entity as a parameter of the function rather than capturing it.

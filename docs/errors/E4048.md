# E4048

> the self parameter must be mutable in the destructor

**Retired.** The message this code named was deleted from the compiler: no
source could reach it. The parser requires `mut self` as the parameter of a destructor.

The code is not reused and not reassigned to another diagnostic, so an E4048
printed by an older compiler still means what is quoted above. This page stays
as its record.

It was raised during **validation**, from `ValidateErrorMessage::DTOR_SELF_NOT_MUT`.

# E4048

> the self parameter must be mutable in the destructor

Raised during **validation**, from `ValidateErrorMessage::DTOR_SELF_NOT_MUT` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A destructor declares its `self` parameter as constant. A destructor releases
what the instance holds, which is a modification of it.

## How to fix it

Declare `self` mutable in the destructor.

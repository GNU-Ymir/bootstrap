# E4119

> malformed __pragma <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::MALFORMED_PRAGMA` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A `__pragma` expression is malformed -- the arguments it was given are not the
ones the pragma takes.

## Example

`test_resources/pragma/test13.yr`:

```ymir
/*
 * Malformed arities of the type producing pragmas.
 */

class A {
    pub self () {}
}

fn fieldTypeTooFew ()-> __pragma!field_type (&A) {
    12
}

fn unproxiedTooMany ()-> __pragma!unproxied (i32, i32) {
    12
}

fn superTooMany ()-> __pragma!super (&A, &A) {
    12
}

fn rootSuperTooMany ()-> __pragma!root_super (&A, &A) {
    12
}
```

```text
Error[E4119] : malformed __pragma field_type
 --> test_resources/pragma/test13.yr:(9,25)
 9  ┃ fn fieldTypeTooFew ()-> __pragma!field_type (&A) {
    ╋                         ^^^^^^^^
    ┗━━━━━━━
```

## How to fix it

Check the pragma against its documented form; the name of the pragma is in the
message.

# E4122

> the type <> cannot be used as a key, it is not hashable

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::MAP_KEY_NOT_HASHABLE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A type is used as a map key and cannot be hashed.

## How to fix it

Make the type hashable, or key the map on a value derived from it that
already is.

# E4244

> undefined for loop operator with <> iterator for type <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::UNDEF_FOR_LOOP_OPERATOR` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A `for` loop was written over a type that defines no iteration. A type is
iterable when it provides the `begin`, `next` and `get` operators.

## How to fix it

Define those operators on the type, or iterate over something that already
has them.

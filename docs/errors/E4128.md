# E4128

> cannot copy a lazy value, maybe copy and lazy keywords are inverted?

Raised during **validation**, from `ValidateErrorMessage::MISMATCH_COPY_LAZY` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

`copy` was applied to a `lazy` value; the keywords are inverted.

## Example

`test_resources/lazyness/test6.yr`:

```ymir
fn main () {
    let dmut i = copy [1, 2, 3];
    let lazy dmut a = copy (lazy i);
    let lazy dmut b = alias (lazy i);
}
```

```text
Error[E4128] : cannot copy a lazy value, maybe copy and lazy keywords are inverted?
 --> test_resources/lazyness/test6.yr:(3,23)
 3  ┃     let lazy dmut a = copy (lazy i);
    ╋                       ^^^^  ----
    ┃
    = help: invert the two keywords
    ┃
 3  -     let lazy dmut a = copy (lazy i);
 3  +     let lazy dmut a = lazy (copy i);
    ┗━━━━━━━
```

## How to fix it

Swap them: `lazy copy v`.

# E4087

> cannot construct a lazy value of type <> implicitly

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::IMPLICIT_LAZY` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A value was used where a lazy one is expected, without the `lazy` keyword. A
lazy value defers its computation, which changes when the expression runs, so it
is never built implicitly.

## How to fix it

Write `lazy` before the expression.

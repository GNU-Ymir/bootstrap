# E4030

> cte assertion failed

Raised during **validation**, from `ValidateErrorMessage::CTE_ASSERT_NO_MSG` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A `cte assert` evaluated to false during compile time execution, and no message
was given.

## Example

`test_resources/diagnostics/test25.yr`:

```ymir
fn main () {
    cte assert (1 == 2);
}
```

```text
Error[E4030] : cte assertion failed
 --> test_resources/diagnostics/test25.yr:(2,9)
 2  ┃     cte assert (1 == 2);
    ╋         ^^^^^^
    ┗━━━━━━━
```

## How to fix it

Fix the condition, or the values it tests. Adding a message to the assert
makes the next failure say what it was checking.

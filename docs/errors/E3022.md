# E3022

> custom attribute <> is not valid on global variables

where `<>` stands for a value the diagnostic fills in.

Raised during **declaration**, from `DeclareErrorMessage::UNDEFINED_ATTRIBUTE_FOR_GLOBAL` (`src/ymirc/semantic/declarator/errors.yr`).

## What it means

A custom attribute was applied to a global variable, and the attribute does not
accept global variables.

## Example

`test_resources/diagnostics/test11.yr`:

```ymir
@final lazy X : i32 = 0;

fn main () { X; }
```

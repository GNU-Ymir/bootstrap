# E4137

> an iterator cannot be mutable, if it is not a reference or does not borrow mutable data

Raised during **validation**, from `ValidateErrorMessage::MUTABLE_CONST_ITERATOR` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A loop iterator is declared mutable while it neither is a reference nor borrows
mutable data. Mutating it would change a copy, which the loop would then
discard.

## Example

`test_resources/for_loops/arrays/test2.yr`:

```ymir
in test2;

fn main () {
    let dmut a = [1, 2, 3, 4];
    for mut elem : i32 in a {
        assert (a[i] == elem);
    }
}
```

```text
Error[E4137] : an iterator cannot be mutable, if it is not a reference or does not borrow mutable data
 --> test_resources/for_loops/arrays/test2.yr:(5,9)
 5  ┃     for mut elem : i32 in a {
    ╋         ^^^
    ┗━━━━━━━
```

## How to fix it

Drop the `mut`, or iterate by reference if the elements are to be
modified.

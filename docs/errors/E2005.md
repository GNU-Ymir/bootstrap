# E2005

> undefined attribute <>

where `<>` stands for a value the diagnostic fills in.

Raised during **parsing**, from `SyntaxErrorMessage::UNDEFINED_ATTRIBUTE` (`src/ymirc/syntax/errors.yr`).

## What it means

The word used as an attribute is not one the parser knows.

## How to fix it

Correct the spelling. Custom attributes -- the ones a user declares -- are
written in their own syntax and validated later; this error is about the
built-in attribute list.

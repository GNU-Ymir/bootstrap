# E2005

> undefined attribute <>

**Retired.** The message this code named was deleted from the compiler: no
code raised it any more. Nothing produces E2005 today.

The code is not reused and not reassigned to another diagnostic, so an E2005
printed by an older compiler still means what is quoted above. This page stays
as its record.

It was raised during **parsing**, from `SyntaxErrorMessage::UNDEFINED_ATTRIBUTE`.

# E4052

> the type <> cannot be enclosed because it is not complete

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::ENCLOSE_INCOMPLETE_TYPE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A closure captures a value whose type is still being validated, so its size is
not known yet and the closure environment cannot be laid out.

## How to fix it

Break the dependency cycle between the closure and the type, cf.
[E4017](E4017.md).

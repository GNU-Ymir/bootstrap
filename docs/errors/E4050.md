# E4050

> empty interpolation, expected an expression between ${ and }

Raised during **validation**, from `ValidateErrorMessage::EMPTY_FORMAT_EMBED` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A string interpolation `${}` contains nothing between its braces.

## Example

`test_resources/format_string/test8.yr`:

```ymir
in test8;

fn main () {
    let str = f"empty: ${}";
    str;
}
```

```text
Error[E4050] : empty interpolation, expected an expression between ${ and }
 --> test_resources/format_string/test8.yr:(4,26)
 4  ┃     let str = f"empty: ${}";
    ╋                          ^
    ┗━━━━━━━
```

## How to fix it

Write the expression to interpolate, or remove the interpolation.

# E4092

> cannot pass value of type <> as ref

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::IMPLICIT_REFERENCE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A value was passed as `ref` that has no storage to borrow -- a temporary, or
the result of an expression.

## Example

`test_resources/control_flow/test21.yr`:

```ymir
fn main () {
    let (ref x,) = (1,);
}
```

```text

 --> test_resources/control_flow/test21.yr:(2,14)
 2  ┃     let (ref x,) = (1,);
    ╋              ^      ^
    ┃ Note : for pattern field access 0 on type (mut i32,)
    ┃  --> test_resources/control_flow/test21.yr:(2,9)
    ┃  2  ┃     let (ref x,) = (1,);
    ┃     ╋         ^
    ┃     ┗━━━━━━━
    ┗━━━━━┻━
```

## How to fix it

Bind the value to a variable first and pass that.

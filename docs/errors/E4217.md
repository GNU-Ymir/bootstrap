# E4217

> type <> has no fields

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::TYPE_HAS_NO_FIELDINFO` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

Field information was asked of a type that has no fields.

## Example

`test_resources/diagnostics/test72.yr`:

```ymir
fn main () {
    let _ = __pragma!field_infos (i32);
}
```

```text
Error[E4217] : type i32 has no fields
 --> test_resources/diagnostics/test72.yr:(2,13)
 2  ┃     let _ = __pragma!field_infos (i32);
    ╋             ^^^^^^^^
    ┗━━━━━━━
```

## How to fix it

Ask it of a record, an entity or a class.

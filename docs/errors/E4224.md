# E4224

> undefined operator <> for types <> and <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::UNDEFINED_BIN_OP` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A binary operator is not defined for the two operand types. Both are in the
message.

## Example

`test_resources/lit_class/operators/test6.yr`:

```ymir
class A {
    pub self () {}
}

fn main () {
    let a = copy A ();
    a * a;

}
```


## How to fix it

Convert one operand, or define the operator on the type. When both types look
the same, the difference is in their mutability, which is part of the type.

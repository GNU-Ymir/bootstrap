# E3003

> only external global variables may be declared static

Raised during **declaration**, from `DeclareErrorMessage::DECL_GLOB_STATIC_NON_EXTERN` (`src/ymirc/semantic/declarator/errors.yr`).

## What it means

A global variable is declared `static` without being `extern`. `static` says
the variable is defined elsewhere and merely referenced here, which only makes
sense for an external symbol.

## How to fix it

Drop `static` for a variable this module defines, or declare it `extern` if it
is defined by another object file.

# E4099

> index assignment of a value of type <> requires a mutable value

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::INDEX_ASSIGN_NOT_MUTABLE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

An index assignment writes into a value that is not mutable.

## Example

`test_resources/lit_class/operators/test17.yr`:

```ymir
class A {
    pub self () {}

    pub fn opIndexAssign (mut self, _ : i32, _ : i32) {}

}


fn main () {
    let dmut a = copy A ();
    a [0] = 0;
    a:[0] = 0;

    let b = copy A ();
    b [0] = 0;
    b:[0] = 0;
}
```

```text
Error[E4099] : index assignment of a value of type &(test17::A) requires a mutable value
 --> test_resources/lit_class/operators/test17.yr:(15,5)
15  ┃     b [0] = 0;
    ╋     ^ ^  note: the index assignment calls the mutable method opIndexAssign, and thus implicitly aliases the value
    ┗━━━━━━━
```

## How to fix it

Declare the indexed value mutable, cf. [E4082](E4082.md).

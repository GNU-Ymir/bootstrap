# E4150

> <> is not a class type

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::NOT_A_CLASS` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

An operation defined only on classes was applied to something else.

## Example

`test_resources/regressions/throws_without_ampersand/test3.yr`:

```ymir
fn main ()
    throws i32
{}

fn foo () {
    throw 12;
}
```

```text
Error[E4150] : i32 is not a class type
 --> test_resources/regressions/throws_without_ampersand/test3.yr:(2,12)
 2  ┃     throws i32
    ╋            ^^^
    ┗━━━━━━━
```

## How to fix it

Use a class value.

# E4162

> <> is not a trait

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::NOT_A_TRAIT` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A name is used where a trait is required and does not denote one, cf.
[E4094](E4094.md).

## How to fix it

Name a trait.

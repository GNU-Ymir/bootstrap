# E4159

> <> is not a record type

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::NOT_A_RECORD` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

An operation defined only on records was applied to something else.

## How to fix it

Use a record value.

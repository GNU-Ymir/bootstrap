# E4186

> the throwers of the overriding method <> are not compatible with the throwers of the ancestor method <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::OVERRIDE_MISMATCH_THROWERS` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

An overriding method can throw an exception the ancestor method does not
declare. A caller holding the base type would not know to handle it.

## How to fix it

Catch the exception inside the overriding method, or declare it on the
ancestor method.

# E4191

> cannot override private method <>

**Retired.** The message this code named was deleted from the compiler: no
code raised it any more. Nothing produces E4191 today.

The code is not reused and not reassigned to another diagnostic, so an E4191
printed by an older compiler still means what is quoted above. This page stays
as its record.

It was raised during **validation**, from `ValidateErrorMessage::OVERRIDE_PRIVATE`.

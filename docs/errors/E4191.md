# E4191

> cannot override private method <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::OVERRIDE_PRIVATE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A private method of an ancestor is being overridden. A private method is not
visible to the derived class, so it is not part of what the class exposes to be
replaced.

## How to fix it

Widen the protection of the ancestor method, or give the new one a different
name.

# E4241

> decorator <> is not applicable in template specialization

**Retired.** The message this code named was deleted from the compiler: no
code raised it any more. Nothing produces E4241 today.

The code is not reused and not reassigned to another diagnostic, so an E4241
printed by an older compiler still means what is quoted above. This page stays
as its record.

It was raised during **validation**, from `ValidateErrorMessage::UNDEF_DECORATOR_TEMPLATE`.

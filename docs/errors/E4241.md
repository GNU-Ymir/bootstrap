# E4241

> decorator <> is not applicable in template specialization

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::UNDEF_DECORATOR_TEMPLATE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A decorator was written in a template specialization, which specializes on
types and values rather than on decorators.

## How to fix it

Remove the decorator from the specialization.

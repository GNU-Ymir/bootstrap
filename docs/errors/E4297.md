# E4297

> a generator or an async cannot hold a value of type <>, which has a destructor

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::GENERATOR_MOVABLE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A generator or an async can be abandoned while suspended, and its frame is then
collected without its pending destructors ever running. A value whose type has a
destructor cannot be held by a generator or an async for that reason. This includes the
`self` of a generator or an async method, so an entity with a destructor cannot
take the default generator or async method of a trait, and the parameters and
locals of an async lambda.

## Example

`test_resources/generators/test15.yr`:

```ymir
// a generator holding a value with a destructor
entity Handle {
    pub self () {}

    __dtor (mut self) {}
}

yield gen ()-> i32 {
    let h = Handle ();
    yield 1;
}
```

```text
Error[E4297] : a generator or an async cannot hold a value of type mut test15::Handle, which has a destructor
 --> test_resources/generators/test15.yr:(9,20)
 9  ┃     let h = Handle ();
    ╋                    ^
    ┃
    = when validating test15::gen -- (test_resources/generators/test15.yr:(8,7))
    ┗━━━━━━━
```

## How to fix it

Hold the value in the consumer of the generator or the driver of the async, and
pass it what it needs from it.

# E4093

> trait <> is implemented multiple times by <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::IMPL_MULTIPLE_TIMES` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

The same trait is implemented twice by one type, so a call to one of its
methods would have two candidates.

## Example

`test_resources/diagnostics/test43.yr`:

```ymir
trait T { pub fn f (self); }

class Foo {
    pub self () {}
    impl T { pub over f (self) {} }
    impl T { pub over f (self) {} }
}

fn main () {}
```

```text
Error[E4093] : trait test43::T is implemented multiple times by test43::Foo
 --> test_resources/diagnostics/test43.yr:(6,5)
 6  ┃     impl T { pub over f (self) {} }
    ╋     ^^^^
    ┃ Note : here
    ┃  --> test_resources/diagnostics/test43.yr:(1,7)
    ┃  1  ┃ trait T { pub fn f (self); }
    ┃     ╋       ^
    ┃     ┗━━━━━━━
    ┗━━━━━┻━
```

## How to fix it

Merge the two `impl` blocks.

# E4093

> trait <> is implemented multiple times by <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::IMPL_MULTIPLE_TIMES` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

The same trait is implemented twice by one type, so a call to one of its
methods would have two candidates.

## How to fix it

Merge the two `impl` blocks.

# E4134

> named parameter <> is set multiple times

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::MULTIPLE_NAMED_PARAM` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

The same parameter was given twice by name at a call site.

## Example

`test_resources/diagnostics/test53.yr`:

```ymir
fn foo (a: i32 = 0, b: i32 = 0)-> i32 { a + b }

fn main () { foo (a-> 1, a-> 2); }
```

```text
Error[E4134] : named parameter a is set multiple times
 --> test_resources/diagnostics/test53.yr:(3,23)
 3  ┃ fn main () { foo (a-> 1, a-> 2); }
    ╋                       ^   ^^
    ┗━━━━━━━
```

## How to fix it

Remove the duplicate. A parameter given both positionally and by name also
produces this.

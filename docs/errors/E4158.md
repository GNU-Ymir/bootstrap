# E4158

> <> is not a map type

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::NOT_A_MAP` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

An operation defined only on maps was applied to something else.

## How to fix it

Use a map value.

# E4282

> not supported in version ymir <>

**Retired.** The message this code named was deleted from the compiler: `await`
was its only source, and it is now validated in an async (see
[E4344](E4344.md), [E4345](E4345.md) and [E4346](E4346.md)).

The code is not reused and not reassigned to another diagnostic, so an E4282
printed by an older compiler still means what is quoted above. This page stays
as its record.

It was raised during **validation**, from `ValidateErrorMessage::NOT_SUPPORTED_IN`.

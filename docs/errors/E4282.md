# E4282

> not supported in version ymir <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::NOT_SUPPORTED_IN` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

The construct used is not supported by this version of the compiler. The
version is in the message.

`await` is what raises it today: the expression parses, but nothing validates
it.

## Example

`test_resources/syntax/test15.yr`:

```ymir
fn main () {
    let th = spawn compute (10);
    let _aw_ = await th;
}
```

```text
Error[E4282] : not supported in version ymir 1.6
 --> test_resources/syntax/test15.yr:(27,16)
27  ┃     let _aw_ = await th;
    ╋                ^^^^^
    ┃
    = when validating test15::main -- (test_resources/syntax/test15.yr:(25,4))
    ┗━━━━━━━
```

## How to fix it

Use a construct this version supports, or compile with a version that
implements it.

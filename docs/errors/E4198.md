# E4198

> cannot return inside a scope guard

Raised during **validation**, from `ValidateErrorMessage::RETURN_SCOPE_GUARD` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A `return` inside a scope guard would leave the function while the guard is
running, abandoning a scope exit half-way through, cf. [E4008](E4008.md).

## Example

`test_resources/scope_guards/test7.yr`:

```ymir
fn main () {
    {

    } exit {
        {
            throw copy AssertError ("");
        } catch {
            _ => return ;
        }
    }
}
```

```text
Error[E4198] : cannot return inside a scope guard
 --> test_resources/scope_guards/test7.yr:(4,7)
 4  ┃     } exit {
    ╋       ^^^^
   ...
 --> test_resources/scope_guards/test7.yr:(8,18)
 8  ┃             _ => return ;
    ╋                  ^^^^^^
    ┗━━━━━━━
```

## How to fix it

Move the `return` out of the guard body.

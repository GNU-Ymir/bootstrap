# E4140

> a lazy variable cannot be mutable, if it does not borrow mutable data

Raised during **validation**, from `ValidateErrorMessage::MUTABLE_LAZY_VAR` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A lazy variable is declared mutable while it does not borrow mutable data. Its
value is produced on first use, so there is nothing to mutate.

## Example

`test_resources/global/test7.yr`:

```ymir
lazy mut X = 1;
```

```text
Error[E4140] : a lazy variable cannot be mutable, if it does not borrow mutable data
 --> test_resources/global/test7.yr:(1,6)
 1  ┃ lazy mut X = 1;
    ╋      ^^^
    ┗━━━━━━━
```

## How to fix it

Drop the `mut`.

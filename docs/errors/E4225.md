# E4225

> undefined binary operator <>

**Retired.** The message this code named was deleted from the compiler: no
source could reach it. Every binary operator the parser produces is classified.

The code is not reused and not reassigned to another diagnostic, so an E4225
printed by an older compiler still means what is quoted above. This page stays
as its record.

It was raised during **validation**, from `ValidateErrorMessage::UNDEFINED_BIN_OP_TOK`.

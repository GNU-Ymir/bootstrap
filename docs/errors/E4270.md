# E4270

> expression produces a value, but is used as a type

Raised during **validation**, from `ValidateErrorMessage::USE_AS_TYPE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

An expression producing a value was written where a type is expected.

## How to fix it

Write the type. When the two are spelled the same, the name resolves to the
value; qualify it so it resolves to the type.

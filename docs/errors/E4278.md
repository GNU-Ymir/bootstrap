# E4278

> void expression cannot be used as a value

Raised during **validation**, from `ValidateErrorMessage::VOID_VALUE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

An expression producing nothing was used where a value is required.

## Example

`test_resources/diagnostics/test128.yr`:

```ymir
// an array literal of void values
fn nothing () {}

fn main () {
    let _ = [nothing (), nothing ()];
}
```

```text
Error[E4278] : void expression cannot be used as a value
 --> test_resources/diagnostics/test128.yr:(5,22)
 5  ┃     let _ = [nothing (), nothing ()];
    ╋                      ^
    ┃
    = when validating test128::main -- (test_resources/diagnostics/test128.yr:(4,4))
    ┗━━━━━━━
```

## How to fix it

Use a call that returns something, or make the surrounding construct a
statement.

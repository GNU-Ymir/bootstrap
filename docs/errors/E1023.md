# E1023

> #<> without matching #if

where `<>` stands for a value the diagnostic fills in.

Raised during **lexing**, from `LexingErrorMessage::UNMATCHED_VERSION_END` (`src/ymirc/lexing/errors.yr`).

## What it means

A `#else` or `#end` directive was found with no `#if` open at that point --
either the `#if` is missing, or an earlier `#end` already closed it.

## Example

`test_resources/lexing/test8.yr`:

```ymir
#else
```

```text
Error[E1023] : #else without matching #if
 --> main.yr:(1,2)
 1  ┃ #else
    ╋  ^^^^
    ┗━━━━━━━
```

## How to fix it

Add the missing `#if`, or remove the stray directive. Check the nesting of the
enclosing blocks: an `#end` written one level too early closes the outer block
and leaves the next directive unmatched.

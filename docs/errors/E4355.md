# E4355

> <> is already a template parameter of tag <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::TAG_TEMPLATE_SHADOWED` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

The template parameters of a tag, `tag ren {N: usize} (names: [[c8] ; N])`,
are inferred from the arguments of each site, or given explicitly with
`#[ren!{2} (...)]`, and bound next to its parameters in every `apply` and `self`
overload instantiated for the site. A parameter of the tag, or a template
parameter of one of its overloads -- the one receiving the tagged symbol
included -- named after one of them would be replaced by its binding.

## Example

`test_resources/tag/test86.yr`:

```ymir
// Neither the parameters of a tag nor the template parameters of its overloads can shadow its template parameters

in test86;

tag t {C, N: usize} (values: [C ; N], N: usize) {
    pub class apply {class C} {}

    pub self {F: fn ()-> C} () {}
}

fn main () {}
```

```text
Error[E4355] : N is already a template parameter of tag test86::t
 --> test_resources/tag/test86.yr:(5,39)
 5  ┃ tag t {C, N: usize} (values: [C ; N], N: usize) {
    ╋                                       ^
    ┗━━━━━━━
Error[E4355] : C is already a template parameter of tag test86::t
 --> test_resources/tag/test86.yr:(6,28)
 6  ┃     pub class apply {class C} {}
    ╋                            ^
    ┗━━━━━━━
```

## How to fix it

Rename the parameter, or use the template parameter of the tag where the
overload meant to refer to it.

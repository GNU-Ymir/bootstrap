# E3036

> custom attribute <> may only be applied to the ctor of an entity

where `<>` stands for a value the diagnostic fills in.

Raised during **declaration**, from `DeclareErrorMessage::MOVE_ATTRIBUTE_NO_ENTITY` (`src/ymirc/semantic/declarator/errors.yr`).

## What it means

`@no_move` and `@only_move` say which side of the `move` operator a ctor may be
selected from. Only an entity is movable, so the attributes mean nothing on the
ctor of a class or of a record.

## Example

`test_resources/entities/test16.yr`:

```ymir
class Foo {
    @no_move
    pub self () {}
}
```

```text
Error[E3036] : custom attribute no_move may only be applied to the ctor of an entity
 --> test_resources/entities/test16.yr:(4,6)
 4  ┃     @no_move
    ╋      ^^^^^^^
    ┗━━━━━━━
```

## How to fix it

Drop the attribute, or make the type an `entity` if it is meant to own a
resource that is moved rather than copied.

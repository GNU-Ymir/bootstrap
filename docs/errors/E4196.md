# E4196

> ancestor cycle found when validating <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::RECURSIVE_ANCESTOR` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A class hierarchy loops back on itself: a class is, directly or transitively,
its own ancestor.

## Example

`test_resources/diagnostics/test136.yr`:

```ymir
// a class that is its own ancestor
class Node over Node {
    pub self () {}
}

fn main () {
    let _ = copy Node ();
}
```

## How to fix it

Break the cycle in the inheritance chain.

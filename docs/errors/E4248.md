# E4248

> aliasing the value of type <> to call begin and end iterator constant methods is useless

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::UNECESSARY_ALIAS_CPTR_LOOP` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

`alias` was used to call the constant `begin` and `end` iterator methods of a
loop, which do not need the mutability the alias carries.

## How to fix it

Drop the `alias` on the loop subject.

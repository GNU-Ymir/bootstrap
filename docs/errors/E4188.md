# E4188

> cannot override a non trait method <> with <> inside impl

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::OVERRIDE_NON_TRAIT_INSIDE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A method inside an `impl` block overrides a method that is not part of the
trait being implemented. An `impl` block provides the trait, and nothing
else.

## How to fix it

Move the method out of the `impl` block into the type body.

# E4353

> <> is a structure, it has no vtable

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::VTABLE_STRUCT` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

`__pragma!vtable (C)` gives the address of the vtable an instance of `C` is
allocated with. A record or an entity is a structure: it lives on the stack, its
methods are never virtual, and it carries no vtable to point at.

## Example

`test_resources/pragma/test21.yr`:

```ymir
// __pragma!vtable on a record and an entity, which have no vtable

record R {
    pub self () {}
}

entity E {
    pub self () {}
}

fn main () {
    let _r_ = __pragma!vtable (R);
    let _e_ = __pragma!vtable (E);
}
```

## How to fix it

A structure needs no vtable to be built: construct it, or declare it as a class
if its instances must be allocated from their vtable.

# E4324

> a part of <> elements cannot be affected from <> elements

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::PART_AFFECT_LENGTH` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A part of an array or a slice -- a range `a [x .. y]` or several indices
`a [i, j]` -- was affected from an array or a slice of another length, both
lengths being known at compile time. When one of them is only known at run-time,
the lengths are compared at run-time instead, and a mismatch panics as an out of
bounds access does.

## Example

`test_resources/index_ops/test9.yr`:

```ymir
fn main () {
    let dmut a = [1, 2, 3];
    a [0 .. 2] = [9, 12, 15];
}
```

```text
Error[E4324] : a part of 2 elements cannot be affected from 3 elements
 --> test_resources/index_ops/test9.yr:(5,7)
 5  ┃     a [0 .. 2] = [9, 12, 15];
    ╋       ^          -
    ┗━━━━━━━
```

## How to fix it

Make the part and the affected value the same length.

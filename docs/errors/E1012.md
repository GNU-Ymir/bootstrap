# E1012

> invalid numeric value formatted in octal

Raised during **lexing**, from `LexingErrorMessage::INVALID_OCT_NUMBER` (`src/ymirc/lexing/errors.yr`).

## What it means

A literal introduced by `0o` contains a digit outside `0` to `7`.

## Example

`test_resources/lexing/test21.yr`:

```ymir
let x = 0o1892;
```

```text
Error[E1012] : invalid numeric value formatted in octal
 --> main.yr:(1,9)
 1  ┃ let x = 0o1892;
    ╋         ^^^^^^
    ┃ Note :
    ┃  --> main.yr:(1,12)
    ┃  1  ┃ let x = 0o1892;
    ┃     ╋            ^
    ┃     ┗━━━━━━━
    ┗━━━━━┻━
```

## How to fix it

Use only octal digits. A leading zero does not make a number octal in Ymir --
the `0o` prefix does -- so `09` is a decimal literal, not an octal one.

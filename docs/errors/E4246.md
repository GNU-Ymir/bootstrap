# E4246

> the creation of a delegate from a method has no effect

Raised during **validation**, from `ValidateErrorMessage::UNECESSARY_ADDRESS_METHOD` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A delegate was taken of a method in a place where the delegate is used
immediately, so building it changes nothing.

## How to fix it

Call the method directly.

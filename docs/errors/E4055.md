# E4055

> <> guard cannot be used when guarding a scope that cannot throw

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::EXIT_SCOPE_NO_THROW` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A `success` or `failure` guard was written on a block that cannot throw. Such a
guard distinguishes the two ways of leaving the block, and a block that cannot
throw only has one.

## How to fix it

Use an `exit` guard, which runs however the block is left, or drop the guard.
If the block was meant to throw, the call inside it is probably already
caught.

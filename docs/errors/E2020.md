# E2020

> a tag list names at least one tag

Raised during **parsing**, from `SyntaxErrorMessage::EMPTY_TAG_LIST` (`src/ymirc/syntax/errors.yr`).

## What it means

A tag list, `#[...]`, `#(...)` or `#{...}` written before a declaration, names
the tags applied to it, separated by commas. An empty list names none.

## Example

`test_resources/diagnostics/test162.yr`:

```ymir
// a tag list naming no tag
#[]
fn foo () {}

fn main () {}
```

```text
Error[E2020] : a tag list names at least one tag
 --> test_resources/diagnostics/test162.yr:(2,1)
 2  ┃ #[]
    ╋ ^^
    ┗━━━━━━━
```

## How to fix it

Name the tags in the list, `#[route ("/f")]`, or remove it.

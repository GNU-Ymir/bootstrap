# E3023

> custom attribute <> is not valid on records

where `<>` stands for a value the diagnostic fills in.

Raised during **declaration**, from `DeclareErrorMessage::UNDEFINED_ATTRIBUTE_FOR_RECORD` (`src/ymirc/semantic/declarator/errors.yr`).

## What it means

A custom attribute was applied to a record, and the attribute does not accept
records.

## Example

`test_resources/diagnostics/test12.yr`:

```ymir
@inline
record Foo {
    let x: i32;
}

fn main () { let _ = Foo (1); }
```

```text
Error[E3023] : custom attribute inline is not valid on records
 --> test_resources/diagnostics/test12.yr:(1,2)
 1  ┃ @inline
    ╋  ^^^^^^
    ┃ Note :
    ┃  --> test_resources/diagnostics/test12.yr:(2,1)
    ┃  2  ┃ record Foo {
    ┃     ╋ ^^^^^^
    ┃     ┗━━━━━━━
    ┗━━━━━┻━
```

## How to fix it

Same as [E3019](E3019.md).

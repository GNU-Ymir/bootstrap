# E4346

> cannot await a value of type <>, only an async value, a future value or a class with a poll method

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::AWAIT_NOT_AWAITABLE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

Only something that can be suspended on can be awaited: an async value
(`async-> T`), a future value, or an instance of a class with a `poll` method.
Anything else is already a value, there is nothing to wait for.

## Example

`test_resources/async/test31.yr`:

```ymir
// Only an async value, a future value or a class with a poll method can be awaited.

fn one ()-> i32 {
    1
}

async outer ()-> i32 {
    await one ()
}
```

```text
Error[E4346] : cannot await a value of type i32, only an async value, a future value or a class with a poll method
 --> test_resources/async/test31.yr:(8,5)
 8  ┃     await one ()
    ╋     ^^^^^
    ┃
    = when validating test31::outer -- (test_resources/async/test31.yr:(7,7))
    ┗━━━━━━━
```

## How to fix it

Use the value directly, without `await`, or make the function it comes from
an async.

# E1014

> expected sign information in scientific floating-point literal

Raised during **lexing**, from `LexingErrorMessage::MISSING_SCI_FLOAT_SIGN` (`src/ymirc/lexing/errors.yr`).

## What it means

A floating-point literal in scientific notation has an `e` exponent marker that
is not followed by a sign.

## Example

`test_resources/lexing/test27.yr`:

```ymir
let x = 1.0e;
```

```text
Error[E1014] : expected sign information in scientific floating-point literal
 --> main.yr:(1,9)
 1  ┃ let x = 1.0e;
    ╋         ^
    ┗━━━━━━━
```

## How to fix it

Write the sign: `1.5e+10` rather than `1.5e10`.

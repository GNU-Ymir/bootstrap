# E4349

> the method poll of an awaited class cannot throw, an async never throws

Raised during **validation**, from `ValidateErrorMessage::AWAIT_POLL_THROWS` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

An async never throws ([E4341](E4341.md)), and an `await` cannot be inside a
try block ([E4293](E4293.md)), so nothing could catch an exception thrown by the
method `poll` of an awaited class. It is reported under [E4347](E4347.md), with
the exceptions the method declares.

## Example

`test_resources/async/test46.yr`:

```ymir
// The method poll of an awaited class cannot throw, an async never throws.

class Throwing {
    let _n: i32 = 0;

    pub self () {}

    pub fn poll (self, waker: dg ()-> void)-> i32?
        throws AssertError
    {
        assert (self._n > 0);
        waker ();
        none
    }
}

async outer ()-> i32 {
    await copy Throwing ()
}
```

## How to fix it

Catch the exceptions inside `poll`, and report the error through the value
the await completes with.

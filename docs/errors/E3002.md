# E3002

> module is ambiguously defined in both <> and <>

**Retired.** The message this code named was deleted from the compiler: a `mod`
declaration names the one file it imports, through its root (`::` for a child,
`.` for a sibling), so no two files can claim the same module. A `mod` without a
root is refused with [E2019](E2019.md).

The code is not reused and not reassigned to another diagnostic, so an E3002
printed by an older compiler still means what is quoted above. This page stays
as its record.

It was raised during **declaration**, from `DeclareErrorMessage::CONFLICT_MODULES`.

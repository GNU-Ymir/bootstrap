# E4015

> alias operator :. is only usable on class, record, entity or map types, not <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::CLASS_ALIAS_FIELD_NO_CLASS` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

The alias operator `:.` was applied to a type that has no method to alias --
it is only defined for classes, records, entities and maps.

## How to fix it

Drop the operator, or apply it to a value of one of those types.

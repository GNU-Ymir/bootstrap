# E3008

> record types cannot define destructors

Raised during **declaration**, from `DeclareErrorMessage::DTOR_IN_RECORD` (`src/ymirc/semantic/declarator/errors.yr`).

## What it means

A record declares a destructor. Records are value types, copied and discarded
without any bookkeeping, so there is no point at which a destructor could be
run.

## How to fix it

Move the type to a `class` if it owns a resource that has to be released, or
release the resource explicitly through a method the user calls.

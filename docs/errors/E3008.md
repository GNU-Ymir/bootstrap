# E3008

> record types cannot define destructors

**Retired.** The message this code named was deleted from the compiler: no
source could reach it. The parser does not accept a destructor inside a record.

The code is not reused and not reassigned to another diagnostic, so an E3008
printed by an older compiler still means what is quoted above. This page stays
as its record.

It was raised during **declaration**, from `DeclareErrorMessage::DTOR_IN_RECORD`.

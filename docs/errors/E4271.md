# E4271

> template specialization expected a type not the value <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::USE_AS_TYPE_TEMPLATE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A template parameter declared as a type was given a value.

## Example

`test_resources/templates/implicit/test18.yr`:

```ymir
record A {N : u32} {
    pub self () {}
}

fn foo {N} (a : A!{N}) {
    a;
}


fn main () {
    let a = A!{2u32} ();
    foo (a);
}
```

```text
Error[E4271] : template specialization expected a type not the value 2u32
 --> test_resources/templates/implicit/test18.yr:(11,16)
11  ┃     let a = A!{2u32} ();
    ╋                ^
    ┃ Note :
    ┃  --> test_resources/templates/implicit/test18.yr:(5,9)
    ┃  5  ┃ fn foo {N} (a : A!{N}) {
    ┃     ╋         ^
    ┃     ┗━━━━━━━
    ┗━━━━━┻━
```

## How to fix it

Pass a type, or declare the parameter as a value parameter.

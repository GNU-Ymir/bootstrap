# E4075

> using a deep copy instead of a one level copy is prohibited when enclosing a record

Raised during **validation**, from `ValidateErrorMessage::FUNCTION_TO_FPTR_RECORD_DCOPY` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A record was captured with `dcopy` where the one level `copy` is required, cf.
[E4033](E4033.md).

## How to fix it

Use `copy`.

# E4075

> using a deep copy instead of a one level copy is prohibited when enclosing a record

Raised during **validation**, from `ValidateErrorMessage::FUNCTION_TO_FPTR_RECORD_DCOPY` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A record was captured with `dcopy` where the one level `copy` is required, cf.
[E4033](E4033.md).

## Example

`test_resources/diagnostics/test105.yr`:

```ymir
// a function pointer made from the method of a record, inside a deep copy
record Counter {
    pub self () {}
    pub fn get (self)-> i32 { 1 }
}

fn main () {
    let c = Counter ();
    let _ = dcopy &c.get;
}
```

```text

 --> test_resources/diagnostics/test105.yr:(9,19)

    = when validating test105::main -- (test_resources/diagnostics/test105.yr:(7,4))
    ┗━━━━━━━
```

## How to fix it

Use `copy`.

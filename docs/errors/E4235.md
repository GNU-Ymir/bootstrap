# E4235

> no constructor of the super class is callable with the parameters <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::UNDEFINED_SUPER_CALL_CTOR` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A `super` constructor call names no constructor of the base class callable with
the arguments given.

## How to fix it

Match one of the base class constructors.

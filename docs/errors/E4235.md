# E4235

> no constructor of the super class is callable with the parameters <>

**Retired.** The message this code named was deleted from the compiler: no
code raised it any more. Nothing produces E4235 today.

The code is not reused and not reassigned to another diagnostic, so an E4235
printed by an older compiler still means what is quoted above. This page stays
as its record.

It was raised during **validation**, from `ValidateErrorMessage::UNDEFINED_SUPER_CALL_CTOR`.

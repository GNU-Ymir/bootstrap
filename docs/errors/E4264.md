# E4264

> unterminated escape sequence

Raised during **validation**, from `ValidateErrorMessage::UNTERMINATED_ESCAPE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A literal ends inside an escape sequence, cf. [E1007](E1007.md).

## Example

`test_resources/diagnostics/test125.yr`:

```ymir
// a unicode escape with no code point
fn main () {
    let _ = "\u";
}
```

```text
Error[E4264] : unterminated escape sequence
 --> test_resources/diagnostics/test125.yr:(3,16)
 3  ┃     let _ = "\u";
    ╋                ^
    ┃
    = when validating test125::main -- (test_resources/diagnostics/test125.yr:(2,4))
    ┗━━━━━━━
```

## How to fix it

Complete the escape, or double the backslash.

# E4169

> no constructor named <> found for class <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::NO_CTOR_FOUND_NAME` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A named constructor was called and the class has no constructor of that
name.

## Example

`test_resources/diagnostics/test62.yr`:

```ymir
class Foo {
    pub self () {}
}

fn main () { let _ = copy Foo::named (); }
```

```text
Error[E4169] : no constructor named named found for class test62::Foo
 --> test_resources/diagnostics/test62.yr:(5,30)
 5  ┃ fn main () { let _ = copy Foo::named (); }
    ╋                              ^^
    ┗━━━━━━━
```

## How to fix it

Check the spelling, or use the unnamed constructor.

# E4011

> cannot cast derived type <> to base class type <> in that context

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::CANNOT_CASTTO_BASE_CLASS` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A value of a derived class type is cast to one of its base classes in a context
that does not allow it. The cast itself is meaningful, but not where it was
written.

## How to fix it

Bind the value to a variable of the base class type, which performs the
conversion where it is allowed, and use that variable.

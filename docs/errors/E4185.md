# E4185

> the protection <> of the overriding method <> does not match the definition in the ancestor class <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::OVERRIDE_MISMATCH_PROTECTION` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

An overriding method has a different protection from the one it overrides. A
caller reaching the method through the base class would otherwise see a
protection that does not hold for the actual instance.

## Example

`test_resources/diagnostics/test66.yr`:

```ymir
class A {
    pub self () {}
    pub fn foo (self) {}
}

class B over A {
    pub self () {}
    prv over foo (self) {}
}

fn main () { let _ = copy B (); }
```

```text
Error[E4185] : the protection prv of the overriding method test66::B::foo ()-> void does not match the definition in the ancestor class pub
 --> test_resources/diagnostics/test66.yr:(3,12)
 3  ┃     pub fn foo (self) {}
    ╋            ^^^
   ...
 --> test_resources/diagnostics/test66.yr:(8,14)
 8  ┃     prv over foo (self) {}
    ╋              ^^^
    ┗━━━━━━━
```

## How to fix it

Give the overriding method the same protection as the ancestor one.

# E4163

> <> is not a tuple type

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::NOT_A_TUPLE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

An operation defined only on tuples was applied to something else.

## Example

`test_resources/lit_tuples/test22.yr`:

```ymir
fn main () {
    let mut a = 0, mut b = 0;

    (a, b) = 12;
}
```

```text
Error[E4163] : i32 is not a tuple type
 --> test_resources/lit_tuples/test22.yr:(4,12)
 4  ┃     (a, b) = 12;
    ╋            ^ ^^
    ┗━━━━━━━
```

## How to fix it

Use a tuple value.

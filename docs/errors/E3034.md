# E3034

> module <> must be defined in a file named <>

where `<>` stands for a value the diagnostic fills in.

Raised during **declaration**, from `DeclareErrorMessage::WRONG_MODULE_NAME` (`src/ymirc/semantic/declarator/errors.yr`).

## What it means

The module name declared by the `in`/`mod` header does not match the file it is
written in. Module names are resolved to paths, so the two have to agree for an
import to find the file.

## How to fix it

Rename the file to the reported name, or change the declared module name to
match the file.

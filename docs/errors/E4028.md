# E4028

> type <> cannot be embedded within a union type

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::CONTAIN_ALIASABLE_TYPE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A type that can be aliased -- one that borrows memory -- was placed in a union.
The fields of a union share their storage, so the compiler cannot know which of
them owns the memory at a given moment.

## Example

`test_resources/union/test5.yr`:

```ymir
@overlaid
record A {
    let a : [i32];
}
```

```text
Error[E4028] : type [i32] cannot be embedded within a union type
 --> test_resources/union/test5.yr:(3,5)
 3  ┃     let a : [i32];
    ╋     ^^^     ^
    ┃ Note : union cannot contain aliasable types, with the exceptions of pointer types
    ┃  --> test_resources/union/test5.yr:(2,8)
    ┃  2  ┃ record A {
    ┃     ╋        ^
    ┃     ┗━━━━━━━
    ┗━━━━━┻━
```

## How to fix it

Store the borrowing type outside the union, and keep only plain values in
it.

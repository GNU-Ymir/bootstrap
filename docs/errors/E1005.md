# E1005

> escaping a line break is prohibited; use a multiline string instead """

Raised during **lexing**, from `LexingErrorMessage::ESCAPE_RETURN_PROHIBITED_STRING` (`src/ymirc/lexing/errors.yr`).

## What it means

A backslash was used to continue a `"` string literal onto the next line. Ymir
does not accept an escaped line break inside a string: a literal either fits on
one line or uses the multiline form.

## Example

`test_resources/lexing/test15.yr`:

```ymir
let x = "abc\
def";
```

```text
Error[E1005] : escaping a line break is prohibited; use a multiline string instead """
 --> main.yr:(1,9)
 1  ┃ let x = "abc\
    ╋         ^   ^
    ┗━━━━━━━
```

## How to fix it

Write the literal as `""" ... """`, which spans lines without any escaping,
or put `\n` in a single-line literal where the break is wanted.

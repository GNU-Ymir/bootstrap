# E4314

> union <> does not list the member <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::UNION_MEMBER_UNKNOWN` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A pattern over a union names the member it tests, and the union holds one of
the members it declares and nothing else. A type the union does not list can
never be the one held, so the arm naming it matches nothing and is rejected
rather than left as dead code.

The member is matched by identity, not by convertibility: a type that merely
converts to a declared member is not that member either.

## Example

`test_resources/type_union/test48.yr`:

```ymir
record X {
    pub self () {}
}

record Y {
    pub self () {}
}

record Z {
    pub self () {}
}

union U
| X
| Y;

fn main () {
    let u : U = X ();
    match u {
        z : Z => { z; }
        _ => {}
    }
}
```

## How to fix it

Name a member the union declares, or add the type to the union when it is meant
to be one.

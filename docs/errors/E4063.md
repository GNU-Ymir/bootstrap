# E4063

> field assign method must not return a value

Raised during **validation**, from `ValidateErrorMessage::FIELD_METHOD_ASSIGN_WITH_RETURN` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A field assign method returns a value. It stands in for an assignment, which
produces nothing.

## Example

`test_resources/diagnostics/test36.yr`:

```ymir
class Foo {
    let mut x: i32 = 0;
    pub self () {}
    @field pub fn bar (mut self, v: i32)-> i32 { self.x = v; v }
}

fn main () { let dmut f = copy Foo (); f:.bar = 1; }
```

## How to fix it

Remove the return value.

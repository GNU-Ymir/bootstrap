# E4152

> <> is enclosed, and cannot be used as a lvalue

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::NOT_A_LVALUE_CLOSURE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A variable captured by a closure was used as an lvalue. The closure holds a
copy in its environment, so writing to the name would not reach the original.

## How to fix it

Capture a reference to the variable if the write has to be visible outside, or
return the new value from the closure.

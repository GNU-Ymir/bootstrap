# E4164

> <> is not a union type

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::NOT_AN_UNION` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

An operation defined only on unions was applied to something else.

## How to fix it

Use a union value.

# E4321

> method <> cannot be used while the methods of <> are being validated

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::CLASS_METHOD_NOT_VALIDATED_YET` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

The prototypes of the methods of a class are validated together, to lay out its
vtable, so none of its methods -- declared in the class or inherited -- can be
called from one of them, e.g. in a `typeof` of a return type. Its fields are
validated before, so `typeof (self.x)` is accepted, cf. [E4017](E4017.md) for a
field used before it is validated.

## Example

`test_resources/diagnostics/test156.yr`:

```ymir
// the prototype of a method reads another method of its own class
class A {
    pub self () {}

    pub fn size (self)-> i64 {
        1
    }

    pub fn get (self)-> typeof (self.size ()) {
        self.size ()
    }
}

fn main () {
    let _ = copy A ();
}
```

## How to fix it

Write the return type explicitly, or take the `typeof` of a field, or of an
expression that does not go through a method of the class.

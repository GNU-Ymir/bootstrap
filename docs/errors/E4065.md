# E4065

> field method <> is mutable

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::FIELD_METHOD_MUTABLE_ALIAS` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A field method is mutable and is being used where a constant one is required --
typically through a value borrowed as constant.

## Example

`test_resources/lit_class/methods/test8.yr`:

```ymir
record A {
    let mut _x : i32 = 0;

    pub self () {}

    @field
    pub fn foo (self)-> i32 {
        self._x
    }

    @field
    pub fn foo (mut self, i : i32) {
        self._x = i;
    }

}


fn main () {
    let a = A ();
    a.foo += 1;
}
```

```text
Error[E4065] : field method test8::A::foo (i: i32)-> void is mutable
 --> test_resources/lit_class/methods/test8.yr:(12,12)
12  ┃     pub fn foo (mut self, i : i32) {
    ╋            ^^^
    ┃ Error[E4082] : left operand of type test8::A is immutable
    ┃  --> test_resources/lit_class/methods/test8.yr:(21,5)
    ┃ 21  ┃     a.foo += 1;
    ┃     ╋     ^^
    ┃     ┗━━━━━━━
    ┗━━━━━┻━
```

## How to fix it

Use a constant field method for reading, and reserve the mutable one for
writing.

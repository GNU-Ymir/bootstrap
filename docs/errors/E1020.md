# E1020

> the fractional part of the floating-point number is empty

Raised during **lexing**, from `LexingErrorMessage::EMPTY_DEC_FLOAT_NUMBER` (`src/ymirc/lexing/errors.yr`).

## What it means

A floating-point literal has a decimal point with no digit after it.

## Example

`test_resources/lexing/test26.yr`:

```ymir
let x = 1._;
```

```text
Error[E1020] : the fractional part of the floating-point number is empty
 --> main.yr:(1,9)
 1  ┃ let x = 1._;
    ╋         ^
    ┃ Note :
    ┃  --> main.yr:(1,11)
    ┃  1  ┃ let x = 1._;
    ┃     ╋           ^
    ┃     ┗━━━━━━━
    ┗━━━━━┻━
```

## How to fix it

Write the fractional digits (`1.0`), or drop the point if an integer was
meant. A trailing point is not a valid way to write a float in Ymir.

# E4330

> the variable <> is only rebound, its type <> can be <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::DECLARED_DMUT_NOT_MUTATED` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A local variable was declared deeply mutable, with `dmut` or a type with inner
mutable levels, but it is only ever rebound: none of its elements is written,
and it is never handed out by `alias`, `ref`, `&` or `move`. Rebinding needs
`mut` alone, the levels below are mutability granted for nothing.

A reference is not reported, it keeps the mutability of what it refers to.

## Example

`test_resources/warnings/test36.yr`:

```ymir
fn main () {
    let dmut b = copy [1, 2, 3];
    b = copy [1];
}
```

```text
Warning[E4330] : the variable b is only rebound, its type mut [mut i32] can be mut [i32]
 --> test_resources/warnings/test36.yr:(8,9)
 8  ┃     let dmut b = copy [1, 2, 3];
    ╋         ^^^^
    ┃
    = help: declare it mut
    ┃
 8  -     let dmut b = copy [1, 2, 3];
 8  +     let mut b = copy [1, 2, 3];
    ┗━━━━━━━
```

## How to fix it

Declare the variable `mut` instead of `dmut`, or give it the type the message
names.

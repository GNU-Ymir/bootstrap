# E4041

> decorator is not applicable on inner types, already deeply mutable

Raised during **validation**, from `ValidateErrorMessage::DEEPLY_INNER_TYPE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A mutability decorator was applied to the inner part of a type that is already
deeply mutable, so it states something already true.

## Example

`test_resources/diagnostics/test99.yr`:

```ymir
// a mut decorator inside a type that is already deeply mutable
fn main () {
    let mut _x_ : dmut [mut i32] = copy [1];
}
```

```text
Error[E4041] : decorator is not applicable on inner types, already deeply mutable
 --> test_resources/diagnostics/test99.yr:(3,25)
 3  ┃     let mut _x_ : dmut [mut i32] = copy [1];
    ╋                         ^^^
    ┃
    = when validating test99::main -- (test_resources/diagnostics/test99.yr:(2,4))
    ┗━━━━━━━
```

## How to fix it

Remove the decorator.

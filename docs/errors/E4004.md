# E4004

> field <> was already initialized by ctor redirection

**Retired.** The message this code named was deleted from the compiler: no
source could reach it. A record constructor redirecting to `self` cannot initialize fields as well: the parser rejects the combination.

The code is not reused and not reassigned to another diagnostic, so an E4004
printed by an older compiler still means what is quoted above. This page stays
as its record.

It was raised during **validation**, from `ValidateErrorMessage::ALREADY_INIT_BY_CTOR_REDIRECT`.

# E4004

> field <> was already initialized by ctor redirection

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::ALREADY_INIT_BY_CTOR_REDIRECT` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A constructor assigns a field that the constructor it redirects to has already
initialized. Redirection runs the other constructor first, so the field already
has its value when this body starts.

## How to fix it

Remove the assignment, or stop redirecting and initialize every field
here.

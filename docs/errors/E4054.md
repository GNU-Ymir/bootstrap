# E4054

> scope guard does not catch exceptions of type <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::EXCEPTION_NOT_CAUGHT` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A scope guard is written on a block that can throw an exception the guard does
not handle, so the exception would escape past the guard.

## Example

`test_resources/diagnostics/test31.yr`:

```ymir
class A over Exception { pub self () {} }
class B over Exception { pub self () {} }

fn foo () throws A, B;

fn main () {
    { foo (); } catch {
        A () => {}
    }
}
```

```text
Error[E4054] : scope guard does not catch exceptions of type test31::B
 --> test_resources/diagnostics/test31.yr:(7,11)
 7  ┃     { foo (); } catch {
    ╋           ^     ^^^^^
    ┗━━━━━━━
```

## How to fix it

Add a catch for the reported type, or declare the enclosing function as
throwing it.

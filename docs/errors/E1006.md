# E1006

> escaping a line break is prohibited; use a multiline comment instead /**/

Raised during **lexing**, from `LexingErrorMessage::ESCAPE_RETURN_PROHIBITED_COMMENT` (`src/ymirc/lexing/errors.yr`).

## What it means

A backslash was used to continue a single-line comment onto the next line.
Escaping a line break has no meaning in a comment.

## Example

`test_resources/lexing/test16.yr`:

```ymir
// abc\
def
```

```text
Error[E1006] : escaping a line break is prohibited; use a multiline comment instead /**/
 --> main.yr:(1,1)
 1  ┃ // abc\
    ╋ ^^    ^
    ┗━━━━━━━
```

## How to fix it

Use a block comment (`/* ... */`) for a comment that spans several lines, or
repeat `//` on each line.

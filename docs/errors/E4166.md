# E4166

> an unsafe context is entered, but no unsafe operations are made

Raised during **validation**, from `ValidateErrorMessage::NOT_UNSAFE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

An `unsafe` block contains no operation that needed it. A block that says it is
unsafe but is not tells a reader the wrong thing.

## How to fix it

Remove the `unsafe`, or narrow it to the operation that actually needs it.

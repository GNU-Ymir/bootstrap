# E4239

> undefined cte for loop operator with <> iterator for type <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::UNDEF_CTE_FOR_LOOP_OPERATOR` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A `cte for` loop was written over a type that defines no compile time
iteration.

## How to fix it

Iterate over a type that does -- a tuple, or a compile time range.

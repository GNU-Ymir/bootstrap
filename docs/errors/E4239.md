# E4239

> undefined cte for loop operator with <> iterator for type <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::UNDEF_CTE_FOR_LOOP_OPERATOR` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A `cte for` loop was written over a type that defines no compile time
iteration.

## Example

`test_resources/diagnostics/test123.yr`:

```ymir
// a compile time loop over a slice, whose length is not known at compile time
fn main () {
    cte for i in copy [1, 2] {
        let _ = i;
    }
}
```

```text
Error[E4239] : undefined cte for loop operator with 1 iterator for type mut [mut i32]
 --> test_resources/diagnostics/test123.yr:(3,9)
 3  ┃     cte for i in copy [1, 2] {
    ╋         ^^^
    ┃
    = when validating test123::main -- (test_resources/diagnostics/test123.yr:(2,4))
    ┗━━━━━━━
```

## How to fix it

Iterate over a type that does -- a tuple, an array, or a compile time range.

# E3026

> custom attribute <> may only be applied to records

where `<>` stands for a value the diagnostic fills in.

Raised during **declaration**, from `DeclareErrorMessage::UNDEFINED_ATTRIBUTE_NO_RECORD` (`src/ymirc/semantic/declarator/errors.yr`).

## What it means

The attribute may only be applied to records, and it was written on something
else.

## Example

`test_resources/diagnostics/test15.yr`:

```ymir
@packed
entity Foo {
    let x: i32 = 0;
}

fn main () { let _ = Foo (); }
```

```text
Error[E3026] : custom attribute packed may only be applied to records
 --> test_resources/diagnostics/test15.yr:(1,2)
 1  ┃ @packed
    ╋  ^^^^^^
    ┃ Note :
    ┃  --> test_resources/diagnostics/test15.yr:(2,1)
    ┃  2  ┃ entity Foo {
    ┃     ╋ ^^^^^^
    ┃     ┗━━━━━━━
    ┗━━━━━┻━
```

## How to fix it

Move the attribute onto the record it was meant for, or remove it.

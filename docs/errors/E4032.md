# E4032

> <> values contained in a block scope are ignored during compile time execution

**Retired.** The message this code named was deleted from the compiler: no
code raised it any more. Nothing produces E4032 today.

The code is not reused and not reassigned to another diagnostic, so an E4032
printed by an older compiler still means what is quoted above. This page stays
as its record.

It was raised during **validation**, from `ValidateErrorMessage::CTE_IGNORED`.

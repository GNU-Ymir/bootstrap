# E4032

> <> values contained in a block scope are ignored during compile time execution

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::CTE_IGNORED` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A block evaluated at compile time produces values that compile time execution
does not keep. They are computed and discarded.

## How to fix it

Remove the dead values, or move what they were meant to do outside the
compile time context.

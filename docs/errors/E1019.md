# E1019

> the exponent part of the floating-point number is empty

Raised during **lexing**, from `LexingErrorMessage::EMPTY_EXP_FLOAT_NUMBER` (`src/ymirc/lexing/errors.yr`).

## What it means

The exponent marker of a floating-point literal is followed by a sign but by no
digit, so the exponent has no value.

## Example

`test_resources/lexing/test5.yr`:

```ymir
1.e+
```

```text
Error[E1019] : the exponent part of the floating-point number is empty
 --> main.yr:(1,1)
 1  ┃ 1.e+
    ╋ ^
    ┗━━━━━━━
```

## How to fix it

Write the exponent digits, as in `1.0e+10`, or drop the exponent part
entirely.

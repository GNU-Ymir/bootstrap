# E5006

> malformed bytecode, type table invalid

Raised during **lowering (YIL)**, from `SerializeYILErrorMessage::MALFORMED_BYTECODE_TYPE_TABLE` (`src/ymirc/lint/serialize/errors.yr`).

## What it means

The type table of a `.yil` file could not be decoded. The bytecode carries the
types of a module in a table the rest of the file refers to by index, and that
table is invalid.

## How to fix it

Recompile the package that produced the file, cf. [E5005](E5005.md).

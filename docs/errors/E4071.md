# E4071

> the type cannot be inferred, as it depends on a forward reference

**Retired.** The message this code named was deleted from the compiler: no
code raised it any more. Nothing produces E4071 today.

The code is not reused and not reassigned to another diagnostic, so an E4071
printed by an older compiler still means what is quoted above. This page stays
as its record.

It was raised during **validation**, from `ValidateErrorMessage::FORWARD_REFERENCE_VAR`.

# E4071

> the type cannot be inferred, as it depends on a forward reference

Raised during **validation**, from `ValidateErrorMessage::FORWARD_REFERENCE_VAR` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

The type of a variable is inferred from its value, and that value depends on
something not yet defined.

## How to fix it

Write the type explicitly, which removes the need to resolve the value first,
or reorder the declarations.

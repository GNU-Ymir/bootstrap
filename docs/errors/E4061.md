# E4061

> method <> is a field method

**Retired.** The message is still raised, but only as a note under
[E4019](E4019.md), which documents it, and it no longer carries a code of its own.

The code is not reused and not reassigned to another diagnostic, so an E4061
printed by an older compiler still means what is quoted above. This page stays
as its record.

It was raised during **validation**, from `ValidateErrorMessage::FIELD_METHOD_ALIAS`.

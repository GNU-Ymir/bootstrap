# E4061

> method <> is a field method

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::FIELD_METHOD_ALIAS` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

An alias was taken of a method that is a field method. Field methods are
reached through the field syntax and have no standalone value to alias.

## How to fix it

Use the field syntax, or alias an ordinary method.

# E4365

> the compile-time execution exceeds its limit of <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::CTE_EXEC_LIMIT` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A value needed at compile time calls a function, which the compiler executed to
compute the value, and the execution evaluated more values, or nested more calls,
than a compile-time execution is allowed to. The limit protects the compilation
against code that does not terminate; the note points at where the execution was
when it reached it.

## Example

`test_resources/cte_exec/test7.yr`:

```ymir
fn forever ()-> i32 {
    let mut i = 0us;
    loop {
        i = i + 1us;
        if (i == 0us) break;
    }
    cast!i32 (i)
}

fn loops () {
    cte assert (forever () == 0);
}
```

```text
Error[E4365] : the compile-time execution exceeds its limit of 100000 steps
 --> test_resources/cte_exec/test7.yr:(18,28)
18  ┃     cte assert (forever () == 0);
    ╋                            ^^
 --> test_resources/cte_exec/test7.yr:(8,9)
 8  ┃         if (i == 0us) break;
    ╋         --  note: here
    ┃
    = when validating test7::loops -- (test_resources/cte_exec/test7.yr:(17,4))
    ┗━━━━━━━
```

## How to fix it

Make sure the executed function terminates on the given arguments, or compute the
value at run time.

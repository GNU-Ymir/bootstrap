# E5009

> malformed bytecode, location table invalid

Raised during **lowering (YIL)**, from `SerializeYILErrorMessage::MALFORMED_BYTECODE_LOCATION_TABLE` (`src/ymirc/lint/serialize/errors.yr`).

## What it means

The location table of a `.yil` file could not be decoded. Source locations are
stored in a table so a diagnostic raised on an imported symbol can still point
at its source, and that table is invalid.

## How to fix it

Recompile the package that produced the file, cf. [E5005](E5005.md).

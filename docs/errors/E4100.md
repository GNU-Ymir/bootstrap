# E4100

> infinite loop with always true test is not allowed, rather use a loop construct

Raised during **validation**, from `ValidateErrorMessage::INFINITE_LOOP` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A `while` loop has a condition that is always true. Written that way, the
condition suggests a test that does not exist.

## Example

`test_resources/control_flow/test3.yr`:

```ymir
fn main () {
    let a = [1, 2, 3];
    if let [x, y, z] = a { // error, len of /a/ is /cte/
        x;
        y;
        z;
    }

    if (a.len <= 3) {
    }

    if (a.len >= 4) {
    }
    
    while a.len <= 3 {
    }

    while a.len >= 4 {
    }

}
```

```text
Error[E4100] : infinite loop with always true test is not allowed, rather use a loop construct
 --> test_resources/control_flow/test3.yr:(15,17)
15  ┃     while a.len <= 3 {
    ╋                 ^^
    ┗━━━━━━━
```

## How to fix it

Use `loop`, which says the loop is infinite on purpose.

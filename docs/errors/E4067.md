# E4067

> decorators are forbidden for index iterator, on <> iteration

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::FORBID_DECO_FOR_LOOP` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A decorator was written on the index variable of a `for` loop. The index is
produced by the loop itself, so its mutability is not the loop body's to
choose.

## Example

`test_resources/for_loops/arrays/test12.yr`:

```ymir
fn main () {
    let a = [1, 2, 3];
    for mut i, _ in a {
        i;
    }
}
```

```text
Error[E4067] : decorators are forbidden for index iterator, on [i32] iteration
 --> test_resources/for_loops/arrays/test12.yr:(3,9)
 3  ┃     for mut i, _ in a {
    ╋         ^^^ ^
    ┗━━━━━━━
```

## How to fix it

Remove the decorator. Copy the index into a local variable if a mutable one is
needed.

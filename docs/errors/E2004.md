# E2004

> scope guard <> is declared multiple times

where `<>` stands for a value the diagnostic fills in.

Raised during **parsing**, from `SyntaxErrorMessage::MULTIPLE_SAME_GUARD` (`src/ymirc/syntax/errors.yr`).

## What it means

The same kind of scope guard was declared twice in one block. A block has at
most one `exit`, one `success` and one `failure` guard.

## Example

`test_resources/diagnostics/test2.yr`:

```ymir
fn main () {
    {
    } exit {
    } exit {
    }
}
```

```text
Error[E2004] : scope guard exit is declared multiple times
 --> test_resources/diagnostics/test2.yr:(3,7)
 3  ┃     } exit {
    ╋       ^^^^
   ...
 --> test_resources/diagnostics/test2.yr:(4,7)
 4  ┃     } exit {
    ╋       ^^^^
    ┗━━━━━━━
```

## How to fix it

Merge the two bodies into a single guard. Two guards of the same kind would
have no defined order between them, which is why the second is rejected rather
than chained.

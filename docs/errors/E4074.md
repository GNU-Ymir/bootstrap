# E4074

> cannot create a function pointer, it would enclose the record by reference

Raised during **validation**, from `ValidateErrorMessage::FUNCTION_TO_FPTR_RECORD` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A function pointer would capture a record by reference, which would outlive the
record.

## Example

`test_resources/diagnostics/test104.yr`:

```ymir
// a function pointer made from the method of a record, outside a copy
record Counter {
    pub self () {}
    pub fn get (self)-> i32 { 1 }
}

fn main () {
    let c = Counter ();
    let _ = &c.get;
}
```

```text
Error[E4074] : cannot create a function pointer, it would enclose the record by reference
 --> test_resources/diagnostics/test104.yr:(9,13)
 9  ┃     let _ = &c.get;
    ╋             ^  note: did you mean to enclose it within a copy?
    ┃
    = when validating test104::main -- (test_resources/diagnostics/test104.yr:(7,4))
    ┗━━━━━━━
```

## How to fix it

Capture a copy of the record, or pass it as a parameter.

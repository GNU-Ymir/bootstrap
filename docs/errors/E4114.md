# E4114

> main function cannot be inline

Raised during **validation**, from `ValidateErrorMessage::MAIN_INLINE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

The `main` function is marked `inline`. It is the entry point the runtime
calls, so it has to exist as a symbol.

## Example

`test_resources/diagnostics/test49.yr`:

```ymir
@inline
fn main () {}
```

```text
Error[E4114] : main function cannot be inline
 --> test_resources/diagnostics/test49.yr:(1,2)
 1  ┃ @inline
    ╋  ^^^^^^
    ┗━━━━━━━
```

## How to fix it

Remove `inline`.

# E4299

> yield in expects a generator, not a value of type <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::YIELD_IN_NO_GENERATOR` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

`yield in g` yields every value of the generator `g`, until it is over. The value
after `in` must therefore be a generator handle, of type `yield-> T`; any other
value, even an iterable one, has no values to hand over this way.

## Example

`test_resources/generators/test43.yr`:

```ymir
// yield in only yields the values of a generator
yield all (a: [i32])-> i32 {
    yield in a;
}

fn main () {
    for x in all (copy [1, 2]) {
        x;
    }
}
```

```text
Error[E4299] : yield in expects a generator, not a value of type [i32]
 --> test_resources/generators/test43.yr:(3,14)
 3  ┃     yield in a;
    ╋              ^
    ┃
    = when validating test43::all -- (test_resources/generators/test43.yr:(2,7))
    ┗━━━━━━━
```

## How to fix it

Yield the values one at a time with a loop, `for x in a { yield x; }`, or pass
a generator producing them to `yield in`.

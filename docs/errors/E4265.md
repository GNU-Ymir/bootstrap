# E4265

> unterminated interpolation, missing closing }

Raised during **validation**, from `ValidateErrorMessage::UNTERMINATED_FORMAT_EMBED` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A string interpolation was opened with `${` and never closed.

## Example

`test_resources/format_string/test5.yr`:

```ymir
in test5;

fn main () {
    let str = f"unterminated ${1 + 2";
    str;
}
```

```text
Error[E4265] : unterminated interpolation, missing closing }
 --> test_resources/format_string/test5.yr:(4,30)
 4  ┃     let str = f"unterminated ${1 + 2";
    ╋                              ^^
    ┗━━━━━━━
```

## How to fix it

Add the closing brace.

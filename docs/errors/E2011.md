# E2011

> <> cannot be used as an identifier

where `<>` stands for a value the diagnostic fills in.

Raised during **parsing**, from `SyntaxErrorMessage::USED_AS_IDENTIFIER` (`src/ymirc/syntax/errors.yr`).

## What it means

The token reported cannot serve as an identifier where the grammar asked for a
name -- typically a keyword, or a literal.

## How to fix it

Choose another name. A name that has to collide with a keyword can be written
between backquotes, cf. [E1015](E1015.md).

# E4167

> no copy exists for type <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::NO_COPY_EXIST` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

`copy` was applied to a type that defines no copy.

## Example

`test_resources/diagnostics/test115.yr`:

```ymir
// a copy of a value that holds nothing to copy
fn main () {
    let _ = copy 1;
}
```

```text
Error[E4167] : no copy exists for type i32
 --> test_resources/diagnostics/test115.yr:(3,13)
 3  ┃     let _ = copy 1;
    ╋             ^^^^
    ┃
    = when validating test115::main -- (test_resources/diagnostics/test115.yr:(2,4))
    ┗━━━━━━━
```

## How to fix it

Define the copy operation on the type, or pass the value without copying if a
borrow is enough.

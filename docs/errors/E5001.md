# E5001

> failed to create YIL output directory <>, permission denied

where `<>` stands for a value the diagnostic fills in.

Raised during **lowering (YIL)**, from `SerializeYILErrorMessage::FAILED_TO_CREATE_OUT_DIR` (`src/ymirc/lint/serialize/errors.yr`).

## What it means

The compiler could not create the directory it was told to write the YIL
bytecode of the compiled package into. The path is reported in the message.

## How to fix it

Check that the parent directory exists and is writable, and that the path
given to the YIL output option is the one intended.

# E4272

> expression produces a value of type <>, but is used as a type

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::USE_AS_TYPE_VAL` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

An expression produces a value of the reported type where a type is expected,
cf. [E4270](E4270.md).

## Example

`test_resources/diagnostics/test126.yr`:

```ymir
// a function name used as a type
fn nothing () {}

fn main () {
    let _x_ : nothing = 1;
}
```

```text
Error[E4272] : expression produces a value of type test126::nothing, but is used as a type
 --> test_resources/diagnostics/test126.yr:(5,15)
 5  ┃     let _x_ : nothing = 1;
    ╋               ^^^^^^^
    ┃
    = when validating test126::main -- (test_resources/diagnostics/test126.yr:(4,4))
    ┗━━━━━━━
```

## How to fix it

Write the type itself.

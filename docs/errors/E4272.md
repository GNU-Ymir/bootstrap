# E4272

> expression produces a value of type <>, but is used as a type

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::USE_AS_TYPE_VAL` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

An expression produces a value of the reported type where a type is expected,
cf. [E4270](E4270.md).

## How to fix it

Write the type itself.

# E4160

> <> is not a slice type

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::NOT_A_SLICE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

An operation defined only on slices was applied to something else. A static
array is not a slice: its length is part of its type.

## How to fix it

Use a slice, or take one from the array with a full range index.

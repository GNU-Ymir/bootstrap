# E4340

> <> is used before its prototype is validated

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::PROTO_CYCLE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

Using a function, a call of it as well as its name alone, needs its prototype:
the types of its parameters, their default values, the type it returns and the
ones it throws. Anything this prototype needs cannot use the function itself,
directly or through another function whose prototype uses it, nor the
specialization of a template being validated.

## Example

`test_resources/function/test33.yr`:

```ymir
// the return type of a function cannot be computed from a call of the function itself

fn foo (x: i32)-> typeof (foo (x)) { x }

fn main () {
    let _x_ = foo (1);
}
```

```text
Error[E4340] : test33::foo is used before its prototype is validated
 --> test_resources/function/test33.yr:(3,27)
 3  ┃ fn foo (x: i32)-> typeof (foo (x)) { x }
    ╋    ---                    ^^^  note: defined here
    ┃
    = when validating test33::foo -- (test_resources/function/test33.yr:(3,4))
    ┗━━━━━━━
```

## How to fix it

Write the types of the prototype instead of computing them from a call of the
function. Its body is validated once its prototype is, so it can call it.

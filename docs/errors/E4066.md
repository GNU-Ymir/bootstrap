# E4066

> field method cannot have more than one parameter

Raised during **validation**, from `ValidateErrorMessage::FIELD_METHOD_PARAMS` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A field method declares more than one parameter besides `self`. A field access
method takes none and a field assign method takes exactly the value being
assigned.

## How to fix it

Reduce the parameter list. A method genuinely needing several arguments is an
ordinary method, not a field one.

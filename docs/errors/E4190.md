# E4190

> field method <> cannot override the non field method <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::OVERRIDE_NO_FIELD_BY_FIELD` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A field method tries to override an ordinary method, cf.
[E4182](E4182.md).

## How to fix it

Declare the overriding method as an ordinary method.

# E4190

> field method <> cannot override the non field method <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::OVERRIDE_NO_FIELD_BY_FIELD` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A field method tries to override an ordinary method, cf.
[E4182](E4182.md).

## Example

`test_resources/diagnostics/test121.yr`:

```ymir
// a field method overriding a method that is not one
class Base {
    pub self () {}
    pub fn size (self)-> i32 { 1 }
}

class Derived over Base {
    pub self () with super () {}

    @field
    pub over size (self)-> i32 { 2 }
}

fn main () {
    let _ = copy Derived ();
}
```

## How to fix it

Declare the overriding method as an ordinary method.

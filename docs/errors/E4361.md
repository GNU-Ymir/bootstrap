# E4361

> the function has no parameter named <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::PARAMETER_UNKNOWN` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

`__pragma!parameter_type (F, name)` selects the parameter whose name is `name`.
None of the parameters of the function has it; the note lists the names it does
have. The parameters of a function pointer or of a delegate have no name at all, so
they can only be selected by index.

## Example

`test_resources/pragma/test29.yr`:

```ymir
fn foo (x: i32, y: [c8])-> i32 {
    x + cast!i32 (y.len)
}

fn main () {
    let _c_: __pragma!parameter_type (foo, "z") = 1;
}
```

```text
Error[E4361] : the function has no parameter named z
 --> test_resources/pragma/test29.yr:(16,44)
16  ┃     let _c_: __pragma!parameter_type (foo, "z") = 1;
    ╋                                            ^  note: its parameters are x, y
    ┃
    = when validating test29::main -- (test_resources/pragma/test29.yr:(13,4))
    ┗━━━━━━━
```

## How to fix it

Correct the name, or select the parameter by its index.

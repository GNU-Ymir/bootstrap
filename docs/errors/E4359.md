# E4359

> <> is neither a function nor a callable type

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::NOT_A_FUNCTION` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

The function reflection pragmas take a function symbol (a function, a generator,
an async, a method reached through a delegate, a pointer to one of them) or a value
or a type that can be called: a function pointer or a delegate, through an enum of
them. Anything else has no parameters and no return type.

## Example

`test_resources/pragma/test30.yr`:

```ymir
class A {
    pub self () {}
}

fn main () {
    let _d_: __pragma!return_type (A) = 1;
}
```

```text
Error[E4359] : test30::A is neither a function nor a callable type
 --> test_resources/pragma/test30.yr:(22,36)
22  ┃     let _d_: __pragma!return_type (A) = 1;
    ╋                                    ^
    ┃
    = when validating test30::main -- (test_resources/pragma/test30.yr:(18,4))
    ┗━━━━━━━
```

## How to fix it

Guard the use with `__pragma!is_function`, which is false instead of failing, for
instance in the test of a template: `fn if (__pragma!is_function (F)) foo {F} ...`.

# E4195

> the index operator on <> with a dynamic operand of type <> is allowed only in the context of a copy statement

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::RANGE_ON_ARRAY_NO_COPY` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A range index whose bounds are not known at compile time was applied outside a
copy. Such an index produces a new value rather than a view, which only the copy
context accepts.

## Example

`test_resources/diagnostics/test122.yr`:

```ymir
// a range index with a runtime bound on a static array, outside a copy
fn main () {
    let a = [1, 2, 3];
    let mut i = 0us;
    i = 1us;
    let _ = a [i .. 2us];
}
```

```text
Error[E4195] : the index operator on [i32 ; 3us] with a dynamic operand of type (..usize) is allowed only in the context of a copy statement
 --> test_resources/diagnostics/test122.yr:(6,15)
 6  ┃     let _ = a [i .. 2us];
    ╋               ^  error: value of type (..usize) is needed but unknown at compilation time
    ┃
    = when validating test122::main -- (test_resources/diagnostics/test122.yr:(2,4))
    ┗━━━━━━━
```

## How to fix it

Enclose the index in a `copy`, or use bounds the compiler can compute.

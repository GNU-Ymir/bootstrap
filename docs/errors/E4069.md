# E4069

> the type cannot be validated due to forward reference

Raised during **validation**, from `ValidateErrorMessage::FORWARD_REFERENCE_TYPE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A type refers to itself, or to a type still being validated, through a path the
compiler must resolve first.

## Example

`test_resources/diagnostics/test135.yr`:

```ymir
// two globals whose types depend on each other
lazy X : i32 = Y;
lazy Y : i32 = X;

fn main () {
    let _ = X;
}
```

```text
Error[E4069] : the type cannot be validated due to forward reference
 --> test_resources/diagnostics/test135.yr:(2,6)
 2  ┃ lazy X : i32 = Y;
    ╋      ^
    ┃
    = when validating test135::Y -- (test_resources/diagnostics/test135.yr:(3,6))
    = when validating test135::X -- (test_resources/diagnostics/test135.yr:(2,6))
    ┗━━━━━━━
```

## How to fix it

Break the cycle by holding the self-reference behind a class or a pointer, cf.
[E4017](E4017.md).

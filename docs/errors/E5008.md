# E5008

> malformed bytecode, symbol table invalid

Raised during **lowering (YIL)**, from `SerializeYILErrorMessage::MALFORMED_BYTECODE_SYMBOL_TABLE` (`src/ymirc/lint/serialize/errors.yr`).

## What it means

The symbol table of a `.yil` file could not be decoded: the frames, globals and
constants the module exports are listed in a table that is invalid.

## How to fix it

Recompile the package that produced the file, cf. [E5005](E5005.md).

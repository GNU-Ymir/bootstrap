# E4262

> call of unsafe function outside unsafe context

Raised during **validation**, from `ValidateErrorMessage::UNSAFE_CALL` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

An unsafe function was called outside an `unsafe` context. Calling it is
allowed, but the call has to say so.

## How to fix it

Wrap the call in an `unsafe` block, or mark the calling function unsafe
too.

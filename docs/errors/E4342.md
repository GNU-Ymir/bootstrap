# E4342

> an async cannot yield, it completes with a single value

Raised during **validation**, from `ValidateErrorMessage::YIELD_IN_ASYNC` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A function is either a generator or an async. An async completes once, with
the value it returns, where a generator yields a sequence of values.

## Example

`test_resources/async/test16.yr`:

```ymir
// A function is either a generator or an async: an async cannot yield.

async count (n: i32)-> i32 {
    yield n;
    n
}
```

```text
Error[E4342] : an async cannot yield, it completes with a single value
 --> test_resources/async/test16.yr:(4,5)
 4  ┃     yield n;
    ╋     ^^^^^
    ┃
    = when validating test16::count -- (test_resources/async/test16.yr:(3,7))
    ┗━━━━━━━
```

## How to fix it

Return the value from the async, or declare the function with `yield` to make
it a generator.

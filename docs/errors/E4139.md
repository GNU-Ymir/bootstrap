# E4139

> a lambda variable cannot be mutable

Raised during **validation**, from `ValidateErrorMessage::MUTABLE_LAMBDA_VAR` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A lambda variable is declared mutable. The lambda is the value; reassigning the
variable would not change the function anywhere it was already passed.

## How to fix it

Drop the `mut`.

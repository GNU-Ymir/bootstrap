# E4139

> a lambda variable cannot be mutable

**Retired.** The message this code named was deleted from the compiler: no
source could reach it. A lambda value cannot be matched: it raises [E4275](E4275.md) before its binding is checked.

The code is not reused and not reassigned to another diagnostic, so an E4139
printed by an older compiler still means what is quoted above. This page stays
as its record.

It was raised during **validation**, from `ValidateErrorMessage::MUTABLE_LAMBDA_VAR`.

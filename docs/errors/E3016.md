# E3016

> <> is private in this context

where `<>` stands for a value the diagnostic fills in.

Raised during **declaration**, from `DeclareErrorMessage::PRIVATE_IN_THIS_CONTEXT` (`src/ymirc/semantic/declarator/errors.yr`).

## What it means

The symbol exists but its protection does not let this module see it.

## Example

`test_resources/data_record/fields/test2.yr`:

```ymir
@data
record Foo {
    let x: i32;
    prv let _y: i32 = 8;
}

fn main() {
    let a = Foo(1);
    a._y;
}
```

```text
Error[E3016] : _y is private in this context
 --> test_resources/data_record/fields/test2.yr:(9,7)
 9  ┃     a._y;
    ╋       ^^  note: class test2::Foo has no field access method named _y
    ┃        ┗━ note: class test2::Foo has no method named _y
    ┃ Note : declared here
    ┃  --> test_resources/data_record/fields/test2.yr:(4,13)
    ┃  4  ┃     prv let _y: i32 = 8;
    ┃     ╋             ^^
    ┃     ┗━━━━━━━
    ┗━━━━━┻━
```

## How to fix it

Import it from a module that may see it, or widen its protection at the
definition. Inside a package, `prot` (protected) makes a symbol visible to the
package without exporting it.

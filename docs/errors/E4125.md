# E4125

> cannot alias an expand value, maybe alias and expand keywords are inverted?

Raised during **validation**, from `ValidateErrorMessage::MISMATCH_ALIAS_EXPAND` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

`alias` was applied to an `expand` value. The two keywords are in the order that
aliases the expansion rather than expanding the alias, which is almost never
what is meant.

## Example

`test_resources/diagnostics/test138.yr`:

```ymir
// alias and expand written the wrong way round
fn take (dmut _ : [i32], _ : [i32]) {}

fn main () {
    let mut z : (mut [mut i32], [i32]) = alias (copy [1, 2], copy [3, 4]);
    take (alias expand z);
}
```

```text
Error[E4125] : cannot alias an expand value, maybe alias and expand keywords are inverted?
 --> test_resources/diagnostics/test138.yr:(6,11)
 6  ┃     take (alias expand z);
    ╋           ^^^^^ ------
    ┃
    = help: invert the two keywords
    ┃
 6  -     take (alias expand z);
 6  +     take (expand alias z);
    ┃
    = when validating test138::main -- (test_resources/diagnostics/test138.yr:(4,4))
    ┗━━━━━━━
```

## How to fix it

Swap them: `expand alias v`.

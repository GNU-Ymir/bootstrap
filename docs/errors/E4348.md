# E4348

> the method poll of an awaited class must return an option, not a value of type <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::AWAIT_POLL_NOT_OPTION` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

The method `poll` of an awaited class tells whether the await can complete
through the option it returns: an option with a value completes it, an empty
one means it is still pending. A method returning anything else cannot say
that it is pending. It is reported under [E4347](E4347.md).

## Example

`test_resources/async/test45.yr`:

```ymir
// The method poll of an awaited class returns an option, empty while it is pending.

class NoOption {
    pub self () {}

    pub fn poll (self, waker: dg ()-> void)-> i32 {
        waker ();
        1
    }
}

async outer ()-> i32 {
    await copy NoOption ()
}
```

## How to fix it

Return `U?`: `(value)?` once the value is ready, `none` while it is pending,
having arranged for the waker to be called.

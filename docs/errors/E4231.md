# E4231

> the index operator is not defined for type <> and <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::UNDEFINED_INDEX_OP` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

The index operator is not defined between the indexed type and the index type.
Both are in the message.

## Example

`test_resources/aka/test2.yr`:

```ymir
def A : dmut [i32];

fn main ()
{
    let dmut x : A = copy [1, 2, 3];
    x [0] = 1;
}
```

```text
Error[E4231] : the index operator is not defined for type error and {i32}
 --> test_resources/aka/test2.yr:(6,7)
 6  ┃     x [0] = 1;
    ╋       ^
    ┗━━━━━━━
```

## How to fix it

Index with the type the operation expects, or define the index operator on the
type.

# E1003

> line break encountered inside a single-line comment

Raised during **lexing**, from `LexingErrorMessage::RETURN_IN_SINGLE_LINE_COMMENT` (`src/ymirc/lexing/errors.yr`).

## What it means

A single-line comment (`//`) was still open when the line ended in a way the
lexer could not accept -- the comment ran into a line break it was told to treat
as part of the comment, which a single-line comment cannot contain.

## How to fix it

Use a block comment (`/* ... */`) for text that spans several lines, or start
each line with its own `//`.

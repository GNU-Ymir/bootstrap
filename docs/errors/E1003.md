# E1003

> line break encountered inside a single-line comment

**Retired.** The message this code named was deleted from the compiler: no
source could reach it. A single-line comment ends at the first line break, so it can never contain one.

The code is not reused and not reassigned to another diagnostic, so an E1003
printed by an older compiler still means what is quoted above. This page stays
as its record.

It was raised during **lexing**, from `LexingErrorMessage::RETURN_IN_SINGLE_LINE_COMMENT`.

# E4021

> class type expected, not the class object instance type <> (i.e. the & is useless)

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::CLASS_THROW_PTR` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A class *type* was expected and the class *instance* type was given -- the `&`
that turns a class into an instance reference is one level too many here.

## Example

`test_resources/aka/test15.yr`:

```ymir
class A {
    pub self () {}
}

def B : &A;
```

```text
Error[E4021] : class type expected, not the class object instance type &(test15::A) (i.e. the & is useless)
 --> test_resources/aka/test15.yr:(5,9)
 5  ┃ def B : &A;
    ╋         ^
    ┗━━━━━━━
```

## How to fix it

Remove the `&`.

# E2008

> unexpected attribute list <>

where `<>` stands for a value the diagnostic fills in.

Raised during **parsing**, from `SyntaxErrorMessage::UNEXPECTED_ATTRIBUTES` (`src/ymirc/syntax/errors.yr`).

## What it means

An attribute list was written on a declaration that does not take one.

## Example

`test_resources/diagnostics/test3.yr`:

```ymir
class Foo {
    @final let x: i32;
    pub self (x: i32) with x = x {}
}

fn main () {}
```

```text
Error[E2008] : unexpected attribute list {final}
 --> test_resources/diagnostics/test3.yr:(2,5)
 2  ┃     @final let x: i32;
    ╋     ^
    ┃ Note :
    ┃  --> test_resources/diagnostics/test3.yr:(2,12)
    ┃  2  ┃     @final let x: i32;
    ┃     ╋            ^^^
    ┃     ┗━━━━━━━
    ┗━━━━━┻━
```

## How to fix it

Remove the list, or move it onto the declaration it was meant for. Attribute
lists apply to declarations, not to the statements inside them.

# E4014

> class alias operator :. is not usable to access fields

Raised during **validation**, from `ValidateErrorMessage::CLASS_ALIAS_FIELD` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

The class alias operator `:.` was used to access a field. That operator
produces a borrowed view for calling a method; a field access takes its
mutability from the value itself, so the operator has nothing to do.

## Example

`test_resources/diagnostics/test98.yr`:

```ymir
// the alias operator used to read a field of a map
fn main () {
    let mut m = copy [1 => 2];
    let _ = m:.len;
}
```

```text
Error[E4014] : class alias operator :. is not usable to access fields
 --> test_resources/diagnostics/test98.yr:(4,14)
 4  ┃     let _ = m:.len;
    ╋              ^^---
    ┃
    = when validating test98::main -- (test_resources/diagnostics/test98.yr:(2,4))
    ┗━━━━━━━
```

## How to fix it

Use a plain `.` to access the field.

# E3013

> module should be located in <> or <>, but no such file exists or access is denied

where `<>` stands for a value the diagnostic fills in.

Raised during **declaration**, from `DeclareErrorMessage::NO_SUCH_FILE` (`src/ymirc/semantic/declarator/errors.yr`).

## What it means

A module was imported but no file defines it. The compiler reports both file
paths it would have accepted -- the directory form and the plain file form.

## How to fix it

Create the file at one of the two reported paths, or fix the import. An
existing file at one of them points at a permission problem instead.

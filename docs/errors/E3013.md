# E3013

> module should be located in <> or <>, but no such file exists or access is denied

**Retired.** The message this code named was deleted from the compiler: a `mod`
declaration names the one file it imports, through its root (`::` for a child,
`.` for a sibling), and a missing file gives [E3014](E3014.md) with that one
path. A `mod` without a root is refused with [E2019](E2019.md).

The code is not reused and not reassigned to another diagnostic, so an E3013
printed by an older compiler still means what is quoted above. This page stays
as its record.

It was raised during **declaration**, from `DeclareErrorMessage::NO_SUCH_FILE`.

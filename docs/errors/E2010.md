# E2010

> unterminated block

Raised during **parsing**, from `SyntaxErrorMessage::UNTERMINATED_BLOCK` (`src/ymirc/syntax/errors.yr`).

## What it means

A block was opened and the parser reached a point where it can no longer be
closed.

## How to fix it

Close the block, cf. [E2001](E2001.md).

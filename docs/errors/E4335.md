# E4335

> an apply overload is a template, whose first parameter receives the tagged symbol

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::TAG_APPLY_NOT_TEMPLATE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

An `apply` overload of a tag is instantiated for each declaration the tag is
put on, its first template parameter receiving that declaration: the original
function `F` in `fn apply {F: fn (T)-> R, T...}`, the class `C` in
`class apply {class C}`. An overload that is not a template cannot receive it.

The overload is reported where the tag is declared, and as a candidate of
[E4332](E4332.md) on a tag site it is the only overload of.

## Example

`test_resources/tag/test31.yr`:

```ymir
// an apply overload is a template receiving the tagged symbol

tag a {
    pub fn apply ()-> i32 { 1 }
}

#[a]
fn foo () {}

fn main () {}
```

## How to fix it

Make the overload a template whose first parameter receives the tagged
declaration, or move it out of the tag if it is a helper.

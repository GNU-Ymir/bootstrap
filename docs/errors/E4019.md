# E4019

> class <> has no field named <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::CLASS_NO_FIELD` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A field name was used on a class that has no field of that name.

## Example

`test_resources/lit_class/ctors/test24.yr`:

```ymir
class A {
    let x : i32;
    let y : i32;

    pub self ()
        with x = 9
        , y = self.z
    {}
}
```

```text
Error[E4019] : class &(test24::A)::fields has no field named z
 --> test_resources/lit_class/ctors/test24.yr:(7,20)
 7  ┃         , y = self.z
    ╋                    ^
    ┗━━━━━━━
```

## How to fix it

Check the spelling. A field that exists but is not visible from here gives a
protection error instead, so this really means no such field. A field method of
that name is reached the same way, so check that it is declared too.

# E4062

> field assign method must be mutable

Raised during **validation**, from `ValidateErrorMessage::FIELD_METHOD_ASSIGN_CONST` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A field assign method is declared constant. It stands in for writing a field,
which modifies the instance.

## Example

`test_resources/diagnostics/test35.yr`:

```ymir
class Foo {
    let mut x: i32 = 0;
    pub self () {}
    @field pub fn bar (self, v: i32) { self.x = v; }
}

fn main () { let dmut f = copy Foo (); f:.bar = 1; }
```

## How to fix it

Declare `self` mutable on the method.

# E1008

> escape character found at end of comment block

Raised during **lexing**, from `LexingErrorMessage::ESCAPE_AT_END_OF_COMMENT` (`src/ymirc/lexing/errors.yr`).

## What it means

The comment block ends on a backslash, so the escape sequence it starts has
nothing to escape.

## Example

`test_resources/lexing/test18.yr`:

```ymir
/* abc\
```

```text
Error[E1008] : escape character found at end of comment block
 --> main.yr:(1,1)
 1  ┃ /* abc\
    ╋ ^^    ^
    ┗━━━━━━━
```

## How to fix it

Remove the trailing backslash, or double it if a literal backslash is wanted.

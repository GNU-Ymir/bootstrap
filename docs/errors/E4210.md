# E4210

> cannot throw exception inside a scope guard

Raised during **validation**, from `ValidateErrorMessage::THROW_SCOPE_GUARD` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A `throw` inside a scope guard would escape the guard uncaught. A guard runs
while a scope is being left, so an exception leaving it would interrupt an
unwinding already in progress.

## Example

`test_resources/scope_guards/test10.yr`:

```ymir
fn main () {
    {

    } exit {
        throw copy AssertError ("");
    }
}
```

```text
Error[E4210] : cannot throw exception inside a scope guard
 --> test_resources/scope_guards/test10.yr:(4,7)
 4  ┃     } exit {
    ╋       ^^^^
   ...
 --> test_resources/scope_guards/test10.yr:(5,9)
 5  ┃         throw copy AssertError ("");
    ╋         ^^^^^
    ┗━━━━━━━
```

## How to fix it

Catch the exception inside the guard. A `throw` in a nested block whose own
`catch` handles every thrown type does not cross the guard and is accepted.

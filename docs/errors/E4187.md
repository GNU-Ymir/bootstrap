# E4187

> trait method <> was already overridden

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::OVERRIDE_MULTIPLE_TIMES_TRAIT` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A trait method is overridden twice, so two bodies claim the same slot.

## Example

`test_resources/diagnostics/test119.yr`:

```ymir
// a trait method overridden twice in the same impl block
trait Shape {
    pub fn area (self)-> i32;
}

class Square {
    pub self () {}

    impl Shape {
        pub over area (self)-> i32 { 1 }
        pub over area (self)-> i32 { 2 }
    }
}

fn main () {
    let _ = copy Square ();
}
```

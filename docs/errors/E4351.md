# E4351

> async <> cannot override the non async method <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::OVERRIDE_NO_ASYNC_BY_ASYNC` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

An async, declared by `over async`, tries to override an ordinary method, even
one returning the handle of an async, cf. [E4350](E4350.md).

## Example

`test_resources/async/test57.yr`:

```ymir
// An async cannot override a method returning the handle of an async.

async answer ()-> i32 {
    1
}

class A {
    pub self () {}

    pub fn f (self)-> (async-> i32) {
        answer ()
    }
}

class B over A {
    pub self () {}

    pub over async f (self)-> i32 {
        2
    }
}

fn main () {
    let _ = B ();
}
```

```text
Error[E4351] : async test57::B::f ()-> (async-> i32) cannot override the non async method test57::A::f ()-> (async-> i32)
 --> test_resources/async/test57.yr:(18,20)
18  ┃     pub over async f (self)-> i32 {
    ╋                    ^
 --> test_resources/async/test57.yr:(10,12)
10  ┃     pub fn f (self)-> (async-> i32) {
    ╋            -
    ┃
    = when validating test57::B -- (test_resources/async/test57.yr:(15,7))
    ┗━━━━━━━
```

## How to fix it

Declare the overriding method as an ordinary method, with `over`.

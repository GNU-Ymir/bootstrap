# E4042

> parameter with a default value must have a referenceable name

Raised during **validation**, from `ValidateErrorMessage::DEFAULT_VAR_NO_NAME` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A parameter has a default value but no name a caller could use. Default values
are only reachable by naming the parameter at the call site, so an unnamed
parameter could never take its default.

## Example

`test_resources/diagnostics/test27.yr`:

```ymir
fn foo (_: i32 = 0)-> i32 { 1 }

fn main () { foo (); }
```

## How to fix it

Give the parameter a name, or remove the default value.

# E4116

> core module is malformed

Raised during **validation**, from `ValidateErrorMessage::MALFORMED_CORE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

The `core` module does not have the shape the validator expects, cf.
[E3009](E3009.md).

## How to fix it

Check that the standard library matches the compiler version.

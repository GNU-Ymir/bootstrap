# E4090

> method <> implicitly overrides method <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::IMPLICIT_OVERRIDE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A method has the same signature as one of an ancestor class but is not marked
`override`. Ymir requires the marker so that adding a method to a base class
cannot silently change what a derived class does.

## How to fix it

Add `override` if overriding was intended, or rename the method if it was
meant to be a new one.

# E4057

> external global variable must be declared with a type

Raised during **validation**, from `ValidateErrorMessage::EXTERN_GLOBAL_NO_TYPE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

An `extern` global variable was declared without a type. Its definition lives
in another object file, so the compiler has no value to infer a type from.

## How to fix it

Write the type explicitly.

# E4057

> external global variable must be declared with a type

**Retired.** The message this code named was deleted from the compiler: no
source could reach it. The parser requires a value whenever the type is omitted, and an external global with a value raises [E4058](E4058.md) first.

The code is not reused and not reassigned to another diagnostic, so an E4057
printed by an older compiler still means what is quoted above. This page stays
as its record.

It was raised during **validation**, from `ValidateErrorMessage::EXTERN_GLOBAL_NO_TYPE`.

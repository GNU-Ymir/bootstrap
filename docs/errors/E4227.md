# E4227

> cannot cast value of type <> into a value of type <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::UNDEFINED_CAST_OP` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A `cast` was asked for between two types with no conversion between them.

## Example

`test_resources/char_type/test3.yr`:

```ymir
in test3;

fn main () {
    let a = 'a'c8;
    let b = 'b'c16;
    let c = 'c'c32;

    cast!u16 (a);
    cast!u8 (b);
    cast!u8 (c);
    cast!u32 (a);

    cast!c16 (12u8);
    cast!c32 (12u16);
    cast!c8 (12u32);
}
```

```text
Error[E4227] : cannot cast value of type c8 into a value of type u16
 --> test_resources/char_type/test3.yr:(8,5)
 8  ┃     cast!u16 (a);
    ╋     ^^^^
    ┗━━━━━━━
```

## How to fix it

Go through a type both convert to, or define the cast operator on the source
type.

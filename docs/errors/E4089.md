# E4089

> ref of type <> must be mutable, but is const

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::IMPLICIT_MUT_REFERENCE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A `ref` parameter is declared mutable and a constant value was passed.

## Example

`test_resources/for_loops/tuples/test5.yr`:

```ymir
fn main () {
    let dmut a = (copy [1, 2],);
    for ref mut x in a {
        x;
    }
}
```

```text
Error[E4089] : ref of type mut [mut i32] must be mutable, but is const
 --> test_resources/for_loops/tuples/test5.yr:(3,17)
 3  ┃     for ref mut x in a {
    ╋                 ^
    ┗━━━━━━━
```

## How to fix it

Pass a mutable value, or declare the parameter constant.

# E3030

> unexpected declaration inside an impl block

Raised during **declaration**, from `DeclareErrorMessage::UNEXPECTED_IN_IMPL` (`src/ymirc/semantic/declarator/errors.yr`).

## What it means

A declaration appeared inside an `impl` block that such a block does not
accept. An `impl` block provides the methods of a trait for a type.

## How to fix it

Move the declaration out of the block. A method that is not part of the trait
belongs in the type body rather than in the `impl`.

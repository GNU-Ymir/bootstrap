# E4013

> the pattern of a catch scope guard must start with a variable declaration or a field deconstructor

Raised during **validation**, from `ValidateErrorMessage::CATCH_PATTERN_MULT_OR_VDECL` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

The pattern of a `catch` does not start with a variable declaration or a field
deconstructor. A catch pattern has to bind the exception before it can test
anything about it.

## How to fix it

Start the pattern with a binding, as in `err: &SomeException => { ... }`.

# E4189

> method <> overrides nothing

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::OVERRIDE_NOTHING` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A method is marked `override` and no ancestor method matches it, cf.
[E3011](E3011.md).

## Example

`test_resources/diagnostics/test68.yr`:

```ymir
class A {
    pub self () {}
    pub over foo (self) {}
}

fn main () { let _ = copy A (); }
```

```text
Error[E4189] : method test68::A::foo overrides nothing
 --> test_resources/diagnostics/test68.yr:(3,14)
 3  ┃     pub over foo (self) {}
    ╋              ^^^
    ┃
    = when validating -- (test_resources/diagnostics/test68.yr:(1,7))
    ┗━━━━━━━
Error[E4104] : symbol test68::A has errors
 --> test_resources/diagnostics/test68.yr:(6,27)
 6  ┃ fn main () { let _ = copy A (); }
    ╋                           ^
 --> test_resources/diagnostics/test68.yr:(3,14)
 3  ┃     pub over foo (self) {}
    ╋              ---  error: method test68::A::foo overrides nothing
    ┃
    = when validating -- (test_resources/diagnostics/test68.yr:(1,7))
    = when validating test68::main -- (test_resources/diagnostics/test68.yr:(6,4))
    ┗━━━━━━━
```

## How to fix it

Compare the signature with the ancestor method, or drop `override`.

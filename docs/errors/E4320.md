# E4320

> generator <> cannot override the non generator method <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::OVERRIDE_NO_GENERATOR_BY_GENERATOR` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A generator, declared by `over yield`, tries to override an ordinary method, even
one returning the handle of a generator, cf. [E4319](E4319.md).

## Example

`test_resources/generators/test86.yr`:

```ymir
// a generator cannot override a method returning the handle of a generator
yield gen ()-> i32 {
    yield 1;
}

class A {
    pub self () {}

    pub fn f (self)-> (yield-> i32) {
        gen ()
    }
}

class B over A {
    pub self () {}

    pub over yield f (self)-> i32 {
        yield 2;
    }
}

fn main () {
    let _ = B ();
}
```

## How to fix it

Declare the overriding method as an ordinary method, with `over`.

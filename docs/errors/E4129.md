# E4129

> cannot copy an expand value, maybe dcopy and expand keywords are inverted?

Raised during **validation**, from `ValidateErrorMessage::MISMATCH_DCOPY_EXPAND` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

`dcopy` was applied to an `expand` value; the keywords are inverted.

## Example

`test_resources/diagnostics/test140.yr`:

```ymir
// dcopy and expand written the wrong way round
fn take (_ : i32, _ : i32) {}

fn main () {
    let x = [1, 2];
    take (dcopy expand x);
}
```

```text
Error[E4129] : cannot copy an expand value, maybe dcopy and expand keywords are inverted?
 --> test_resources/diagnostics/test140.yr:(6,11)
 6  ┃     take (dcopy expand x);
    ╋           ^^^^^ ------
    ┃
    = help: invert the two keywords
    ┃
 6  -     take (dcopy expand x);
 6  +     take (expand dcopy x);
    ┃
    = when validating test140::main -- (test_resources/diagnostics/test140.yr:(4,4))
    ┗━━━━━━━
```

## How to fix it

Swap them: `expand dcopy v`.

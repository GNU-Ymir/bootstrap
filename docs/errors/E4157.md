# E4157

> value of type <> is not a lvalue

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::NOT_A_LVALUE_TYPE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A value of this type never has storage of its own -- a temporary, or the result
of an expression.

## Example

`test_resources/function/test2.yr`:

```ymir
fn foo (mut x : [mut i32]);

fn main () {
    let a = copy [1];
    foo (alias a);
}
```

```text
Error[E4157] : value of type [i32] is not a lvalue
 --> test_resources/function/test2.yr:(5,10)
 5  ┃     foo (alias a);
    ╋          ^^^^^ ^
    ┗━━━━━━━
```

## How to fix it

Bind it to a variable and use that, cf. [E4151](E4151.md).

# E4083

> type must be immutable

Raised during **validation**, from `ValidateErrorMessage::IMMUTABLE_PARENT` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A type used in this position has to be immutable and is not -- typically the
aliased type of a `def`, or a type used where sharing requires immutability.

## Example

`test_resources/aka/test2.yr`:

```ymir
def A : dmut [i32];

fn main ()
{
    let dmut x : A = copy [1, 2, 3];
    x [0] = 1;
}
```

```text
Error[E4083] : type must be immutable
 --> test_resources/aka/test2.yr:(1,9)
 1  ┃ def A : dmut [i32];
    ╋         ^^^^
    ┗━━━━━━━
```

## How to fix it

Remove the mutability decorator from the type.

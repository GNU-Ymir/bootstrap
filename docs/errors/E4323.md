# E4323

> a part of <> cannot be affected from a value of type <>, an array or a slice was expected

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::PART_AFFECT_TYPE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A part of an array or a slice -- a range `a [x .. y]` or several indices
`a [i, j]` -- is affected element by element from an array or a slice of the
same length. Any other value is rejected, a single value is not repeated over
the part.

## Example

`test_resources/index_ops/test16.yr`:

```ymir
fn main () {
    let dmut a = [1, 2, 3];
    a [0 .. 2] = 1;
}
```

```text
Error[E4323] : a part of mut [mut i32 ; 3us] cannot be affected from a value of type i32, an array or a slice was expected
 --> test_resources/index_ops/test16.yr:(5,7)
 5  ┃     a [0 .. 2] = 1;
    ╋       ^          -
    ┗━━━━━━━
```

## How to fix it

Affect an array or a slice holding one value per element of the part, or
affect the elements one by one.

# E1016

> binary number is empty

Raised during **lexing**, from `LexingErrorMessage::EMPTY_BIN_NUMBER` (`src/ymirc/lexing/errors.yr`).

## What it means

A `0b` prefix is not followed by any binary digit, so the literal has no
value.

## Example

`test_resources/lexing/test20.yr`:

```ymir
let x = 0b_;
```

```text
Error[E1016] : binary number is empty
 --> main.yr:(1,9)
 1  ┃ let x = 0b_;
    ╋         ^^^
    ┗━━━━━━━
```

## How to fix it

Write the digits after the prefix, or remove the prefix if a plain `0` was
meant.

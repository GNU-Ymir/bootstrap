# E4105

> <> is a method and must be called from an instance

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::IS_A_METHOD` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A method was used as if it were a free function. A method needs the instance it
runs on.

## Example

`test_resources/lit_class/errors/test1.yr`:

```ymir


class A {
    pub self () {}

    pub fn bar (self) {}
    pub fn foo (self) {
        bar ();
    }
}
```


## How to fix it

Call it on an instance (`x.m ()`), or take a delegate with `&x.m` if the call
is to happen later.

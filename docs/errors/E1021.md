# E1021

> missing the exponent part in a floating-point number formatted in hexadecimal

Raised during **lexing**, from `LexingErrorMessage::MISSING_P_IN_HEX_FLOAT` (`src/ymirc/lexing/errors.yr`).

## What it means

A hexadecimal literal contains a decimal point, which makes it a floating-point
literal, but it has no `p` exponent part. A hexadecimal float always carries its
binary exponent explicitly.

## Example

`test_resources/lexing/test29.yr`:

```ymir
let x = 0x1.8;
```

```text
Error[E1021] : missing the exponent part in a floating-point number formatted in hexadecimal
 --> main.yr:(1,9)
 1  ┃ let x = 0x1.8;
    ╋         ^^^
    ┃ Note :
    ┃  --> main.yr:(1,12)
    ┃  1  ┃ let x = 0x1.8;
    ┃     ╋            ^
    ┃     ┗━━━━━━━
    ┗━━━━━┻━
```

## How to fix it

Add the exponent: `0x1.8p+0`. Use a decimal literal instead if the exponent
notation is not what was wanted.

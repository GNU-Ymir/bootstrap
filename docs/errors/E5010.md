# E5010

> YIL byte file was created for a <> bits target, mismatch current target arch <> bits

where `<>` stands for a value the diagnostic fills in.

Raised during **lowering (YIL)**, from `SerializeYILErrorMessage::MISMATCH_ARCH_POINTER_SIZE` (`src/ymirc/lint/serialize/errors.yr`).

## What it means

A `.yil` file was produced for a target whose pointer width is not the one
being compiled for -- a 32 bit bytecode read by a 64 bit compilation, or the
reverse. Pointer width changes the layout of every type in the file, so the
bytecode cannot be reused across targets.

## How to fix it

Recompile the imported package for the target currently being built. A build
directory shared between two targets has to be separated, one output directory
per target.

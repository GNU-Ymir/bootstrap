# E4184

> the return type of the overriding method <> is not compatible with the return type of the ancestor method <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::OVERRIDE_INCOMPATIBLE_RETURN_TYPE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

An overriding method returns a type the ancestor method's return type does not
accept. A caller holding the base type has to be able to use the result.

## Example

`test_resources/implement/test8.yr`:

```ymir
trait X {T} {
    cte if template!{T}{U of i32} {
        pub fn foo (self)-> i32;
    } else {
        pub fn foo (self)-> f32;
    }
}

class Z {
    impl X!{i32} {
        pub over foo (self)-> f32 {
            1.0f
        }
    }
}

class Y {
    impl X!{f32} {
        pub over foo (self)-> i32 {
            1
        }
    }
}
```

## How to fix it

Return the ancestor's type, or a type that converts to it.

# E4172

> record or entity type <> has no size due to forward references

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::NO_SIZE_FORWARD_REF` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

The size of a record or an entity cannot be computed because one of its fields
refers to a type not yet defined.

## Example

`test_resources/struct/test1.yr`:

```ymir
in test1;

record A {
    let a : A;
}

record B {
    let c : C;
}

record C {
    let b : B;
}
```

```text
Error[E4172] : record or entity type test1::A has no size due to forward references
 --> test_resources/struct/test1.yr:(3,8)
 3  ┃ record A {
    ╋        ^
    ┃ Note : for the field a
    ┃  --> test_resources/struct/test1.yr:(4,9)
    ┃  4  ┃     let a : A;
    ┃     ╋         ^
    ┃     ┃ Note : within type test1::A
    ┃     ┃  --> test_resources/struct/test1.yr:(3,8)
    ┃     ┃  3  ┃ record A {
    ┃     ┃     ╋        ^
    ┃     ┃     ┗━━━━━━━
    ┃     ┗━━━━━┻━
    ┗━━━━━┻━
```

## How to fix it

Break the cycle: hold the offending field behind a class or a pointer, cf.
[E4017](E4017.md).

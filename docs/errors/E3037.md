# E3037

> custom attribute <> is not valid on unit tests

where `<>` stands for a value the diagnostic fills in.

Raised during **declaration**, from `DeclareErrorMessage::UNDEFINED_ATTRIBUTE_FOR_UNITTEST` (`src/ymirc/semantic/declarator/errors.yr`).

## What it means

A unit test is not a symbol other code can refer to, so the attributes shaping
how a function is emitted or overridden mean nothing on it. `@parameters` is the
only attribute it accepts.

## Example

`test_resources/unittest/test9.yr`:

```ymir
@final
__test {
    assert (true);
}
```

```text
Error[E3037] : custom attribute final is not valid on unit tests
 --> test_resources/unittest/test9.yr:(2,2)
 2  ┃ @final
    ╋  ^^^^^
    ┗━━━━━━━
```

## How to fix it

Drop the attribute.

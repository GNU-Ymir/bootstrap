# E4007

> break statement is not within a loop

Raised during **validation**, from `ValidateErrorMessage::BREAK_NO_LOOP` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A `break` was written outside any loop.

## Example

`test_resources/diagnostics/test18.yr`:

```ymir
fn main () {
    break;
}
```

```text
Error[E4007] : break statement is not within a loop
 --> test_resources/diagnostics/test18.yr:(2,5)
 2  ┃     break;
    ╋     ^^^^^
    ┗━━━━━━━
```

## How to fix it

Remove it, or move it inside the loop it was meant to leave. To leave a
function early, use `return`.

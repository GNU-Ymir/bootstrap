# E4263

> unsafe operation outside unsafe context

Raised during **validation**, from `ValidateErrorMessage::UNSAFE_OPERATION` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

An operation the language considers unsafe -- a raw pointer dereference, for
instance -- was written outside an `unsafe` context.

## Example

`test_resources/diagnostics/test124.yr`:

```ymir
// a pointer dereferenced outside an unsafe block
fn main () {
    let x = 1;
    let p = &x;
    let _ = *p;
}
```

```text
Error[E4263] : unsafe operation outside unsafe context
 --> test_resources/diagnostics/test124.yr:(5,13)
 5  ┃     let _ = *p;
    ╋             ^
    ┃
    = when validating test124::main -- (test_resources/diagnostics/test124.yr:(2,4))
    ┗━━━━━━━
```

## How to fix it

Wrap it in an `unsafe` block, cf. [E4262](E4262.md).

# E4220

> type <> has no field named <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::TYPE_NO_FIELD` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A field name was used on a type that has no field of that name, cf.
[E4019](E4019.md).

## How to fix it

Check the spelling and the type.

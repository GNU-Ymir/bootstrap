# E4012

> catching pattern of type <> catches no exception

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::CATCH_NOTHING` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A catch pattern names a type no exception thrown inside the guarded block can
have, so the pattern can never run.

## How to fix it

Remove the pattern, or widen it to a type the block can actually throw. The
types a block may throw are the ones declared by the `throws` of everything it
calls.

# E2002

> decorator <> is defined multiple times

where `<>` stands for a value the diagnostic fills in.

Raised during **parsing**, from `SyntaxErrorMessage::MULTIPLE_ATTRS` (`src/ymirc/syntax/errors.yr`).

## What it means

The same decorator was written twice on one declaration. A decorator states a
property; stating it twice says nothing more and is more likely a mistake than
an intention.

## How to fix it

Remove the duplicate. If two different decorators were meant, check the
spelling of the second one.

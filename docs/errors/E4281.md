# E4281

> var declaration <> outside a function context

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::DECLARE_VARIABLE_NO_FUNCTION` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A `var` declaration was written outside any function. Variables live in a
function frame; a declaration at module level is a global variable, declared
differently.

## How to fix it

Move the declaration into a function, or declare it as a global.

# E4173

> class <> has no ancestor

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::NO_SUPER_CLASS` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

`super` was used in a class with no base class.

## Example

`test_resources/diagnostics/test63.yr`:

```ymir
class Foo {
    pub self () {
        self.super ();
    }
}

fn main () { let _ = copy Foo (); }
```

```text
Error[E4173] : class &(test63::Foo) has no ancestor
 --> test_resources/diagnostics/test63.yr:(3,9)
 3  ┃         self.super ();
    ╋         ^^^^ ^^^^^
    ┗━━━━━━━
```

## How to fix it

Give the class a base, or remove the `super` access.

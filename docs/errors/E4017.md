# E4017

> field <> has not yet been validated

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::CLASS_FIELD_NOT_VALIDATED_YET` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A field is used while the type it belongs to is still being validated, so its
type is not known yet. This happens when a type refers to itself through a path
the compiler has to resolve before it can finish the type.

## Example

`test_resources/lit_class/ctors/test23.yr`:

```ymir
class A {
    let x : i32;
    let y : i32;

    pub self ()
        with y = self.x
        , x = 9
    {}
}
```

```text
Error[E4017] : field x has not yet been validated
 --> test_resources/lit_class/ctors/test23.yr:(6,23)
 6  ┃         with y = self.x
    ╋                       ^
    ┃ Note : declared here
    ┃  --> test_resources/lit_class/ctors/test23.yr:(2,9)
    ┃  2  ┃     let x : i32;
    ┃     ╋         ^
    ┃     ┗━━━━━━━
    ┗━━━━━┻━
```

## How to fix it

Break the cycle: hold the self-reference behind a class (which is a
reference) or a pointer, rather than by value.

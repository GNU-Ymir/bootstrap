# E4115

> malformed literal, number of <> is <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::MALFORMED_CHAR` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A character literal does not hold exactly one character -- the count the
compiler found is in the message.

## How to fix it

Write a single character between quotes, or use a string literal if several
characters were meant. A multi-byte character needs the character type wide
enough to hold it.

# E3032

> unexpected declaration

**Retired.** The message this code named was deleted from the compiler: no
source could reach it. The parser only hands a module the declarations it accepts.

The code is not reused and not reassigned to another diagnostic, so an E3032
printed by an older compiler still means what is quoted above. This page stays
as its record.

It was raised during **declaration**, from `DeclareErrorMessage::UNEXPECTED_IN_MODULE`.

# E3032

> unexpected declaration

Raised during **declaration**, from `DeclareErrorMessage::UNEXPECTED_IN_MODULE` (`src/ymirc/semantic/declarator/errors.yr`).

## What it means

A declaration appeared at module level that is not one of the declarations a
module accepts.

## How to fix it

Move it inside the declaration it belongs to. A statement, as opposed to a
declaration, can only appear inside a function body.

# E4276

> var declared without value, when necessary

**Retired.** The message this code named was deleted from the compiler: no
source could reach it. The parser requires a value in a local variable declaration.

The code is not reused and not reassigned to another diagnostic, so an E4276
printed by an older compiler still means what is quoted above. This page stays
as its record.

It was raised during **validation**, from `ValidateErrorMessage::VAR_DECL_WITHOUT_VALUE`.

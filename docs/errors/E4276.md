# E4276

> var declared without value, when necessary

Raised during **validation**, from `ValidateErrorMessage::VAR_DECL_WITHOUT_VALUE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A `var` declaration has no value where the context requires one to infer
from.

## How to fix it

Give the declaration a value, or write its type explicitly.

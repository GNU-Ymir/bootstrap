# E4215

> tuple matcher only applies to tuple values not <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::TUPLE_MATCHER` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A tuple pattern was matched against something that is not a tuple.

## How to fix it

Match a tuple, or use a pattern for the type at hand.

# E4215

> tuple matcher only applies to tuple values not <>

**Retired.** The message this code named was deleted from the compiler: no
code raised it any more. Nothing produces E4215 today.

The code is not reused and not reassigned to another diagnostic, so an E4215
printed by an older compiler still means what is quoted above. This page stays
as its record.

It was raised during **validation**, from `ValidateErrorMessage::TUPLE_MATCHER`.

# E4082

> left operand of type <> is immutable

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::IMMUTABLE_LVALUE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

An assignment writes through a value whose type is immutable.

## Example

`test_resources/for_loops/tuples/test2.yr`:

```ymir
fn main () {
    let a = (1, 2, 3);
    for x in ref a {
        x;
    }
}
```

```text
Error[E4082] : left operand of type (i32, i32, i32) is immutable
 --> test_resources/for_loops/tuples/test2.yr:(3,14)
 3  ┃     for x in ref a {
    ╋              ^^^ ^
    ┗━━━━━━━
```

## How to fix it

Declare the variable, or the borrow it came from, as mutable. Mutability
travels with the type, so a value reached through a constant borrow stays
constant.

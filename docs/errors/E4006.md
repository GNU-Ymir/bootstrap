# E4006

> array pattern match len <> never matches the value len <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::ARRAY_PATTERN_SIZE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

An array pattern matches a fixed number of elements, and the value it is
matched against has a different, statically known length, so the pattern can
never match.

## Example

`test_resources/pattern_match/test13.yr`:

```ymir

fn main () {
    let x = [1, 2, 3];
    let [a = 1, b] = x;
}
```

```text
Error[E4006] : array pattern match len 2us never matches the value len 3us
 --> test_resources/pattern_match/test13.yr:(4,9)
 4  ┃     let [a = 1, b] = x;
    ╋         ^
    ┗━━━━━━━
```

## How to fix it

Give the pattern the length of the value, or use a slice pattern if a variable
number of elements was meant.

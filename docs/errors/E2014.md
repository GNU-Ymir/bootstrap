# E2014

> attribute <> takes no argument

where `<>` stands for a value the diagnostic fills in.

Raised during **parsing**, from `SyntaxErrorMessage::ATTRIBUTE_WITHOUT_ARGS` (`src/ymirc/syntax/errors.yr`).

## What it means

An attribute declares how many arguments it takes, and most take none. The set of
attributes is closed, so this is checked as the name is read, next to the error
raised for an attribute that does not exist at all.

Only `@parameters` takes an argument today.

## Example

`test_resources/diagnostics/test91.yr`:

```ymir
@final(3)
fn main () {}
```

```text
Error[E2014] : attribute final takes no argument
 --> test_resources/diagnostics/test91.yr:(2,2)
 2  ┃ @final(3)
    ╋  ^^^^^
    ┗━━━━━━━
```

## How to fix it

Drop the argument list.

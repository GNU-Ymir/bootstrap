# E4331

> <> is not a tag

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::NOT_A_TAG` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

The path of a tag site, `#[path (args)]`, is resolved from the scope the tagged
declaration is written in, and must name a tag declaration, `tag path { ... }`.
It names something else: a function, a class, a module, a variable...

A path naming nothing at all is reported as an undefined symbol instead,
[E3027](E3027.md).

## Example

`test_resources/diagnostics/test166.yr`:

```ymir
// a tag site naming a function, not a tag
fn route ()-> i32 { 1 }

#[route]
fn foo () {}

fn main () {}
```

```text
Error[E4331] : route is not a tag
 --> test_resources/diagnostics/test166.yr:(4,3)
 4  ┃ #[route]
    ╋   ^^^^^
    ┃
    = when validating test166::foo -- (test_resources/diagnostics/test166.yr:(5,4))
    ┗━━━━━━━
```

## How to fix it

Name a tag in the tag list, declaring it if needed, or remove the tag site.

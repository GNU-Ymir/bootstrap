# E4144

> class <> is not abstract but has empty methods

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::NON_ABSTRACT_NOT_COMPLETE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A class has methods with no body but is not declared `abstract`, so it could be
instantiated with nothing to call.

## Example

`test_resources/implement/test3.yr`:

```ymir
trait X {
    pub fn foo (self);
}

class A {
    pub self () {}
    impl X ;
}

record B {
    pub self () {}
    impl X ;
}
```

```text
Error[E4144] : class test3::A is not abstract but has empty methods
 --> test_resources/implement/test3.yr:(5,7)
 5  ┃ class A {
    ╋       ^  note: X::foo ()-> void is empty -- (test_resources/implement/test3.yr:(2,12))
    ┗━━━━━━━
```

## How to fix it

Give the methods bodies, or declare the class `abstract`, cf.
[E4026](E4026.md).

# E4142

> index cannot be negative for type <>, but is <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::NEGATIVE_INT_INDEX` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

An index the compiler computed is negative, on a type whose indices start at
zero.

## Example

`test_resources/diagnostics/test56.yr`:

```ymir
fn main () {
    let a = [1, 2, 3];
    let _ = a [-1];
}
```

```text
Error[E4142] : index cannot be negative for type [i32 ; 3us], but is -1
 --> test_resources/diagnostics/test56.yr:(3,15)
 3  ┃     let _ = a [-1];
    ╋               ^^
    ┗━━━━━━━
```

## How to fix it

Correct the index. To count from the end, use `$` inside the index
operation.

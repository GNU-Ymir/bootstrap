# E4229

> operator $ is not defined for type <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::UNDEFINED_DOLLAR_OP` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

`$` was used on a type that does not define a length.

## Example

`test_resources/diagnostics/test74.yr`:

```ymir
class Foo { pub self () {} }

fn main () {
    let f = copy Foo ();
    let _ = f [$];
}
```

```text

 --> test_resources/diagnostics/test74.yr:(5,16)
 5  ┃     let _ = f [$];
    ╋                ^
    ┃ Error[E4020] : class &(test74::Foo) has no method named opDollar
    ┃  --> test_resources/diagnostics/test74.yr:(5,16)
    ┃  5  ┃     let _ = f [$];
    ┃     ╋                ^  note: class &(test74::Foo) has no method named `opDollar`
    ┃     ┗━━━━━━━
    ┗━━━━━┻━
```

## How to fix it

Use a type with a length, or write the bound explicitly.

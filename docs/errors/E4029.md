# E4029

> movable type <> cannot be embedded within another type

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::CONTAIN_MOVABLE_TYPE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A movable type was embedded in another type. A movable type has an identity
that survives being moved, which embedding it by value would break.

## Example

`test_resources/union/test4.yr`:

```ymir
entity Z {
    pub self () {}
}

@overlaid
record A {
    let z : Z;
}
```

```text
Error[E4029] : movable type test4::Z cannot be embedded within another type
 --> test_resources/union/test4.yr:(7,5)
 7  ┃     let z : Z;
    ╋     ^^^     ^
    ┃ Note : the structure is defined as a record but must be an entity to store movable values
    ┃  --> test_resources/union/test4.yr:(6,8)
    ┃  6  ┃ record A {
    ┃     ╋        ^
    ┃     ┗━━━━━━━
    ┗━━━━━┻━
```

## How to fix it

Hold it behind a class or a pointer, rather than by value.

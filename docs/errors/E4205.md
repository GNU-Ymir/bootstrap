# E4205

> a lambda function must be safe, but there are exceptions that are not caught

Raised during **validation**, from `ValidateErrorMessage::THROWS_IN_LAMBDA` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A lambda body can throw, and a lambda has no prototype to declare what it
throws.

## How to fix it

Catch the exception inside the lambda, or use a named function, whose
prototype can declare the throw.

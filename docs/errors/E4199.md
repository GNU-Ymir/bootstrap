# E4199

> declaration of <> shadows another declaration

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::SHADOWING_DECL` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A declaration hides an earlier one still in scope, cf. [E3018](E3018.md).

## Example

`test_resources/enumeration/test17.yr`:

```ymir
enum X
| A = 1
| A = 2;
```

```text
Error[E4199] : declaration of A shadows another declaration
 --> test_resources/enumeration/test17.yr:(3,1)
 3  ┃ | A = 2;
    ╋ ^
    ┃ Note : defined here
    ┃  --> test_resources/enumeration/test17.yr:(2,7)
    ┃  2  ┃ | A = 1
    ┃     ╋       ^
    ┃     ┗━━━━━━━
    ┗━━━━━┻━
```

## How to fix it

Rename one of the two.

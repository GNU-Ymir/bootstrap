# E4247

> aliasing the value of type <> to create a constant borrowing is prohibited

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::UNECESSARY_ALIAS` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

`alias` was used to produce a constant borrow. Aliasing exists to carry
mutability across a borrow; producing a constant one from it says the borrow is
not needed.

## Example

`test_resources/function/test3.yr`:

```ymir
fn foo (x : [i32]);

fn main () {
    let dmut a = copy [1];
    foo (alias a);
}
```

```text
Error[E4247] : aliasing the value of type [i32] to create a constant borrowing is prohibited
 --> test_resources/function/test3.yr:(5,10)
 5  ┃     foo (alias a);
    ╋          ^^^^^  note: for parameter x: [i32]
    ┗━━━━━━━
```

## How to fix it

Drop the `alias`: a constant borrow is what passing the value already
gives.

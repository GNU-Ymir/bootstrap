# E4294

> a generator cannot return a value, its values are yielded

Raised during **validation**, from `ValidateErrorMessage::RETURN_VALUE_GENERATOR` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

The declared return type of a generator is the type of the values it yields,
and a call of a generator returns its handle. A `return` can only end the
generator.

## Example

`test_resources/generators/test10.yr`:

```ymir
// a generator returning a value
yield gen ()-> i32 {
    yield 1;
    return 2;
}
```

```text
Error[E4294] : a generator cannot return a value, its values are yielded
 --> test_resources/generators/test10.yr:(4,5)
 4  ┃     return 2;
    ╋     ^^^^^^
    ┃
    = when validating test10::gen -- (test_resources/generators/test10.yr:(2,7))
    ┗━━━━━━━
```

## How to fix it

Yield the value, then `return;` if the generator has to stop there.

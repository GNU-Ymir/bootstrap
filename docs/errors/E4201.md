# E4201

> template validation is not complete, unresolved: {<>}

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::TEMPLATE_REST` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

Template resolution matched part of the specialization and left arguments over.
What is left is in the message.

## How to fix it

Give the template the parameters it declares, or extend the template to take
the extra ones.

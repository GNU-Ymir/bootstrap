# E4153

> <> is a value iterator, and cannot be used as a lvalue

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::NOT_A_LVALUE_ITERATOR` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A `for` loop iterator that yields values, not references, was used as an
lvalue. Each iteration produces a fresh value, which is discarded at the end of
the round.

## Example

`test_resources/for_loops/tuples/test9.yr`:

```ymir
fn main () {
    let dmut a = (copy [1, 2],);
    for dmut x in alias a {
        x = copy [8, 3];
    }
}
```

```text
Error[E4153] : x is a value iterator, and cannot be used as a lvalue
 --> test_resources/for_loops/tuples/test9.yr:(4,9)
 4  ┃         x = copy [8, 3];
    ╋         ^ ^
    ┗━━━━━━━
```

## How to fix it

Iterate by reference so the loop yields the elements themselves, or collect
the new values into a result.

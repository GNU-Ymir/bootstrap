# E2017

> a comma only ends an arm whose value is a simple expression, neither a block nor a statement

Raised during **parsing**, from `SyntaxErrorMessage::ARM_COMMA` (`src/ymirc/syntax/errors.yr`).

## What it means

A comma ends the arm of a `match` or a `catch` whose value is a simple
expression, so that the pattern of the next arm cannot be read into it. An arm
whose value is a block, a control expression (`if`, `match`, a loop, ...), or a
statement ended by `;` is already closed, and a comma after it is refused.

## Example

`test_resources/diagnostics/test151.yr`:

```ymir
fn foo (a: i32)-> i32 {
    match a {
        0 => { 1 },
        _ => 2
    }
}

fn main () {
    let _b_ = foo (1);
}
```

```text
Error[E2017] : a comma only ends an arm whose value is a simple expression, neither a block nor a statement
 --> test_resources/diagnostics/test151.yr:(4,19)
 4  ┃         0 => { 1 },
    ╋                   ^
    ┗━━━━━━━
```

## How to fix it

Drop the comma, or the braces around a value that does not need them:
`0 => 1,`.

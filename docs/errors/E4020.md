# E4020

> class <> has no method named <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::CLASS_NO_METHOD` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A method name was used on a class that has no method of that name.

## Example

`test_resources/lit_class/operators/test6.yr`:

```ymir
class A {
    pub self () {}
}

fn main () {
    let a = copy A ();
    a * a;

}
```

```text
Error[E4020] : class &(test6::A) has no method named opBinary
 --> test_resources/lit_class/operators/test6.yr:(7,7)
 7  ┃     a * a;
    ╋       ^  note: class &(test6::A) has no method named `opBinary`
    ┗━━━━━━━
```

## How to fix it

Check the spelling and the class. When the method comes from a trait, the
class needs an `impl` block for it, cf. [E4018](E4018.md).

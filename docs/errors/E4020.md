# E4020

> class <> has no method named <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::CLASS_NO_METHOD` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A method name was used on a class that has no method of that name.

## Example

`test_resources/lit_class/operators/test13.yr`:

```ymir
class A {
    pub self () {}

    pub fn opIndex (self, _ : i32)-> i32 {
        1
    }

}


class B  {
    pub self () {}
}



fn main () {
    let a = copy A ();
    let _ = a ['i'];

    let b = copy B ();
    let _ = b [1];
}
```

```text
Error[E4020] : class &(test13::B) has no method named opIndex
 --> test_resources/lit_class/operators/test13.yr:(22,15)
22  ┃     let _ = b [1];
    ╋               ^
    ┃
    = when validating test13::main -- (test_resources/lit_class/operators/test13.yr:(17,4))
    ┗━━━━━━━
```

## How to fix it

Check the spelling and the class. When the method comes from a trait, the
class needs an `impl` block for it, cf. [E4018](E4018.md).

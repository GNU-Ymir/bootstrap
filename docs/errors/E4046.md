# E4046

> division by 0

Raised during **validation**, from `ValidateErrorMessage::DIVISION_BY_ZERO` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A division or a modulo by a zero the compiler could compute.

## Example

`test_resources/binary_int/test5.yr`:

```ymir
in test5;

fn main () {
    cte {1 % 0};

    1u32 + 3;

    let a = 12;
    a = 9;

    3 + 1i32;

    let mut b = 1;
    b = 1us;

}
```

```text
Error[E4046] : division by 0
 --> test_resources/binary_int/test5.yr:(4,12)
 4  ┃     cte {1 % 0};
    ╋            ^
    ┗━━━━━━━
```

## How to fix it

Fix the divisor, or test it before dividing when it is not statically
known.

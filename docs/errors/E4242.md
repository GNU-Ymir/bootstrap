# E4242

> decorator <> is not applicable for types

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::UNDEF_DECORATOR_TYPE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A decorator that applies to values was written on a type.

## How to fix it

Remove it, or apply it to the value instead.

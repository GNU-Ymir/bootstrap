# E4242

> decorator <> is not applicable for types

**Retired.** The message this code named was deleted from the compiler: no
source could reach it. The parser only accepts `self` or `mut self` as the first parameter of a method.

The code is not reused and not reassigned to another diagnostic, so an E4242
printed by an older compiler still means what is quoted above. This page stays
as its record.

It was raised during **validation**, from `ValidateErrorMessage::UNDEF_DECORATOR_TYPE`.

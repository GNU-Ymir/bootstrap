# E4202

> template specialization for <> fails with <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::TEMPLATE_SPECIALIZATION_FAILS` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A template could not be specialized for the given arguments; the reason is in
the message.

## Example

`test_resources/templates/class/test4.yr`:

```ymir
class A {

    pub self {T} (a : T)
        with self!{i32} (a)
    {
    }

}


fn main () {
    copy A (1);
}
```

## How to fix it

Read the reason: it is usually a constraint the arguments do not satisfy, or
a parameter that could not be deduced.

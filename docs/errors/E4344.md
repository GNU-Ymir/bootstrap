# E4344

> await statement is not within an async

Raised during **validation**, from `ValidateErrorMessage::AWAIT_NO_ASYNC` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

An `await` appears in a function that is not an async. Only a function
introduced by `async` can be suspended until what it awaits is ready; a lambda
nested in an async is a function of its own, and cannot await on behalf of the
async either, unless it is itself an async lambda (`async || { await one () }`).

## Example

`test_resources/async/test27.yr`:

```ymir
// await is only valid in an async.

async one ()-> i32 {
    1
}

fn main () {
    let _ = await one ();
}
```

```text
Error[E4344] : await statement is not within an async
 --> test_resources/async/test27.yr:(8,13)
 8  ┃     let _ = await one ();
    ╋             ^^^^^
    ┃
    = when validating test27::main -- (test_resources/async/test27.yr:(7,4))
    ┗━━━━━━━
```

## How to fix it

Declare the function with `async`, or drive the async to completion with
`run ()`, which blocks the thread until it completes.

# E4197

> return statement is not within a function

Raised during **validation**, from `ValidateErrorMessage::RETURN_NO_FUNCTION` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A `return` was written outside any function.

## Example

`test_resources/diagnostics/test69.yr`:

```ymir
lazy X : i32 = { return 1; };

fn main () { X; }
```

## How to fix it

Remove it, or move it into the function it was meant to leave.

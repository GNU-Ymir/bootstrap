# E4256

> value of type <> is needed but unknown at compilation time

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::UNKNOWN_AT_COMPILE_TIME` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A value is needed at compile time and is only known at run time.

## Example

`test_resources/regressions/cte_if_else_if_chain/test1.yr`:

```ymir
in test1;

/**
 * `else if` continues the `cte if` chain, so its condition is evaluated at
 * compile time as well. A runtime comparison there is an error.
 */

fn check {R...} (x : [c8], lst : R)-> bool {
    cte if (R,)::arity > 1 {
        for z in lst if x == z {
            return true;
        }
    }

    else if lst == x {
        return true;
    }

    return false;
}

fn main () {
    let _ = check ("a", "b");
}
```

```text
Error[E4256] : value of type bool is needed but unknown at compilation time
 --> test_resources/regressions/cte_if_else_if_chain/test1.yr:(15,17)
15  ┃     else if lst == x {
    ╋                 ^^
    ┗━━━━━━━
```

## How to fix it

Make the value a compile time constant, or move the construction needing it to
run time.

# E4025

> conflicting decorators <> and <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::CONFLIT_DECORATORS` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

Two decorators applied to the same declaration contradict each other.

## How to fix it

Keep the one that describes the intent.

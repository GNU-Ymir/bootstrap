# E4025

> conflicting decorators <> and <>

**Retired.** The message this code named was deleted from the compiler: no
code raised it any more. Nothing produces E4025 today.

The code is not reused and not reassigned to another diagnostic, so an E4025
printed by an older compiler still means what is quoted above. This page stays
as its record.

It was raised during **validation**, from `ValidateErrorMessage::CONFLIT_DECORATORS`.

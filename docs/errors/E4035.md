# E4035

> infinite constructor redirection calls when calling <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::CTOR_INFINITE_REDIRECTION` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A chain of constructor redirections comes back to a constructor already in the
chain, so construction would never terminate.

## Example

`test_resources/templates/class/test3.yr`:

```ymir
class A {
    pub self (a : i32)
        with self (a)
    {}
}
```

```text
Error[E4035] : infinite constructor redirection calls when calling test3::A::self (a: i32)-> mut &(mut test3::A)
 --> test_resources/templates/class/test3.yr:(3,14)
 3  ┃         with self (a)
    ╋              ^^^^
    ┗━━━━━━━
```

## How to fix it

Break the cycle: one constructor of the chain has to initialize the fields
itself instead of redirecting.

# E3045

> a declaration of a tag is a global, an apply or a self overload, not <>

where `<>` stands for a value the diagnostic fills in.

Raised during **declaration**, from `DeclareErrorMessage::UNEXPECTED_IN_TAG` (`src/ymirc/semantic/declarator/errors.yr`).

## What it means

A tag declares three things: its globals, one per tag whatever the number of
its sites; its `apply` overloads, the rewrites merged into the declarations it
is put on; and its `self` overloads, run once per tag site. A function, a class,
an enum or a union of a tag is an `apply` overload, so it must be named `apply`.
The message names the one that is not.

## Example

`test_resources/diagnostics/test165.yr`:

```ymir
// a tag declaring a function that is not an apply overload
tag route (path: [c8]) {
    pub fn helper ()-> [c8] { path }
}

fn main () {}
```

```text
Error[E3045] : a declaration of a tag is a global, an apply or a self overload, not helper
 --> test_resources/diagnostics/test165.yr:(3,12)
 3  ┃     pub fn helper ()-> [c8] { path }
    ╋            ^^^^^^
    ┗━━━━━━━
```

## How to fix it

Name the declaration `apply` if it is a rewrite of the tagged declarations, or
move it out of the tag.

# E4108

> validation of lazy closure function fails to generate value of type <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::LAZY_VALIDATION` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A lazy value could not be built: validating the closure that defers the
computation failed to produce a value of the expected type.

## Example

`test_resources/diagnostics/test109.yr`:

```ymir
// a lazy value assigning a variable it encloses
fn main () {
    let mut x = 1;
    let y = lazy { x = 2; 1 };
    let _ = y;
    x = 3;
}
```

## How to fix it

Check the expression the `lazy` applies to; the errors under this diagnostic
say what went wrong inside it.

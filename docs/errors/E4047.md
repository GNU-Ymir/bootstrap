# E4047

> '$' is usable only inside an index operation

Raised during **validation**, from `ValidateErrorMessage::DOLLAR_OUTSIDE_CONTEXT` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

`$`, which stands for the length of the value being indexed, was used outside
an index operation, where it has nothing to refer to.

## How to fix it

Use the length explicitly (`x.len`) outside an index.

# E4051

> cannot perform a direct call of the method <> that is empty

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::EMPTY_METHOD_CALL` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A method with no body was called directly rather than through the virtual
dispatch of an instance. An empty method has no code to jump to.

## Example

`test_resources/diagnostics/test30.yr`:

```ymir
@abstract
class Foo {
    pub self () {}
    pub fn bar (self);
}

class Bar over Foo {
    pub self () {}
    pub over bar (self) { self.super.bar (); }
}

fn main () { let _ = copy Bar (); }
```

```text
Error[E4051] : cannot perform a direct call of the method test30::Foo::bar ()-> void that is empty
 --> test_resources/diagnostics/test30.yr:(4,12)
 4  ┃     pub fn bar (self);
    ╋            ^^^
    ┃ Note : from an proxied instance of class &(test30::Foo) that is abstract
    ┃  --> test_resources/diagnostics/test30.yr:(9,32)
    ┃  9  ┃     pub over bar (self) { self.super.bar (); }
    ┃     ╋                                ^^^^^
    ┃     ┗━━━━━━━
    ┗━━━━━┻━
```

## How to fix it

Call it on an instance whose dynamic type provides a body, or give the method
a body.

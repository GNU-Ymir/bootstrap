# E4218

> temporary type <> has no size

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::TYPE_HAS_NO_SIZE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

The size of a temporary type was asked for, and it has none.

## Example

`test_resources/struct/test1.yr`:

```ymir
in test1;

record A {
    let a : A;
}

record B {
    let c : C;
}

record C {
    let b : B;
}
```

```text
    ╋         -  note: for the field a

    ┗━━━━━━━
```

## How to fix it

Ask the size of a concrete type instead.

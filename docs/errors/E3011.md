# E3011

> method <> is marked override but does not override any base method

**Retired.** The message this code named was deleted from the compiler: no
source could reach it. The parser does not accept `over` inside a trait.

The code is not reused and not reassigned to another diagnostic, so an E3011
printed by an older compiler still means what is quoted above. This page stays
as its record.

It was raised during **declaration**, from `DeclareErrorMessage::NOT_OVERRIDE`.

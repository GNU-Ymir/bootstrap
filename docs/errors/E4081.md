# E4081

> the if condition has no else value, so it must produce a void value not a <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::IF_COND_NOT_COMPLETE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

An `if` used as an expression produces a value on the branch that is taken, but
has no `else`, so there would be nothing to produce when the condition is
false.

## Example

`test_resources/control_flow/test16.yr`:

```ymir
fn main () {
    let mut cond = false;
    let a = if cond {
        12
    }; // error, no else value

    let b = if cond {
        12
    } else {
        "str"
    }; // error, incompatible i32 and [c8]

    let d = if cond {
        12
    } else {
        11u32
    }; // ok, implicit cast of 11u32 to i32
}
```

```text
Error[E4081] : the if condition has no else value, so it must produce a void value not a i32
 --> test_resources/control_flow/test16.yr:(3,13)
 3  ┃     let a = if cond {
    ╋             ^^
   ...
 --> test_resources/control_flow/test16.yr:(4,9)
 4  ┃         12
    ╋         ^^
    ┗━━━━━━━
```

## How to fix it

Add an `else` branch producing a value of the same type, or make the `if` a
statement by ending the branch with something that produces nothing.

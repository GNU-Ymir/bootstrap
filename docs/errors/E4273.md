# E4273

> expression produces a type, but is used as a value

Raised during **validation**, from `ValidateErrorMessage::USE_AS_VALUE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A type was written where a value is expected.

## How to fix it

Construct a value of that type, or use a value that already exists.

# E4103

> method <> cannot be inline as it is virtual(overridable or inherited)

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::INLINE_VIRTUAL_METHOD` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A method is marked `inline` and is virtual. A virtual call is resolved at run
time through the vtable, so there is no single body to inline.

## How to fix it

Drop `inline`, or make the method `final` so it is no longer overridable.

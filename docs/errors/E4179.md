# E4179

> static array size <> exceeds limits <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::OVERFLOW_CAPACITY_ARRAY` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A static array is declared with a size beyond what the compiler accepts.

## How to fix it

Reduce the size, or allocate a slice at run time instead.

# E1015

> <> is not a valid identifier; use backquotes for special identifiers(e.g. `<>`)

where `<>` stands for a value the diagnostic fills in.

Raised during **lexing**, from `LexingErrorMessage::INVALID_IDENTIFIER` (`src/ymirc/lexing/errors.yr`).

## What it means

The name reported is not a valid identifier: it either starts with a character
identifiers cannot start with, or it is a reserved keyword. Ymir can still name
such a symbol, but the name has to be quoted.

## Example

`test_resources/lexing/test30.yr`:

```ymir
let __ = 1;
```

```text
Error[E1015] : __ is not a valid identifier; use backquotes for special identifiers(e.g. `__`)
 --> main.yr:(1,5)
 1  ┃ let __ = 1;
    ╋     ^^
    ┗━━━━━━━
```

## How to fix it

Rename the symbol, or write it between backquotes -- `` `if` `` -- which makes
any text usable as an identifier. This is how a symbol coming from another
language whose name collides with an Ymir keyword is referred to.

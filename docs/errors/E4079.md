# E4079

> the field <> is not public, and has no initial value to be constructed from

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::GEN_CTOR_HIDDEN_FIELD_NO_VALUE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

The constructor built from the fields cannot initialize the reported field: it
is not public, so a caller could not pass it, and it has no initial value to
fall back on.

## Example

`test_resources/data_record/ctors/test3.yr`:

```ymir
@data
record Foo {
    prv let _x: i32;
    let y: i32;
}

fn main() {
    let a = Foo(1);
    a.y;
}
```

```text
Error[E4079] : the field _x is not public, and has no initial value to be constructed from
 --> test_resources/data_record/ctors/test3.yr:(3,13)
 3  ┃     prv let _x: i32;
    ╋             ^^
    ┗━━━━━━━
```

## How to fix it

Give the field an initial value, make it public, or write the constructor
explicitly.

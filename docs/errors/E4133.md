# E4133

> field <> is initialized multiple times

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::MULTIPLE_FIELD_INIT` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A constructor assigns the same field twice.

## Example

`test_resources/union/test3.yr`:

```ymir
@overlaid
record A {
    let mut a : i32;
    let mut b : i64 = 0;

    pub self ()
        with a = 12
        , a = 9
    {}
}

fn main () {
    let _ = A ();
}
```

```text
Error[E4133] : field a is initialized multiple times
 --> test_resources/union/test3.yr:(8,11)
 8  ┃         , a = 9
    ╋           ^
    ┃ Note : here
    ┃  --> test_resources/union/test3.yr:(7,14)
    ┃  7  ┃         with a = 12
    ┃     ╋              ^
    ┃     ┗━━━━━━━
    ┗━━━━━┻━
```

## How to fix it

Keep one assignment. When the two came from a field constructor and an
explicit assignment, drop the explicit one.

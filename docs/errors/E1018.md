# E1018

> hexadecimal number is empty

Raised during **lexing**, from `LexingErrorMessage::EMPTY_HEX_NUMBER` (`src/ymirc/lexing/errors.yr`).

## What it means

A `0x` prefix is not followed by any hexadecimal digit, so the literal has no
value.

## Example

`test_resources/lexing/test24.yr`:

```ymir
let x = 0x_;
```

```text
Error[E1018] : hexadecimal number is empty
 --> main.yr:(1,9)
 1  ┃ let x = 0x_;
    ╋         ^^^
    ┗━━━━━━━
```

## How to fix it

Write the digits after the prefix, or remove the prefix if a plain `0` was
meant.

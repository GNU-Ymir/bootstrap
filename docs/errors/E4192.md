# E4192

> cannot override trait method <> with <> outside impl

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::OVERRIDE_TRAIT_OUTSIDE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A trait method is overridden outside an `impl` block. The trait states which
methods it provides, and their bodies belong in the block implementing it.

## Example

`test_resources/implement/test4.yr`:

```ymir
trait X {
    pub fn foo (self);
}

@abstract
class A {
    pub self () {}
    impl X ;
}

class B over A {
    pub over foo (self) {}
}
```

```text
Error[E4192] : cannot override trait method X::foo ()-> void with test4::B::foo ()-> void outside impl
 --> test_resources/implement/test4.yr:(2,12)
 2  ┃     pub fn foo (self);
    ╋            ^^^
   ...
 --> test_resources/implement/test4.yr:(12,14)
12  ┃     pub over foo (self) {}
    ╋              ^^^
    ┗━━━━━━━
```

## How to fix it

Move the method into the `impl` block for that trait.

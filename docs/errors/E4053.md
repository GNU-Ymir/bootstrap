# E4053

> movable type <> cannot be enclosed within a closure function

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::ENCLOSE_MOVABLE_TYPE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A closure captures a movable value. Capturing copies the value into the closure
environment, which is exactly what a movable type forbids.

## How to fix it

Capture a reference to it instead, or move it explicitly before creating the
closure.

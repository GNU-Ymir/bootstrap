# E4230

> undefined escape sequence

Raised during **validation**, from `ValidateErrorMessage::UNDEFINED_ESCAPE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A backslash in a literal is followed by a character that is not an escape the
language defines.

## Example

`test_resources/diagnostics/test75.yr`:

```ymir
fn main () {
    let _ = "\q";
}
```

```text
Error[E4230] : undefined escape sequence
 --> test_resources/diagnostics/test75.yr:(2,15)
 2  ┃     let _ = "\q";
    ╋               ^
    ┗━━━━━━━
```

## How to fix it

Use a defined escape, or double the backslash for a literal one.

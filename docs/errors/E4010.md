# E4010

> cannot continue loop inside a scope guard

Raised during **validation**, from `ValidateErrorMessage::CONTINUE_SCOPE_GUARD` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A `continue` inside a scope guard would jump out of the guard while it is
running, cf. [E4008](E4008.md).

## Example

`test_resources/diagnostics/test21.yr`:

```ymir
fn main () {
    loop {
        {
        } exit {
            continue;
        }
    }
}
```

```text
Error[E4010] : cannot continue loop inside a scope guard
 --> test_resources/diagnostics/test21.yr:(4,11)
 4  ┃         } exit {
    ╋           ^^^^
   ...
 --> test_resources/diagnostics/test21.yr:(5,13)
 5  ┃             continue;
    ╋             ^^^^^^^^
    ┗━━━━━━━
```

## How to fix it

Move the `continue` out of the guard body.

# E4132

> decorator <> is specified multiple times

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::MULTIPLE_DECORATORS` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

The same decorator appears more than once on one declaration.

## How to fix it

Remove the duplicate, cf. [E2002](E2002.md).

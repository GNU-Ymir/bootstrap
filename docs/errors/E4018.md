# E4018

> class type <> does not implement trait <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::CLASS_NOT_IMPL` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A class is used where the trait named is required, and the class does not
implement it.

## Example

`test_resources/templates/explicit/test13.yr`:

```ymir
trait R {I} {}

class B  {
    pub self () {}
    impl R!i32;
}

fn foo {T impl X!{I}, X, I of f32} () {
}

fn main () {
    foo!(&B) ();
}
```

## How to fix it

Add an `impl` block for the trait to the class, or use a type that already
implements it.

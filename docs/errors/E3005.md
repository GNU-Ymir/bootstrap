# E3005

> only external C functions may be variadic

**Retired.** The message this code named was deleted from the compiler: no
source could reach it. The parser only reads a C variadic parameter list inside an `extern (C)` block.

The code is not reused and not reassigned to another diagnostic, so an E3005
printed by an older compiler still means what is quoted above. This page stays
as its record.

It was raised during **declaration**, from `DeclareErrorMessage::DECL_VARIADIC_FUNC`.

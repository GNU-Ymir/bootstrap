# E3005

> only external C functions may be variadic

Raised during **declaration**, from `DeclareErrorMessage::DECL_VARIADIC_FUNC` (`src/ymirc/semantic/declarator/errors.yr`).

## What it means

A function declared in Ymir uses the C variadic form. Variadic arguments have
no Ymir calling convention -- only the C one -- so only an `extern (C)` function
may be variadic.

## How to fix it

Declare the function `extern (C)` if it really is a C variadic function.
Otherwise use a template variadic parameter (`{T...}`), which is the Ymir way to
take an arbitrary number of arguments and keeps their types.

# E4077

> cannot create a function pointer from the unsafe function <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::FUNCTION_TO_FPTR_UNSAFE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A function pointer was created from an unsafe function. Calling through the
pointer would leave no trace that the call is unsafe.

## Example

`test_resources/function/test13.yr`:

```ymir
@unsafe
fn foo ();

fn main () {
    let a = &foo;
    a ();
}
```

```text
Error[E4077] : cannot create a function pointer from the unsafe function test13::foo ()-> void
 --> test_resources/function/test13.yr:(5,13)
 5  ┃     let a = &foo;
    ╋             ^
    ┗━━━━━━━
```

## How to fix it

Wrap the call in a safe function that enters an `unsafe` block itself, and
take a pointer to that.

# E4059

> expected a name expression

Raised during **validation**, from `ValidateErrorMessage::FIELD_MATCHER_NO_NAME` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A field pattern expected the name of a field and got something that is not a
name.

## How to fix it

Write the field name. A pattern matching by position rather than by name uses
the tuple form instead.

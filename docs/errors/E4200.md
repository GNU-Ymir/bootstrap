# E4200

> the superclass proxy of <> is only accessible through self

**Retired.** The message is still raised, but only as a note under
[E4019](E4019.md), which documents it, and it no longer carries a code of its own.

The code is not reused and not reassigned to another diagnostic, so an E4200
printed by an older compiler still means what is quoted above. This page stays
as its record.

It was raised during **validation**, from `ValidateErrorMessage::SUPER_NO_SELF_CLASS`.

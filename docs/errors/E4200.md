# E4200

> the superclass proxy of <> is only accessible through self

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::SUPER_NO_SELF_CLASS` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

The superclass proxy was reached other than through `self`. It exists only to
call the ancestor implementation from inside the instance.

## How to fix it

Use `self` to reach it.

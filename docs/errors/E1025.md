# E1025

> undefined version directive; expecting if, else or end

Raised during **lexing**, from `LexingErrorMessage::UNDEFINED_VERSION_DIRECTIVE` (`src/ymirc/lexing/errors.yr`).

## What it means

The word following `#` is not one of the directives the lexer knows. The only
conditional compilation directives are `#if`, `#else` and `#end`.

## Example

`test_resources/lexing/test10.yr`:

```ymir
#foo
```

```text
Error[E1025] : undefined version directive; expecting if, else or end
 --> main.yr:(1,1)
 1  ┃ #foo
    ╋ ^
    ┃ Note :
    ┃  --> main.yr:(1,2)
    ┃  1  ┃ #foo
    ┃     ╋  ^^^
    ┃     ┗━━━━━━━
    ┗━━━━━┻━
```

## How to fix it

Correct the spelling of the directive, or remove the `#` if the line was not
meant to be a directive at all.

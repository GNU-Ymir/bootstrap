# E4338

> a self overload of a tag is run at program start, it can neither take parameters nor throw

Raised during **validation**, from `ValidateErrorMessage::TAG_CTOR_SHAPE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A `self` overload of a tag is the code run once for each declaration the tag
is put on. The package constructor of the module calls its instance before
`main`, with no argument, and nothing is there to catch what it would throw.

The overload is reported where the tag is declared, at its first parameter or
at its throwers, whether a tag site uses it or not.

## Example

`test_resources/tag/test62.yr`:

```ymir
// a self overload of a tag neither takes parameters nor throws

tag a {
    pub self (x: i32) {
        x;
    }

    pub self {F: fn ()-> i32} () throws &AssertError {
        assert (F () == 1);
    }
}

fn main () {}
```

```text
 --> test_resources/tag/test62.yr:(13,34)

    ╋                                  ^^^^^^

```

## How to fix it

Pass what the overload needs as a parameter of the tag, given at the tag site,
and handle the errors in the overload itself.

# E5007

> malformed bytecode, string table invalid

Raised during **lowering (YIL)**, from `SerializeYILErrorMessage::MALFORMED_BYTECODE_STRING_TABLE` (`src/ymirc/lint/serialize/errors.yr`).

## What it means

The string table of a `.yil` file could not be decoded. Symbol names and
literals are stored in a table the rest of the file refers to by index, and that
table is invalid.

## How to fix it

Recompile the package that produced the file, cf. [E5005](E5005.md).

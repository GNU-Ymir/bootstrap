# E4058

> external global variable cannot be declared with a value

Raised during **validation**, from `ValidateErrorMessage::EXTERN_GLOBAL_WITH_VALUE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

An `extern` global variable was given an initial value. `extern` says the
variable is defined elsewhere; the initial value belongs to that definition.

## How to fix it

Remove the value, or remove `extern` if this module is meant to define
it.

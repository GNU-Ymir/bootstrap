# E4072

> overriding the for loop operation on a class type <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::FOR_LOOP_CPTR` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

The `for` loop operators are being overridden on a class type; this reports the
context in which the override is validated.

## How to fix it

Check the `begin`, `next` and `get` methods the loop needs, which the notes
under this diagnostic point at.

# E4078

> cannot create an option delegate from the non throwing function <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::FUNCTION_TO_OPTION_NO_THROW` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

The `&?` operator, which wraps a throwing function into one returning an
option, was applied to a function that does not throw. There is no error for the
option to carry.

## Example

`test_resources/function/test19.yr`:

```ymir
fn foo (i : i32)-> i32 {
    i + 1
}

fn main () {
    let _f_ = &?foo; // nothing to catch, '&' is what creates a pointer on 'foo'
}
```

```text
Error[E4078] : cannot create an option delegate from the non throwing function test19::foo (i: i32)-> i32
 --> test_resources/function/test19.yr:(6,15)
 6  ┃     let _f_ = &?foo; // nothing to catch, '&' is what creates a pointer on 'foo'
    ╋               ^^  note: replace the operator &? by the simple & operator
    ┗━━━━━━━
```

## How to fix it

Use a plain `&` to take the address of a non-throwing function.

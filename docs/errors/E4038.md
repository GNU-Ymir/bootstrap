# E4038

> the symbol <> was declared but never used

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::DECLARED_NOT_USED` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A symbol was declared and never read. Since an unused declaration is almost
always a leftover or a typo, the compiler reports it rather than letting it
pass silently.

## Example

`test_resources/control_flow/test1.yr`:

```ymir
fn main () {
    let _a_ = 12;
    let a = 12;
    let _a = 12;
    let a_ = 12;
    let _ = 12;
}
```

```text
Warning[E4038] : the symbol a was declared but never used
 --> test_resources/control_flow/test1.yr:(3,9)
 3  ┃     let a = 12;
    ╋         ^
    ┗━━━━━━━
```

## How to fix it

Remove the declaration, or use it. A value deliberately ignored can be bound
to `_`, which is never reported.

# E4033

> using a deep copy instead of a one level copy is prohibited when constructing class <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::CTOR_CLASS_DCOPY` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A class was constructed with a deep copy (`dcopy`) where the language requires
the one level form (`copy`). Constructing a class allocates the instance itself;
deep-copying its contents at the same time conflates two different operations.

## How to fix it

Use `copy` to construct, and `dcopy` afterwards if the contents really have to
be duplicated.

# E4033

> using a deep copy instead of a one level copy is prohibited when constructing class <>

**Retired.** The message this code named was deleted from the compiler: no
source could reach it. A class constructor call always allocates its instance, inside a `dcopy` or not.

The code is not reused and not reassigned to another diagnostic, so an E4033
printed by an older compiler still means what is quoted above. This page stays
as its record.

It was raised during **validation**, from `ValidateErrorMessage::CTOR_CLASS_DCOPY`.

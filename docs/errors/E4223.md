# E4223

> undefined module operator <> for <> and field <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::UNDEFINED_BIN_MOD_OP` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A module-level binary operator is not defined for the operands given.

## Example

`test_resources/diagnostics/test62.yr`:

```ymir
class Foo {
    pub self () {}
}

fn main () { let _ = copy Foo::named (); }
```

```text
Error[E4223] : undefined module operator :: for test62::Foo::self and field named
 --> test_resources/diagnostics/test62.yr:(5,30)
 5  ┃ fn main () { let _ = copy Foo::named (); }
    ╋                              ^^
    ┗━━━━━━━
```

## How to fix it

Define the operator, or use one that exists for these types.

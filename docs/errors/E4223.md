# E4223

> undefined module operator <> for <> and field <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::UNDEFINED_BIN_MOD_OP` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A module-level binary operator is not defined for the operands given.

## Example

`test_resources/aka/test6.yr`:

```ymir

mod inner {
    pub def T = foo ();

    fn foo ()-> i32;

}

fn main () {
    let _ = inner::foo ();
}
```

```text
Error[E4223] : undefined module operator :: for test6::inner and field foo
 --> test_resources/aka/test6.yr:(10,18)
10  ┃     let _ = inner::foo ();
    ╋                  ^^  note: foo from module test6::inner is private in this context
    ┗━━━━━━━
```

## How to fix it

Define the operator, or use one that exists for these types.

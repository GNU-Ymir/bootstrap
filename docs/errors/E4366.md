# E4366

> the compile-time execution panics

Raised during **validation**, from `ValidateErrorMessage::CTE_EXEC_PANIC` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A value needed at compile time calls a function, which the compiler executed to
compute the value, and the execution reached a panic: an explicit `panic`, or a
check of the generated code, such as an index out of the bounds of a slice. The
note points at it.

## Example

`test_resources/cte_exec/test8.yr`:

```ymir
fn at (s: [c8], i: usize)-> c8 {
    s [i]
}

fn outOfBounds () {
    cte assert (at ("abc", 5us) == 'a');
}
```

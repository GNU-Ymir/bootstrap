# E4293

> cannot yield inside a try block, a catch or a scope guard

Raised during **validation**, from `ValidateErrorMessage::YIELD_PROTECTED_REGION` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A generator is suspended at each `yield` and resumed by a jump back to it. A
jump cannot re-enter a try block, a catch or a block guarded by a scope guard,
as the handler of the region would not be installed again.

## Example

`test_resources/generators/test8.yr`:

```ymir
// yield inside a try block
class Err over Exception {
    pub self () {}
}

fn mayThrow ()
    throws Err
{
    throw copy Err ();
}

yield gen ()-> i32 {
    {
        mayThrow ();
        yield 1;
    } catch {
        _: &Err => {}
    }
}
```

```text
Error[E4293] : cannot yield inside a try block, a catch or a scope guard
 --> test_resources/generators/test8.yr:(13,5)
13  ┃     {
    ╋     ^
14  ┃         mayThrow ();
15  ┃         yield 1;
    ╋         -----
    ┃
    = when validating test8::gen -- (test_resources/generators/test8.yr:(12,7))
    ┗━━━━━━━
```

## How to fix it

Move the `yield` out of the protected region, storing what it yields in a
variable of the generator.

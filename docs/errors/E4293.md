# E4293

> cannot <> inside a try block, a catch or a scope guard

where `<>` stands for a value the diagnostic fills in: `yield` or `await`.

Raised during **validation**, from `ValidateErrorMessage::SUSPEND_PROTECTED_REGION` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A generator is suspended at each `yield`, and an async at each `await`, and
both are resumed by a jump back to it. A jump cannot re-enter a try block, a
catch or a block guarded by a scope guard, as the handler of the region would
not be installed again.

## Example

`test_resources/generators/test8.yr`:

```ymir
// yield inside a try block
class Err over Exception {
    pub self () {}
}

fn mayThrow ()
    throws Err
{
    throw copy Err ();
}

yield gen ()-> i32 {
    {
        mayThrow ();
        yield 1;
    } catch {
        _: &Err => {}
    }
}
```

```text
Error[E4293] : cannot yield inside a try block, a catch or a scope guard
 --> test_resources/generators/test8.yr:(13,5)
13  ┃     {
    ╋     ^
14  ┃         mayThrow ();
15  ┃         yield 1;
    ╋         -----
    ┃
    = when validating test8::gen -- (test_resources/generators/test8.yr:(12,7))
    ┗━━━━━━━
```

## How to fix it

Move the `yield` or the `await` out of the protected region, storing what it
yields, or what it awaits, in a variable of the generator or of the async.

# E4040

> range index cannot be decreasing for type <>, but goes from <> to <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::DECREASING_RANGE_ACCESS` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A range index goes from a higher bound to a lower one on a type whose indices
only increase.

## How to fix it

Swap the bounds. To walk the values backwards, reverse the result rather than
the range.

# E4181

> method <> must have a body to override <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::OVERRIDE_EMPTY` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A method marked `override` has no body. Overriding replaces an implementation,
so it has to provide one.

## Example

`test_resources/diagnostics/test64.yr`:

```ymir
class A {
    pub self () {}
    pub fn foo (self) {}
}

class B over A {
    pub self () {}
    pub over foo (self);
}

fn main () { let _ = copy B (); }
```


## How to fix it

Give the method a body, or drop `override` and declare it in an abstract
class as an empty method.

# E4085

> cannot create a delegate from the method <> implicitly

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::IMPLICIT_ADDRESS_METHOD` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A method was used where a delegate is expected, without asking for its
address.

## Example

`test_resources/diagnostics/test40.yr`:

```ymir
class Foo {
    pub self () {}
    pub fn bar (self)-> i32 { 0 }
}

fn main () {
    let f = copy Foo ();
    let _: dg ()-> i32 = f.bar;
}
```

```text
Error[E4085] : cannot create a delegate from the method f.test40::Foo::bar ()-> i32 implicitly
 --> test_resources/diagnostics/test40.yr:(8,27)
 8  ┃     let _: dg ()-> i32 = f.bar;
    ╋                           ^  note: did you forget ()?
    ┃                           ┗━ note: or did you forget &?
    ┗━━━━━━━
```

## How to fix it

Write `&` before the method access.

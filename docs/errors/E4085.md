# E4085

> cannot create a delegate from the method <> implicitly

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::IMPLICIT_ADDRESS_METHOD` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A method was used where a delegate is expected, without asking for its
address.

## How to fix it

Write `&` before the method access.

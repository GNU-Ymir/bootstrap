# E4146

> <> is not an aliasable type

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::NOT_ALIASABLE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

`alias` was applied to a type that does not borrow anything, so there is
nothing to alias.

## Example

`test_resources/templates/implicit/test16.yr`:

```ymir
fn foo {alias T} (a : T) {
    a;
}

fn main () {
    foo ([1, 2, 3]);
    foo ((1, 2, 3));
}
```

```text
Error[E4146] : [i32 ; 3us] is not an aliasable type
 --> test_resources/templates/implicit/test16.yr:(1,15)
 1  ┃ fn foo {alias T} (a : T) {
    ╋               ^
   ...
 --> test_resources/templates/implicit/test16.yr:(6,10)
 6  ┃     foo ([1, 2, 3]);
    ╋          ^
    ┗━━━━━━━
```

## How to fix it

Remove the `alias`.

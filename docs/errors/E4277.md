# E4277

> var declaration must at least have a type or a value

Raised during **validation**, from `ValidateErrorMessage::VAR_DECL_WITH_NOTHING` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A `var` declaration has neither a type nor a value, so nothing says what it
holds.

## How to fix it

Give it a type, a value, or both.

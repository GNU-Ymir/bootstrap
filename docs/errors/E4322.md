# E4322

> the affectation of a part of <> is only defined for the operator <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::PART_AFFECT_OPERATOR` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A part of an array or a slice -- a range `a [x .. y]` or several indices
`a [i, j]` -- was affected with an operator other than the plain one. The
affectation of a part is defined for `=` alone.

## Example

`test_resources/index_ops/test12.yr`:

```ymir
fn main () {
    let dmut a = [1, 2, 3];
    a [0 .. 2] += [1, 1];
}
```

```text
Error[E4322] : the affectation of a part of mut [mut i32 ; 3us] is only defined for the operator =
 --> test_resources/index_ops/test12.yr:(5,7)
 5  ┃     a [0 .. 2] += [1, 1];
    ╋       ^           -
    ┗━━━━━━━
```

## How to fix it

Affect each element with the compound operator, or compute the new part and
affect it with `=`.

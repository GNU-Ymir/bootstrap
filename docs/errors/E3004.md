# E3004

> only local global variables may be declared thread-local

Raised during **declaration**, from `DeclareErrorMessage::DECL_GLOB_THREAD_EXTERN` (`src/ymirc/semantic/declarator/errors.yr`).

## What it means

A global variable is declared both thread-local and `extern`. Thread-local
storage is allocated by the module that defines the variable, so an external
declaration cannot ask for it.

## Example

`test_resources/global/test10.yr`:

```ymir
@thread
extern lazy i : i32;
```

```text
Error[E3004] : only local global variables may be declared thread-local
 --> test_resources/global/test10.yr:(1,2)
 1  ┃ @thread
    ╋  ^^^^^^
    ┃ Note :
    ┃  --> test_resources/global/test10.yr:(2,8)
    ┃  2  ┃ extern lazy i : i32;
    ┃     ╋        ^^^^
    ┃     ┗━━━━━━━
    ┗━━━━━┻━
```

## How to fix it

Drop the thread-local decorator on the `extern` declaration; it belongs on the
definition.

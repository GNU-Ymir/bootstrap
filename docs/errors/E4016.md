# E4016

> class alias operator :[ is only usable on class, record or entity types, not <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::CLASS_ALIAS_INDEX_NO_CLASS` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

The class alias index operator `:[` was applied to a type it is not defined
for; it only applies to classes, records and entities.

## How to fix it

Use the plain `[` index operator.

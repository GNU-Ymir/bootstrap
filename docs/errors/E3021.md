# E3021

> custom attribute <> is not valid on functions

where `<>` stands for a value the diagnostic fills in.

Raised during **declaration**, from `DeclareErrorMessage::UNDEFINED_ATTRIBUTE_FOR_FUNCTION` (`src/ymirc/semantic/declarator/errors.yr`).

## What it means

A custom attribute was applied to a function, and the attribute does not accept
functions.

## Example

`test_resources/diagnostics/test10.yr`:

```ymir
@abstract
fn foo () {}

fn main () { foo (); }
```

```text
Error[E3021] : custom attribute abstract is not valid on functions
 --> test_resources/diagnostics/test10.yr:(1,2)
 1  ┃ @abstract
    ╋  ^^^^^^^^
    ┗━━━━━━━
```

## How to fix it

Same as [E3019](E3019.md).

# E4106

> the identifier <> describes a native type but has no meaning within this context

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::IS_NATIVE_TYPE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

The name of a native type was used where it has no meaning -- as a value, for
instance, rather than as a type.

## How to fix it

Use the identifier where a type is expected, or use a value of that type.

# E4043

> parameter with a default value cannot be a reference

Raised during **validation**, from `ValidateErrorMessage::DEFAULT_VAR_REF` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A parameter is declared `ref` and given a default value. A reference parameter
borrows the caller's storage; a default value has no storage in the caller to
borrow.

## How to fix it

Drop either the `ref` or the default value.

# E1010

> invalid numeric value formatted in decimal

Raised during **lexing**, from `LexingErrorMessage::INVALID_DEC_NUMBER` (`src/ymirc/lexing/errors.yr`).

## What it means

A decimal literal contains a character that is neither a digit nor a valid
suffix.

## Example

`test_resources/lexing/test25.yr`:

```ymir
let x = 12a4;
```

```text
Error[E1010] : invalid numeric value formatted in decimal
 --> main.yr:(1,9)
 1  ┃ let x = 12a4;
    ╋         ^^^^
    ┃ Note :
    ┃  --> main.yr:(1,11)
    ┃  1  ┃ let x = 12a4;
    ┃     ╋           ^
    ┃     ┗━━━━━━━
    ┗━━━━━┻━
```

## How to fix it

Remove the offending character, or separate the number from what follows it.
`_` is accepted inside a number as a digit separator (`1_000_000`).

# E4044

> field must have a referenceable name

Raised during **validation**, from `ValidateErrorMessage::CLASS_FIELD_NO_NAME` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A field was declared without a name that can be referred to.

## Example

`test_resources/diagnostics/test100.yr`:

```ymir
// a class field named _
class Point {
    let _ : i32 = 1;
    pub self () {}
}

fn main () {
    let _ = copy Point ();
}
```

## How to fix it

Give the field a name.

# E3027

> undefined symbol <>

where `<>` stands for a value the diagnostic fills in.

Raised during **declaration**, from `DeclareErrorMessage::UNDEF_VAR` (`src/ymirc/semantic/declarator/errors.yr`).

## What it means

A name used in a declaration resolves to nothing: no symbol of that name is
visible from this module.

## Example

`test_resources/regressions/use_is_file_local/test1/foo.yr`:

```ymir
in foo;
use std::io;

mod bar;
```

```text
Error[E3027] : undefined symbol println
 --> test_resources/regressions/use_is_file_local/test1/foo/bar.yr:(5,5)
 5  ┃     println ("in bar");
    ╋     ^^^^^^^
    ┗━━━━━━━
```

## How to fix it

Check the spelling, and check that the module defining the symbol is
imported. A symbol that exists but is not visible gives
[E3016](E3016.md) instead, which distinguishes a missing import from a
protection problem.

# E4211

> rethrowing an exception of type <> inside a scope guard is forbidden

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::THROW_SCOPE_GUARD_RETHROW` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A caught exception is rethrown from inside a scope guard, which would let it
escape the guard, cf. [E4210](E4210.md).

## Example

`test_resources/scope_guards/test11.yr`:

```ymir
fn foo ()
    throws AssertError;

fn main () {
    {

    } exit {
        foo ();
    }
}
```

```text
Error[E4211] : rethrowing an exception of type core::exception::assertion::AssertError inside a scope guard is forbidden
 --> test_resources/scope_guards/test11.yr:(7,7)
 7  ┃     } exit {
    ╋       ^^^^
   ...
 --> test_resources/scope_guards/test11.yr:(8,13)
 8  ┃         foo ();
    ╋             ^
    ┗━━━━━━━
```

## How to fix it

Handle the exception inside the guard rather than rethrowing it.

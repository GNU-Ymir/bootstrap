# E4156

> <> is a value parameter, and cannot be used as a lvalue

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::NOT_A_LVALUE_PARAM` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A parameter passed by value was used as an lvalue in a way that expects the
caller's storage.

## Example

`test_resources/diagnostics/test59.yr`:

```ymir
fn foo (x: i32) {
    x = 1;
}

fn main () { foo (1); }
```

```text
Error[E4156] : x is a value parameter, and cannot be used as a lvalue
 --> test_resources/diagnostics/test59.yr:(2,5)
 2  ┃     x = 1;
    ╋     ^ ^
    ┗━━━━━━━
```

## How to fix it

Declare the parameter `ref` if the caller's value has to be written, or bind
the value to a local variable.

# E4183

> cannot override final method <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::OVERRIDE_FINAL` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A method marked `final` in an ancestor is being overridden. `final` says the
implementation is the last word.

## Example

`test_resources/diagnostics/test65.yr`:

```ymir
class A {
    pub self () {}
    @final pub fn foo (self) {}
}

class B over A {
    pub self () {}
    pub over foo (self) {}
}

fn main () { let _ = copy B (); }
```

```text
Error[E4183] : cannot override final method test65::A::foo ()-> void
 --> test_resources/diagnostics/test65.yr:(3,19)
 3  ┃     @final pub fn foo (self) {}
    ╋                   ^^^
   ...
 --> test_resources/diagnostics/test65.yr:(8,14)
 8  ┃     pub over foo (self) {}
    ╋              ^^^
    ┗━━━━━━━
```

## How to fix it

Remove `final` from the ancestor method, or give the new method a different
name.

# E4183

> cannot override final method <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::OVERRIDE_FINAL` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A method marked `final` in an ancestor is being overridden. `final` says the
implementation is the last word.

## How to fix it

Remove `final` from the ancestor method, or give the new method a different
name.

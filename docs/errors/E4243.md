# E4243

> decorator <> is not applicable for values

**Retired.** The message this code named was deleted from the compiler: no
code raised it any more. Nothing produces E4243 today.

The code is not reused and not reassigned to another diagnostic, so an E4243
printed by an older compiler still means what is quoted above. This page stays
as its record.

It was raised during **validation**, from `ValidateErrorMessage::UNDEF_DECORATOR_VALUE`.

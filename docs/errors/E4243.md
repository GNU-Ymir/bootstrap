# E4243

> decorator <> is not applicable for values

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::UNDEF_DECORATOR_VALUE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A decorator that applies to types was written on a value.

## How to fix it

Remove it, or apply it to the type instead.

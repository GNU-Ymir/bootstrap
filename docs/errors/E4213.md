# E4213

> tuple left affectation is only defined for the operator <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::TUPLE_AFFECT_OPERATOR` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A tuple on the left of an assignment was used with an operator other than the
plain one. Destructuring assignment is defined for `=` alone.

## Example

`test_resources/lit_tuples/test23.yr`:

```ymir
fn foo ()-> (i32, i32);

fn main () {
    let mut a = 0, mut b = 0;

    (a, b) += foo ();
}
```

```text
Error[E4213] : tuple left affectation is only defined for the operator =
 --> test_resources/lit_tuples/test23.yr:(6,5)
 6  ┃     (a, b) += foo ();
    ╋     ^      ^^
    ┗━━━━━━━
```

## How to fix it

Split the compound assignment into a read and a write.

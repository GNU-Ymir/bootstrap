# E4056

> <> scope guard value must be of type void, not <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::EXIT_SCOPE_VALUE_TYPE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

The body of a scope guard produces a value. A guard runs while a scope is being
left, and there is nothing to receive what it would produce.

## How to fix it

Make the guard body end in a statement rather than a value -- assign the value
to something, or discard it.

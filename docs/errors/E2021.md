# E2021

> unexpected tag list <>

where `<>` stands for a value the diagnostic fills in.

Raised during **parsing**, from `SyntaxErrorMessage::UNEXPECTED_TAGS` (`src/ymirc/syntax/errors.yr`).

## What it means

A tag list applies to the declaration written after it, in a module, a
protection block or an extern block. It was written where no such declaration
follows: before a `use`, a `pub { ... }` or `extern { ... }` block, the end of a
block, or inside a tag.

The tags of a declaration are also written before its attributes and its
protection, `#[a] @inline pub fn foo`: written after either, `pub #[a] fn foo`,
the list is refused with a note saying so.

## Example

`test_resources/diagnostics/test163.yr`:

```ymir
// a tag list written before what is not a declaration
#[route ("/f")]
use std::io;

fn main () {}
```

```text
Error[E2021] : unexpected tag list {route ("/f")}
 --> test_resources/diagnostics/test163.yr:(2,1)
 2  ┃ #[route ("/f")]
    ╋ ^^
 3  ┃ use std::io;
    ╋ ---
    ┗━━━━━━━
```

## How to fix it

Move the list onto the declaration it was meant for, before its attributes and
its protection, or tag each declaration of a block one by one.

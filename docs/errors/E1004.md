# E1004

> line break encountered inside a single-line string literal

Raised during **lexing**, from `LexingErrorMessage::RETURN_IN_SINGLE_LINE_STRING` (`src/ymirc/lexing/errors.yr`).

## What it means

A `"` string literal contains a raw line break. A single-line literal ends at
the end of its line, so the closing quote can never be reached.

## Example

`test_resources/lexing/test14.yr`:

```ymir
let x = "abc
let y = 1;
```

```text
Error[E1004] : line break encountered inside a single-line string literal
 --> main.yr:(1,9)
 1  ┃ let x = "abc

    ╋         ^   ^
    ┗━━━━━━━
```

## How to fix it

Either close the literal before the end of the line and concatenate the pieces,
or use the multiline form `""" ... """`, which accepts line breaks. `\n`
inside a single-line literal also works when a line break is all that is wanted.

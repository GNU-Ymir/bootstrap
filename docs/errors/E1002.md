# E1002

> unterminated comment block <>

where `<>` stands for a value the diagnostic fills in.

Raised during **lexing**, from `LexingErrorMessage::UNTERMINATED_COMMENT` (`src/ymirc/lexing/errors.yr`).

## What it means

The lexer reached the end of the file while still inside a comment block. The
opening marker it reports was never matched by its closing one.

## Example

`test_resources/lexing/test13.yr`:

```ymir
fn main () {
    /* unterminated
```

```text
Error[E1002] : unterminated comment block */
 --> main.yr:(2,5)
 2  ┃     /* unterminated
    ╋     ^^
    ┗━━━━━━━
```

## How to fix it

Close the comment. `/*` is closed by `*/` and `/**` by `*/` as well; a comment
opened inside another one has to be closed too, since block comments nest.

# E4245

> undefined symbol <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::UNDEF_VAR` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A name resolves to nothing visible from here.

## Example

`test_resources/aka/test9.yr`:

```ymir
def A = V;
def V = A;
```

## How to fix it

Check the spelling, and check that the module defining the symbol is
imported, cf. [E3027](E3027.md).

# E4245

> undefined symbol <>

where `<>` stands for a value the diagnostic fills in.

**Retired.** The message is still raised, but only as a note under
[E4110](E4110.md), which documents it, and it no longer carries a code of its own.
A name that resolves to nothing is reported as [E3027](E3027.md).

The code is not reused and not reassigned to another diagnostic, so an E4245
printed by an older compiler still means what is quoted above. This page stays
as its record.

It was raised during **validation**, from `ValidateErrorMessage::UNDEF_VAR`.

# E4252

> referencing the value has no effect

Raised during **validation**, from `ValidateErrorMessage::UNECESSARY_REFERENCE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A reference was taken where the value is used as a value anyway.

## Example

`test_resources/for_loops/arrays/test13.yr`:

```ymir
fn main () {
    let dmut a = [1, 2, 3, 4];
    for x in ref a {
        x;
    }
}
```

```text
Error[E4252] : referencing the value has no effect
 --> test_resources/for_loops/arrays/test13.yr:(3,14)
 3  ┃     for x in ref a {
    ╋              ^^^
    ┗━━━━━━━
```

## How to fix it

Drop the reference.

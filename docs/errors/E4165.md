# E4165

> type <> is not a movable type

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::NOT_MOVABLE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

`move` was applied to a type that is not movable. Moving is defined only for
types that carry an identity worth transferring.

## Example

`test_resources/diagnostics/test60.yr`:

```ymir
fn main () {
    let x = 1;
    let _ = move x;
}
```

```text
Error[E4165] : type i32 is not a movable type
 --> test_resources/diagnostics/test60.yr:(3,13)
 3  ┃     let _ = move x;
    ╋             ^^^^
    ┗━━━━━━━
```

## How to fix it

Copy the value instead, or make the type movable.

# E4143

> loop test is always false, loop is never entered

Raised during **validation**, from `ValidateErrorMessage::NEVER_ENTERED_LOOP` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A loop condition is always false, so the body never runs.

## Example

`test_resources/control_flow/test3.yr`:

```ymir
fn main () {
    let a = [1, 2, 3];
    if let [x, y, z] = a { // error, len of /a/ is /cte/
        x;
        y;
        z;
    }

    if (a.len <= 3) {
    }

    if (a.len >= 4) {
    }
    
    while a.len <= 3 {
    }

    while a.len >= 4 {
    }

}
```

```text
Error[E4143] : loop test is always false, loop is never entered
 --> test_resources/control_flow/test3.yr:(18,17)
18  ┃     while a.len >= 4 {
    ╋                 ^^
    ┗━━━━━━━
```

## How to fix it

Remove the loop, or fix the condition. This most often means the variable the
condition tests is not the one the loop updates.

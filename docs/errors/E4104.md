# E4104

> symbol <> has errors

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::INVALID_SYMBOLS` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A symbol this code uses could not be validated, so the compiler cannot say
anything about the use.

It is never printed on its own: the error on the symbol is reported instead,
once, whatever the number of uses reaching it. The uses it went through are
the `when validating` lines under that error. A language server client still
receives it at each use.

## Example

`test_resources/aka/test9.yr`:

```ymir
def A = V;
def V = A;
```

The use of `V` by `A` and of `A` by `V` both raise this error, which is
reported as the failure under them:

```text
Error[E4068] : the name alias test9::A cannot be validated due to forward reference
 --> test_resources/aka/test9.yr:(1,5)
 1  ┃ def A = V;
    ╋     ^
    ┃
    = when validating test9::V -- (test_resources/aka/test9.yr:(2,5))
    = when validating test9::A -- (test_resources/aka/test9.yr:(1,5))
    ┗━━━━━━━
```

## How to fix it

Fix the reported errors on the symbol. This diagnostic disappears with
them.

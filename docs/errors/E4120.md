# E4120

> the type <> that is used as a map key must always be immutable

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::MAP_KEY_MUTABLE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A mutable type is used as a map key. A key that could change after insertion
would move in the table without the map noticing.

## How to fix it

Use the immutable form of the type as the key.

# E4120

> the type <> that is used as a map key must always be immutable

**Retired.** The message this code named was deleted from the compiler: no
source could reach it. A map key type is always validated as immutable: a mutable key raises [E4083](E4083.md) instead.

The code is not reused and not reassigned to another diagnostic, so an E4120
printed by an older compiler still means what is quoted above. This page stays
as its record.

It was raised during **validation**, from `ValidateErrorMessage::MAP_KEY_MUTABLE`.

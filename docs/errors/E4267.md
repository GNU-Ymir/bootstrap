# E4267

> operator <> is useless, the left operand of type <> always has a value

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::USELESS_OPTION_OR_ELSE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

An option fallback operator was applied to a value that always holds one, so
the fallback can never run.

## Example

`test_resources/lit_options/test21.yr`:

```ymir
// the left operand always has a value, the right one would never be evaluated
fn main () {
    let _a_ : i32 = 12 ?? 42;
}
```

```text
Error[E4267] : operator ?? is useless, the left operand of type i32 always has a value
 --> test_resources/lit_options/test21.yr:(3,24)
 3  ┃     let _a_ : i32 = 12 ?? 42;
    ╋                        ^^
    ┗━━━━━━━
```

## How to fix it

Remove the operator and use the value directly.

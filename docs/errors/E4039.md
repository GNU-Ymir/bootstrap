# E4039

> cannot declare a variable of type <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::DECLARE_VOID_VAR` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A variable was declared with a type that has no values to hold -- `void`, or a
type reduced to nothing.

## Example

`test_resources/lit_slices/test21.yr`:

```ymir
fn foo () {
    for i in copy [] {}
}
```

```text
Error[E4039] : cannot declare a variable of type void
 --> test_resources/lit_slices/test21.yr:(2,9)
 2  ┃     for i in copy [] {}
    ╋         ^
    ┗━━━━━━━
```

## How to fix it

Remove the declaration. When the value came from a call, the function returns
nothing and the call should be a statement rather than an initializer.

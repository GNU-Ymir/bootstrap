# E5003

> failed to read YIL byte file <>, file format error

where `<>` stands for a value the diagnostic fills in.

Raised during **lowering (YIL)**, from `SerializeYILErrorMessage::FAILED_TO_PARSE_BYTE_FILE` (`src/ymirc/lint/serialize/errors.yr`).

## What it means

A `.yil` file was read but its content is not valid YIL bytecode. Most often
the file was produced by a different version of the compiler, or it was
truncated by an interrupted build.

## How to fix it

Recompile the package that produced the file with the current compiler. A
stale build directory left over from an earlier version is the usual cause.

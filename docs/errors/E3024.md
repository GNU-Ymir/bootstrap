# E3024

> custom attribute <> is not valid on template methods

where `<>` stands for a value the diagnostic fills in.

Raised during **declaration**, from `DeclareErrorMessage::UNDEFINED_ATTRIBUTE_FOR_TEMPLATE_METHOD` (`src/ymirc/semantic/declarator/errors.yr`).

## What it means

A custom attribute was applied to a template method, and the attribute does not
accept template methods.

## How to fix it

Same as [E3019](E3019.md). A template method is only a declaration until it is
instantiated, which is why attributes that act on a concrete symbol cannot apply
to it.

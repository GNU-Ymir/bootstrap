# E4034

> creating an instance of class <> on the stack is prohibited

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::CTOR_CLASS_STACK` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A class instance was created on the stack. Classes in Ymir are reference
types, allocated on the heap and reached through a reference.

## How to fix it

Construct it with `copy`, which allocates the instance and gives back the
reference.

# E4034

> creating an instance of class <> on the stack is prohibited

**Retired.** The message this code named was deleted from the compiler: no
source could reach it. A class constructor call always allocates its instance, with or without `copy`.

The code is not reused and not reassigned to another diagnostic, so an E4034
printed by an older compiler still means what is quoted above. This page stays
as its record.

It was raised during **validation**, from `ValidateErrorMessage::CTOR_CLASS_STACK`.

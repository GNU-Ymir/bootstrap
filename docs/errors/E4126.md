# E4126

> cannot alias a lazy value, maybe alias and lazy keywords are inverted? (lazy alias V)

Raised during **validation**, from `ValidateErrorMessage::MISMATCH_ALIAS_LAZY` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

`alias` was applied to a `lazy` value; the keywords are inverted.

## Example

`test_resources/lazyness/test6.yr`:

```ymir
fn main () {
    let dmut i = copy [1, 2, 3];
    let lazy dmut a = copy (lazy i);
    let lazy dmut b = alias (lazy i);
}
```

```text
Error[E4126] : cannot alias a lazy value, maybe alias and lazy keywords are inverted? (lazy alias V)
 --> test_resources/lazyness/test6.yr:(4,23)
 4  ┃     let lazy dmut b = alias (lazy i);
    ╋                       ^^^^^  ^^^^
    ┗━━━━━━━
```

## How to fix it

Swap them: `lazy alias v`.

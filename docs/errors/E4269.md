# E4269

> useless runtime assertion for a test that is always true

Raised during **validation**, from `ValidateErrorMessage::USELESS_RUNTIME_ASSERT` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A run time assertion tests something the compiler already proved true, so it
can never fire.

## How to fix it

Remove the assertion, or make it a `cte assert` if the compile time check is
what was wanted.

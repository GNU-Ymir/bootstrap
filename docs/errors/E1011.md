# E1011

> invalid numeric value formatted in binary

Raised during **lexing**, from `LexingErrorMessage::INVALID_BIN_NUMBER` (`src/ymirc/lexing/errors.yr`).

## What it means

A literal introduced by `0b` contains a character other than `0` or `1`.

## Example

`test_resources/lexing/test19.yr`:

```ymir
let x = 0b1021;
```

```text
Error[E1011] : invalid numeric value formatted in binary
 --> main.yr:(1,9)
 1  ┃ let x = 0b1021;
    ╋         ^^^^^^
    ┃ Note :
    ┃  --> main.yr:(1,13)
    ┃  1  ┃ let x = 0b1021;
    ┃     ╋             ^
    ┃     ┗━━━━━━━
    ┗━━━━━┻━
```

## How to fix it

Use only `0` and `1` in a binary literal, with `_` as an optional separator.
Write the value in another base if binary is not what was wanted.

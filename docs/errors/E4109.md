# E4109

> the size of the list comprehension, constructed from type <>, must be determinable at compile time

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::LIST_COMPR_SIZE_CTE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

The length of a list comprehension is not computable at compile time, and the
type it is being built into needs a statically known size.

## Example

`test_resources/for_loops/lst_compr/test12.yr`:

```ymir
fn main () {
    let mut a = copy [1, 2, 3];
    let _ = [i for i in a];
}
```

```text
Error[E4109] : the size of the list comprehension, constructed from type mut [i32], must be determinable at compile time
 --> test_resources/for_loops/lst_compr/test12.yr:(3,25)
 3  ┃     let _ = [i for i in a];
    ╋                         ^  note: did you mean to enclose it within a copy?
    ┗━━━━━━━
```

## How to fix it

Build a slice, whose length is a run time value, or make the bounds of the
comprehension compile time constants.

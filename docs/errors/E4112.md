# E4112

> macro validation is not complete, some tokens remain unassociated  <> <> <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::MACRO_REST` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A macro rule matched a prefix of the call and left tokens over. A rule has to
consume everything it is given.

## Example

`test_resources/lit_macro/test7.yr`:

```ymir
/*
 * A macro call matching a constructor, but whose content is not
 * entirely consumed by it
 */

macro one {
    self (a=__operand) skips (" ") #{
        #(a)
    }
}

fn foo () {
    let x = one#{ 1 2 };

    x;
}
```

```text
Error[E4112] : macro validation is not complete, some tokens remain unassociated
==
2
==
 --> test_resources/lit_macro/test7.yr:(13,21)
13  ┃     let x = one#{ 1 2 };
    ╋                     ^^
    ┗━━━━━━━
```

## How to fix it

Extend the rule to cover the remaining tokens, or shorten the call.

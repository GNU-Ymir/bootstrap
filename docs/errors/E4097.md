# E4097

> the type <> is not complete

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::INCOMPLETE_TYPE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A type is used where its size or its layout is needed, and it is not finished
being validated.

## Example

`test_resources/lit_class/ctors/test26.yr`:

```ymir
fn foo (_ : &A)-> i32;
fn bar (_ : &A)-> i32;

class A {
    let x : i32;

    pub self ()
        with x = foo (self)
    {}
}

class B over A {
    let z : i32;

    pub self ()
        with z = bar (super)
    {}
}
```

```text
Error[E4097] : the type &(test26::A)::fields is not complete
 --> test_resources/lit_class/ctors/test26.yr:(7,9)
 7  ┃     pub self ()
    ╋         ^^^^  note: when creating the value self of &(test26::A)::fields
   ...
 --> test_resources/lit_class/ctors/test26.yr:(8,23)
 8  ┃         with x = foo (self)
    ╋                       ^^^^
    ┗━━━━━━━
```

## How to fix it

Break the cycle, cf. [E4017](E4017.md).

# E4203

> template specialization fails with <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::TEMPLATE_SPECIALIZATION_FAILS_SIMPLE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A template specialization failed, with the reason in the message and no
specific symbol to attribute it to.

## Example

`test_resources/diagnostics/test79.yr`:

```ymir
fn main () {
    let f = copy (|| => { 1 });
    f ();
}
```

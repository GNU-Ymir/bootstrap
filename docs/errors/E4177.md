# E4177

> option matcher <> only applies to option values not <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::OPTION_MATCHER` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

An option pattern was matched against something that is not an option.

## How to fix it

Match the option itself, or use a pattern for the type at hand.

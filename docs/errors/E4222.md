# E4222

> undefined operator <> for type <> and field <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::UNDEFINED_BIN_ACC_OP` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A binary operator is not defined between the type and the field named.

## Example

`test_resources/regressions/float_properties/test2.yr`:

```ymir
in test2;

fn main () {

    f32::foo;
    f64::bar;
    f80::baz;
    fsize::bad;


}
```

```text
Error[E4222] : undefined operator :: for type f32 and field foo
 --> test_resources/regressions/float_properties/test2.yr:(5,8)
 5  ┃     f32::foo;
    ╋        ^^
    ┗━━━━━━━
```

## How to fix it

Check the field: a field method may be needed, or the operator may have to be
defined on the field type.

# E5005

> malformed bytecode

Raised during **lowering (YIL)**, from `SerializeYILErrorMessage::MALFORMED_BYTECODE` (`src/ymirc/lint/serialize/errors.yr`).

## What it means

A `.yil` file is structurally invalid: the reader found a byte sequence that
cannot be decoded at the position it had reached. As with [E5003](E5003.md),
this points at a file produced by another compiler version or at a truncated
one.

## How to fix it

Recompile the package that produced the file. If it was produced by the
current compiler and the error persists, the file is a compiler bug worth
reporting with the code and the file.

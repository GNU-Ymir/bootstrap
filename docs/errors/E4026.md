# E4026

> cannot construct an instance of class <> that is abstract

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::CONSTRUCT_ABSTRACT_CLASS` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

An instance of an abstract class was constructed. An abstract class has methods
with no body, so an instance of it would have nothing to call.

## How to fix it

Construct a derived class that implements the empty methods, or give the
class bodies for them and drop `abstract`.

# E4254

> constructor of the union type <> initializes multiple fields <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::UNION_CTOR_MULTIPLE_FIELDS` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A union constructor initializes more than one field. The fields of a union
share their storage, so only one of them holds a value at a time.

## How to fix it

Initialize a single field.

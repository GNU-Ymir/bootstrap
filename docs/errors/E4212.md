# E4212

> <> parameters <> expected, but <> <> provided

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::TOO_FEW_PARAMETERS` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A call provides a different number of arguments than the callee takes. Both
counts are in the message.

## Example

`test_resources/data_record/ctors/test2.yr`:

```ymir
@data
record Foo {
    let x: i32;
}

fn main() {
    let a = Foo();
    let b = Foo(x-> 34);
    a.x;
    b.x;
}
```

```text
Error[E4212] : 1 parameters is expected, but 0 are provided
 --> test_resources/data_record/ctors/test2.yr:(7,16)
 7  ┃     let a = Foo();
    ╋                ^
    ┗━━━━━━━
```

## How to fix it

Pass the missing arguments. Note that a parameter with a default value is only
reachable by name, so it still counts in the arity of a positional call.

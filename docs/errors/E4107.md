# E4107

> call operator is not defined for value <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::IS_NOT_CALLABLE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A value was called and its type defines no call operator.

## Example

`test_resources/diagnostics/test48.yr`:

```ymir
fn main () {
    let x = 1;
    x ();
}
```

```text
Error[E4107] : call operator is not defined for value 1
 --> test_resources/diagnostics/test48.yr:(2,13)
 2  ┃     let x = 1;
    ╋             ^
    ┗━━━━━━━
```

## How to fix it

Check that the value is the function, the function pointer or the delegate
intended. A class can be made callable by defining the call operator on it.

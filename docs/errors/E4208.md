# E4208

> the prototype of the function <> declares a possible throw of an exception of type <>, but the function never throws it

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::THROWS_NOT_USED` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A function declares that it throws an exception its body can never raise. The
declaration forces every caller to handle something that cannot happen.

## Example

`test_resources/lit_class/ctors/test8.yr`:

```ymir
fn foo (t : bool = false)-> i32 {
    t;
    12
}

record A {
    let a : i32 = 0;

    pub self ()
        with a = foo ()
        throws AssertError
    {}

}
```

```text

 --> test_resources/lit_class/ctors/test8.yr:(9,9)
 9  ┃     pub self ()
    ╋         ^^^^
    ┃ Note :
    ┃  --> test_resources/lit_class/ctors/test8.yr:(11,16)
    ┃ 11  ┃         throws AssertError
    ┃     ╋                ^^^^^^^^^^^
    ┃     ┗━━━━━━━
    ┗━━━━━┻━
```

## How to fix it

Remove the exception from the `throws` clause.

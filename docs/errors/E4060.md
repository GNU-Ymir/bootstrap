# E4060

> field access method must return a value

Raised during **validation**, from `ValidateErrorMessage::FIELD_METHOD_ACCESS_NO_RETURN` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A field access method has no return value. A field access method stands in for
reading a field, so it has to produce one.

## Example

`test_resources/diagnostics/test34.yr`:

```ymir
class Foo {
    pub self () {}
    @field pub fn bar (self) {}
}

fn main () { let f = copy Foo (); f.bar; }
```

# E4178

> overflow capacity for type <> = <>, maximum value is <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::OVERFLOW_CAPACITY` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A value the compiler computed does not fit in its type. The type, the value and
the maximum it can hold are all in the message.

## Example

`test_resources/enumeration/test15.yr`:

```ymir
enum X : i32
| A = 1
| B = 900;

fn main () {
    let mut a : i8 = X::A;
    a = X::B;

}
```

```text
Error[E4178] : overflow capacity for type mut i8 = 900, maximum value is 127
 --> test_resources/enumeration/test15.yr:(3,7)
 3  ┃ | B = 900;
    ╋       ^^^
    ┗━━━━━━━
```

## How to fix it

Use a wider type, or reduce the value.

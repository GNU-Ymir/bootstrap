# E4174

> do while loop test is always false, the loop is always entered exactly once, so the branching construct is useless

**Retired.** The message this code named was deleted from the compiler: no
code raised it any more. Nothing produces E4174 today.

The code is not reused and not reassigned to another diagnostic, so an E4174
printed by an older compiler still means what is quoted above. This page stays
as its record.

It was raised during **validation**, from `ValidateErrorMessage::ONE_ITER_LOOP`.

# E4174

> do while loop test is always false, the loop is always entered exactly once, so the branching construct is useless

Raised during **validation**, from `ValidateErrorMessage::ONE_ITER_LOOP` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A `do while` loop has a condition that is always false, so the body runs
exactly once and the loop construct adds nothing.

## How to fix it

Replace the loop with its body, or fix the condition.

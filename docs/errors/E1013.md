# E1013

> expected sign information in hexadecimal floating-point literal

Raised during **lexing**, from `LexingErrorMessage::MISSING_HEX_FLOAT_SIGN` (`src/ymirc/lexing/errors.yr`).

## What it means

A hexadecimal floating-point literal has a `p` exponent marker that is not
followed by a sign. The exponent of a hexadecimal float is written with an
explicit `+` or `-`.

## Example

`test_resources/lexing/test28.yr`:

```ymir
let x = 0x1.8p;
```

```text
Error[E1013] : expected sign information in hexadecimal floating-point literal
 --> main.yr:(1,9)
 1  ┃ let x = 0x1.8p;
    ╋         ^^^
    ┗━━━━━━━
```

## How to fix it

Write the sign: `0x1.8p+3` rather than `0x1.8p3`.

# E4319

> method <> must be a generator to override the generator <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::OVERRIDE_GENERATOR_NO_GENERATOR` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

An ordinary method tries to override a generator, declared by `yield`. Being a
generator is part of the contract of a method, even when the overriding method
returns the same handle type, cf. [E4320](E4320.md).

## Example

`test_resources/generators/test85.yr`:

```ymir
// a method overriding a generator must be a generator
yield gen ()-> i32 {
    yield 1;
}

class A {
    pub self () {}

    pub yield f (self)-> i32 {
        yield 1;
    }
}

class B over A {
    pub self () {}

    pub over f (self)-> (yield-> i32) {
        gen ()
    }
}

fn main () {
    let _ = B ();
}
```

## How to fix it

Declare the overriding method with `over yield`, and yield its values.

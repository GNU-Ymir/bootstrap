# E4036

> using a deep copy instead of a one level copy is prohibited when constructing a map <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::CTOR_MAP_DCOPY` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A map was constructed with `dcopy` where `copy` is required, cf.
[E4033](E4033.md).

## Example

`test_resources/lit_map/test12.yr`:

```ymir
// a map is built one level deep, so a deep copy of a map literal is refused
fn main () {
    let _m_ = dcopy [1 => 2];
}
```

```text
Error[E4036] : using a deep copy instead of a one level copy is prohibited when constructing a map mut [i32 => mut i32]
 --> test_resources/lit_map/test12.yr:(3,21)
 3  ┃     let _m_ = dcopy [1 => 2];
    ╋                     ^
    ┃
    = help: replace dcopy by the simple copy operator
    ┃
 3  -     let _m_ = dcopy [1 => 2];
 3  +     let _m_ = copy [1 => 2];
    ┃
    = when validating test12::main -- (test_resources/lit_map/test12.yr:(2,4))
    ┗━━━━━━━
```

## How to fix it

Use `copy` to construct the map.

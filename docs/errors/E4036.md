# E4036

> using a deep copy instead of a one level copy is prohibited when constructing a map <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::CTOR_MAP_DCOPY` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A map was constructed with `dcopy` where `copy` is required, cf.
[E4033](E4033.md).

## How to fix it

Use `copy` to construct the map.

# E2018

> the filter of a for loop cannot have an else branch

Raised during **parsing**, from `SyntaxErrorMessage::FOR_FILTER_ELSE` (`src/ymirc/syntax/errors.yr`).

## What it means

The content of a `for` loop is a block, a nested `for`, a `match`, or an `if`
or `if let` filter guarding a block: `for i in 0 .. 10 if i % 2 == 0 { ... }`,
`for k in keys if let Ok(v) = m[k] { ... }`. The filter selects
the iterations the block runs for, it is not a conditional, and there is no
iteration left for an `else` to run.

## Example

`test_resources/diagnostics/test152.yr`:

```ymir
fn main () {
    let mut sum = 0;
    for i in 0 .. 4 if i % 2 == 0 {
        sum += i;
    } else {
        sum -= i;
    }

    let _s_ = sum;
}
```

```text
Error[E2018] : the filter of a for loop cannot have an else branch
 --> test_resources/diagnostics/test152.yr:(5,7)
 3  ┃     for i in 0 .. 4 if i % 2 == 0 {
    ╋                     --  note: filter of the loop
 4  ┃         sum += i;
 5  ┃     } else {
    ╋       ^^^^
    ┗━━━━━━━
```

## How to fix it

Put the conditional inside the braces of the loop:

```ymir
for i in 0 .. 4 {
    if i % 2 == 0 {
        sum += i;
    } else {
        sum -= i;
    }
}
```

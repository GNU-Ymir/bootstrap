# E3041

> custom attribute <> is not valid on modules

where `<>` stands for a value the diagnostic fills in.

Raised during **declaration**, from `DeclareErrorMessage::UNDEFINED_ATTRIBUTE_FOR_MODULE` (`src/ymirc/semantic/declarator/errors.yr`).

## What it means

A custom attribute was applied to a module declared in its parent, and the
attribute does not accept modules. `@companion` is the only attribute a module
takes.

## Example

`test_resources/companion/test12.yr`:

```ymir
in test12;

class X {
    pub self () {}
}

@final
mod X {
}

fn main () {
}
```

```text
Error[E3041] : custom attribute final is not valid on modules
 --> test_resources/companion/test12.yr:(7,2)
 7  ┃ @final
    ╋  ^^^^^
 8  ┃ mod X {
    ╋ ---
    ┗━━━━━━━
```

## How to fix it

Remove the attribute, or apply it to a declaration it accepts. The
declarations an attribute accepts are stated where the attribute itself is
declared.

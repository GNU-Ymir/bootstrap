# E3006

> the ctor built from the fields is already declared

Raised during **declaration**, from `DeclareErrorMessage::DEFAULT_CTOR_ALREADY_DECLARED` (`src/ymirc/semantic/declarator/errors.yr`).

## What it means

The constructor built from the fields of the type is declared explicitly while
the compiler also generates it. Both would have the same signature.

## Example

`test_resources/default_ctor/test11.yr`:

```ymir
// The request is a declaration of its own, so a class makes it once.
class Foo {
   pub let x: i32;

   pub self;
   prv self;
}

fn main () {
    let a = copy Foo (1);
    a.x;
}
```

```text
Error[E3006] : the ctor built from the fields is already declared
 --> test_resources/default_ctor/test11.yr:(6,8)
 6  ┃    prv self;
    ╋        ^^^^
    ┃ Note : declared here
    ┃  --> test_resources/default_ctor/test11.yr:(5,8)
    ┃  5  ┃    pub self;
    ┃     ╋        ^^^^
    ┃     ┗━━━━━━━
    ┗━━━━━┻━
```

## How to fix it

Remove the explicit constructor and rely on the generated one, or change its
parameters so the two no longer collide.

# E4260

> unreachable statement

Raised during **validation**, from `ValidateErrorMessage::UNREACHBLE_STATEMENT` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A statement follows one that never completes -- a `return`, a `break`, a
`throw` -- so it can never run.

## Example

`test_resources/lit_options/test16.yr`:

```ymir
fn main () {
    loop {
        let _a_ = ({
            break 12;
        })?;
    };
}
```

```text
Error[E4260] : unreachable statement
 --> test_resources/lit_options/test16.yr:(5,11)
 5  ┃         })?;
    ╋           ^
    ┃ Note : exiting scope here
    ┃  --> test_resources/lit_options/test16.yr:(4,13)
    ┃  4  ┃             break 12;
    ┃     ╋             ^^^^^
    ┃     ┗━━━━━━━
    ┗━━━━━┻━
```

## How to fix it

Remove the statement, or move it before the one that leaves the block.

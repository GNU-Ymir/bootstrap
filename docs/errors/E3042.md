# E3042

> custom attribute <> is not valid on entities

where `<>` stands for a value the diagnostic fills in.

Raised during **declaration**, from `DeclareErrorMessage::UNDEFINED_ATTRIBUTE_FOR_ENTITY` (`src/ymirc/semantic/declarator/errors.yr`).

## What it means

A custom attribute was applied to an entity. No attribute applies to an entity
itself, only to its constructors (`@no_move`, `@only_move`).

## Example

`test_resources/diagnostics/test159.yr`:

```ymir
// no attribute applies to an entity
@thread
entity A {
    pub self () {}
}

fn main () {
    let _ = A ();
}
```

```text
Error[E3042] : custom attribute thread is not valid on entities
 --> test_resources/diagnostics/test159.yr:(2,2)
 2  ┃ @thread
    ╋  ^^^^^^
 3  ┃ entity A {
    ╋ ------
    ┗━━━━━━━
```

## How to fix it

Remove the attribute, or move it onto the constructor of the entity when it is
one a constructor accepts.

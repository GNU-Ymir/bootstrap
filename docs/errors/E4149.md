# E4149

> class type <> does not inherit from exception type <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::NOT_AN_EXCEPTION_CLASS` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A class is thrown, or caught, that does not derive from the exception base
class.

## Example

`test_resources/diagnostics/test58.yr`:

```ymir
class A { pub self () {} }

fn foo () throws A;

fn main () { foo (); }
```

```text
Error[E4149] : class type test58::A does not inherit from exception type core::exception::Exception
 --> test_resources/diagnostics/test58.yr:(3,11)
 3  ┃ fn foo () throws A;
    ╋           ^^^^^^ ^
    ┗━━━━━━━
```

## How to fix it

Make the class inherit from the exception type reported in the message.

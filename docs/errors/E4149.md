# E4149

> class type <> does not inherit from exception type <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::NOT_AN_EXCEPTION_CLASS` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A class is thrown, or caught, that does not derive from the exception base
class.

## How to fix it

Make the class inherit from the exception type reported in the message.

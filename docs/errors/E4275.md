# E4275

> expression produces the type <>, but is used as a value

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::USE_AS_VALUE_TYPE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

An expression produces the reported type where a value is expected, cf.
[E4273](E4273.md).

## Example

`test_resources/diagnostics/test137.yr`:

```ymir
// a trait used as a value
trait Shape {}

fn main () {
    let _ = Shape;
}
```

```text
Error[E4275] : expression produces the type test137::Shape, but is used as a value
 --> test_resources/diagnostics/test137.yr:(5,13)
 5  ┃     let _ = Shape;
    ╋             ^^^^^
    ┃
    = when validating test137::main -- (test_resources/diagnostics/test137.yr:(4,4))
    ┗━━━━━━━
```

## How to fix it

Construct a value of the type.

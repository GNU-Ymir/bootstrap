# E4238

> undefined unary operator <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::UNDEFINED_UN_OP_TOK` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

The token used as a unary operator is not one the language defines.

## How to fix it

Use a defined operator.

# E4238

> undefined unary operator <>

**Retired.** The message this code named was deleted from the compiler: no
source could reach it. Every unary operator the parser produces is validated.

The code is not reused and not reassigned to another diagnostic, so an E4238
printed by an older compiler still means what is quoted above. This page stays
as its record.

It was raised during **validation**, from `ValidateErrorMessage::UNDEFINED_UN_OP_TOK`.

# E4345

> a generator cannot await, it is resumed by its consumer, never woken

Raised during **validation**, from `ValidateErrorMessage::AWAIT_IN_GENERATOR` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A function is either a generator or an async. A generator is resumed each
time its consumer asks for a value, it is given no waker to be woken by once
what it awaits is ready.

## Example

`test_resources/async/test28.yr`:

```ymir
// A function is either a generator or an async: a generator cannot await.

yield gen ()-> i32 {
    await;
    yield 1;
}
```

```text
Error[E4345] : a generator cannot await, it is resumed by its consumer, never woken
 --> test_resources/async/test28.yr:(4,5)
 4  ┃     await;
    ╋     ^^^^^
    ┃
    = when validating test28::gen -- (test_resources/async/test28.yr:(3,7))
    ┗━━━━━━━
```

## How to fix it

Make the function an async, or drive what the generator waits for to
completion with `run ()`.

# E4064

> field method <> cannot be overlapped by a method with the same name <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::FIELD_METHOD_COLLISION` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A field method and an ordinary method share a name, so a use of that name would
have two meanings.

## How to fix it

Rename one of them.

# E4064

> field method <> cannot be overlapped by a method with the same name <>

**Retired.** The message this code named was deleted from the compiler: no
code raised it any more. Nothing produces E4064 today.

The code is not reused and not reassigned to another diagnostic, so an E4064
printed by an older compiler still means what is quoted above. This page stays
as its record.

It was raised during **validation**, from `ValidateErrorMessage::FIELD_METHOD_COLLISION`.

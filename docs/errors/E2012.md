# E2012

> a named move ctor requires an argument list

Raised during **parsing**, from `SyntaxErrorMessage::MOVE_NAMED_CTOR_PARAMS` (`src/ymirc/syntax/errors.yr`).

## What it means

A `move` naming the ctor that resets the moved value was not followed by an
argument list. The parentheses are what separate the arguments of the ctor from
the value being moved, so they are mandatory as soon as a name is given -- even
when the ctor takes nothing.

## Example

`test_resources/diagnostics/test90.yr`:

```ymir
entity Foo {
    pub self open () {}
}

fn main () {
    let mut a = Foo::open ();
    let mut _b_ = move::open a;
}
```

```text
Error[E2012] : a named move ctor requires an argument list
 --> test_resources/diagnostics/test90.yr:(8,23)
 8  ┃     let mut _b_ = move::open a;
    ╋                       ^^----  note: failed to read standard variable declaration
    ┗━━━━━━━
```

## How to fix it

Write the empty argument list: `move::open () a`.

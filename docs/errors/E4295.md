# E4295

> a generator cannot throw exceptions

Raised during **validation**, from `ValidateErrorMessage::GENERATOR_THROWS` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

The body of a generator runs while its consumer iterates over it, where the
exceptions it declares could not be tracked. A generator method, declared by
`yield` in a class, a record or a trait, is rejected the same way.

## Example

`test_resources/generators/test11.yr`:

```ymir
// a generator declaring exceptions
class Err over Exception {
    pub self () {}
}

yield gen ()-> i32
    throws Err
{
    yield 1;
    throw copy Err ();
}
```

```text
Error[E4295] : a generator cannot throw exceptions
 --> test_resources/generators/test11.yr:(7,5)
 7  ┃     throws Err
    ╋     ^^^^^^
    ┃
    = when validating test11::gen -- (test_resources/generators/test11.yr:(6,7))
    ┗━━━━━━━
```

## How to fix it

Catch the exceptions inside the generator, outside of the region of any
`yield`, cf. [E4293](E4293.md).

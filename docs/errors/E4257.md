# E4257

> unknown length of expansion for type <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::UNKNOWN_LENGTH_OF_EXPANSION` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

An expansion was written over a type whose length the compiler cannot
determine.

## Example

`test_resources/lit_slices/test15.yr`:

```ymir
in test15;

fn foo (_ : [c8], _ : i32) {}
fn foo (_ : i32) {}
fn foo (_ : [c8]) {}

fn foo {T, U...} (a : T, b : U) {
    foo ("[", a);
    cte if ((U,)::arity > 1us) {
        for i in b {
            foo (", ", i);
        }
    } else {
        foo (", ", b);
    }
    foo ("]");
}

fn main () {
    let mut c = 20;
    let a = copy [0 ; c];
    foo (expand a [0 .. c]);
}
```

```text
Error[E4257] : unknown length of expansion for type mut [i32]
 --> test_resources/lit_slices/test15.yr:(22,10)
22  ┃     foo (expand a [0 .. c]);
    ╋          ^^^^^^
    ┗━━━━━━━
```

## How to fix it

Expand something whose arity is statically known -- a tuple, or a template
variadic parameter.

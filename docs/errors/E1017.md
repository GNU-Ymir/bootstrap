# E1017

> octal number is empty

Raised during **lexing**, from `LexingErrorMessage::EMPTY_OCT_NUMBER` (`src/ymirc/lexing/errors.yr`).

## What it means

A `0o` prefix is not followed by any octal digit, so the literal has no
value.

## Example

`test_resources/lexing/test22.yr`:

```ymir
let x = 0o_;
```

```text
Error[E1017] : octal number is empty
 --> main.yr:(1,9)
 1  ┃ let x = 0o_;
    ╋         ^^^
    ┗━━━━━━━
```

## How to fix it

Write the digits after the prefix, or remove the prefix if a plain `0` was
meant.

# E1022

> unterminated version block: missing #end

Raised during **lexing**, from `LexingErrorMessage::UNTERMINATED_VERSION_BLOCK` (`src/ymirc/lexing/errors.yr`).

## What it means

A `#if` conditional compilation block was opened and the file ended before the
matching `#end` was found.

## Example

`test_resources/lexing/test9.yr`:

```ymir
#if FOO
```

```text
Error[E1022] : unterminated version block: missing #end
 --> main.yr:(1,2)
 1  ┃ #if FOO
    ╋  ^^
    ┗━━━━━━━
```

## How to fix it

Close the block with `#end`. Every `#if` needs one, including the ones whose
`#else` branch is empty.

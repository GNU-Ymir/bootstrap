# E4168

> no constructor found for class <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::NO_CTOR_FOUND` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A class was constructed and it declares no constructor callable that way.

## Example

`test_resources/default_ctor/test8.yr`:

```ymir
// The generated ctor carries the protection of the `self;` asking for it.
class Foo {
   pub let x: i32;
   prv self;

   pub fn get (self)-> i32 { self.x }
}

fn main () {
    let a = copy Foo (1);
    a.get ();
}
```

## How to fix it

Declare a constructor matching the arguments given, or call one that exists;
the candidates are listed under the diagnostic.

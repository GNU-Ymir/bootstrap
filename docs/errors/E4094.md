# E4094

> impl statement must be followed by a trait, not <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::IMPL_NO_TRAIT` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

An `impl` statement names something that is not a trait.

## How to fix it

Name a trait. To add methods to a type without a trait, declare them in the
type body.

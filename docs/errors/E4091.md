# E4091

> implicit override of method <> by trait impl

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::IMPLICIT_OVERRIDE_BY_TRAIT` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A trait `impl` provides a method that overrides an ancestor method, without the
override being declared.

## How to fix it

Mark the method `override` in the `impl`, or rename it.

# E4131

> mismatch tuple arity <> and <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::MISMATCH_TUPLE_ARITY` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

Two tuples meet where they have to agree and do not hold the same number of
elements. Both arities are in the message.

## Example

`test_resources/lit_tuples/test21.yr`:

```ymir
fn foo ()-> (i32, i32);

fn main () {
    let mut a = 0, mut b = 0, mut c = 0;

    (a, b, c) = foo ();
}
```

```text
Error[E4131] : mismatch tuple arity 3 and 2
 --> test_resources/lit_tuples/test21.yr:(6,5)
 6  ┃     (a, b, c) = foo ();
    ╋     ^               ^
    ┗━━━━━━━
```

## How to fix it

Make the two tuples the same length. A destructuring that binds fewer names
than the tuple has also produces this.

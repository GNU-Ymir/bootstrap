# E4317

> union <> does not implement trait <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::UNION_NOT_IMPL` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A union is used where the trait named is required, and the union does not
implement it.

A union implements a trait when every one of its members implements it, so that
the methods of the trait can be dispatched to whichever member the union holds.
A union declaring a base with `over` is dispatched through the vtable of that
base, so it implements only the traits the base implements, even when every
member implements more. The notes name the members, or the base, that do not
implement the trait.

## Example

`test_resources/type_union/test69.yr`:

```ymir
// A union having a member that does not implement a trait does not implement it.

use std::stream;

record A {
    impl Streamable;
}

record C {}

union Y
| A
| C;

fn foo {T impl Streamable} (_ : T) {}

fn bar (y : Y) {
    foo (y);
}
```

## How to fix it

Implement the trait in every member of the union -- or, for a union declaring a
base, in the base itself.

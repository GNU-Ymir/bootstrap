# E4008

> cannot break loop inside a scope guard

Raised during **validation**, from `ValidateErrorMessage::BREAK_SCOPE_GUARD` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A `break` inside a scope guard would leave the loop while the guard is running.
A guard runs as part of leaving the scope it guards, so jumping out of it would
abandon a scope exit half-way through.

## Example

`test_resources/diagnostics/test19.yr`:

```ymir
fn main () {
    loop {
        {
        } exit {
            break;
        }
    }
}
```

```text
Error[E4008] : cannot break loop inside a scope guard
 --> test_resources/diagnostics/test19.yr:(4,11)
 4  ┃         } exit {
    ╋           ^^^^
   ...
 --> test_resources/diagnostics/test19.yr:(5,13)
 5  ┃             break;
    ╋             ^^^^^
    ┗━━━━━━━
```

## How to fix it

Move the `break` out of the guard body. A guard that has to influence the
loop should set a flag the loop tests instead.

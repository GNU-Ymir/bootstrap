# E4118

> malformed int literal <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::MALFORMED_INT_LITERAL` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

An integer literal cannot be represented: it is malformed, or outside what its
type can hold.

## How to fix it

Correct the literal, or use a wider integer type. A suffix on the literal
selects its type explicitly.

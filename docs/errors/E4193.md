# E4193

> the pattern <> with value <> is refutable

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::PATTERN_IS_REFUTABLE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A pattern is used where every value has to match -- a destructuring binding,
for instance -- and this one can fail.

## Example

`test_resources/control_flow/test8.yr`:

```ymir
fn foo ()-> i32?;

fn main () {
    let Ok (x : i32) = foo (); // error, refutable since it may fail if /foo/ returns /none/
}
```

```text
Error[E4193] : the pattern Ok(x: i32) with value test8::foo () is refutable
 --> test_resources/control_flow/test8.yr:(4,5)
 4  ┃     let Ok (x : i32) = foo (); // error, refutable since it may fail if /foo/ returns /none/
    ╋     ^^^
    ┗━━━━━━━
```

## How to fix it

Use a pattern that always matches, or move the destructuring into a `match`
with a default case.

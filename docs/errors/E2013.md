# E2013

> missing the value moved by the operator

Raised during **parsing**, from `SyntaxErrorMessage::MOVE_MISSING_OPERAND` (`src/ymirc/syntax/errors.yr`).

## What it means

A `(` directly following `move` always opens the argument list of the reset
ctor, so what looks like the moved value is read as an argument and the operator
is left without an operand.

## Example

`test_resources/diagnostics/test89.yr`:

```ymir
entity Foo {
    pub self () {}
}

fn foo ()-> Foo;

fn main () {
    let mut _a_ = move (foo ());
}
```

```text
Error[E2013] : missing the value moved by the operator
 --> test_resources/diagnostics/test89.yr:(9,19)
 9  ┃     let mut _a_ = move (foo ());
    ╋                   ^^^^ -       -
    ┃                      ┗━ note: failed to read standard variable declaration
    ┃                        ┗━ note: the argument list of move was read instead, write move () (...) to move a parenthesized value
    ┃                                ┗━ error: unexpected ;
    ┗━━━━━━━
```

## How to fix it

Drop the parentheses around the moved value, or -- when they are needed to
enclose a complex expression -- put an explicit argument list in front of them:
`move () (foo ())`.

# E4350

> method <> must be an async to override the async <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::OVERRIDE_ASYNC_NO_ASYNC` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

An ordinary method tries to override an async, declared by `async`. Being an
async is part of the contract of a method, even when the overriding method
returns the same handle type, cf. [E4351](E4351.md).

## Example

`test_resources/async/test56.yr`:

```ymir
// A method overriding an async must be an async.

async answer ()-> i32 {
    1
}

class A {
    pub self () {}

    pub async f (self)-> i32 {
        1
    }
}

class B over A {
    pub self () {}

    pub over f (self)-> (async-> i32) {
        answer ()
    }
}

fn main () {
    let _ = B ();
}
```

```text
Error[E4350] : method test56::B::f ()-> (async-> i32) must be an async to override the async test56::A::f ()-> (async-> i32)
 --> test_resources/async/test56.yr:(18,14)
18  ┃     pub over f (self)-> (async-> i32) {
    ╋              ^
 --> test_resources/async/test56.yr:(10,15)
10  ┃     pub async f (self)-> i32 {
    ╋               -
    ┃
    = when validating test56::B -- (test_resources/async/test56.yr:(15,7))
    ┗━━━━━━━
```

## How to fix it

Declare the overriding method with `over async`, and return the value it completes with.

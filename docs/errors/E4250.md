# E4250

> copy the lambda closure has no effect, no values are enclosed

Raised during **validation**, from `ValidateErrorMessage::UNECESSARY_LMBD_COPY` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

`copy` was applied to a lambda that captures nothing, so there is no
environment to duplicate.

## Example

`test_resources/diagnostics/test79.yr`:

```ymir
fn main () {
    let f = copy (|| => { 1 });
    f ();
}
```

```text
Error[E4250] : copy the lambda closure has no effect, no values are enclosed
 --> test_resources/diagnostics/test79.yr:(2,13)
 2  ┃     let f = copy (|| => { 1 });
    ╋             ^^^^
    ┗━━━━━━━
```

## How to fix it

Drop the `copy`.

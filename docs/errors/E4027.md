# E4027

> method <> is defined as constant

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::CONST_METHOD` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A method declared constant is used where a mutable one is needed -- typically
to write through the instance it is called on.

## Example

`test_resources/lit_class/operators/test15.yr`:

```ymir
class A {

    pub self () {}

    pub fn opIndex (self, _ : i32) {}

}

fn main () {
    let dmut a = copy A ();
    let _ = a:[0];
    let _ = a:.opIndex (0);
}
```

```text
Error[E4027] : method test15::A::opIndex (_: i32)-> void is defined as constant
 --> test_resources/lit_class/operators/test15.yr:(5,12)
 5  ┃     pub fn opIndex (self, _ : i32) {}
    ╋            ^^^^^^^
    ┃ Note : aliasing the value of type mut &(mut test15::A) to create a constant borrowing is prohibited
    ┃  --> test_resources/lit_class/operators/test15.yr:(11,14)
    ┃ 11  ┃     let _ = a:[0];
    ┃     ╋              ^^
    ┃     ┗━━━━━━━
    ┗━━━━━┻━
```

## How to fix it

Make the method mutable (`self` declared `mut`), or call a mutable method
instead.

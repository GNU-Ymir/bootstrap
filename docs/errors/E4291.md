# E4291

> yield statement is not within a generator

Raised during **validation**, from `ValidateErrorMessage::YIELD_NO_GENERATOR` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A `yield` appears in a function that is not a generator. Only a function
introduced by `yield` can yield values; a lambda nested in a generator is a
function of its own, and cannot yield on behalf of the generator either.

## Example

`test_resources/generators/test6.yr`:

```ymir
// yield outside a generator
fn notGenerator ()-> i32 {
    yield 1;
    2
}
```

```text
Error[E4291] : yield statement is not within a generator
 --> test_resources/generators/test6.yr:(3,5)
 3  ┃     yield 1;
    ╋     ^^^^^
    ┃
    = when validating test6::notGenerator -- (test_resources/generators/test6.yr:(2,4))
    ┗━━━━━━━
```

## How to fix it

Introduce the function with `yield` instead of `fn`, its declared return type
being the type of the yielded values.

# E4240

> decorator <> is not applicable in that context

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::UNDEF_DECORATOR_HERE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A decorator is valid in general but not where it was written.

## Example

`test_resources/pattern_match/test19.yr`:

```ymir
fn main () {
    let (lazy x,) = (1,);
    x;
}
```

```text

 --> test_resources/pattern_match/test19.yr:(2,10)
 2  ┃     let (lazy x,) = (1,);
    ╋          ^^^^
    ┃ Note : for pattern field access 0 on type (mut i32,)
    ┃  --> test_resources/pattern_match/test19.yr:(2,9)
    ┃  2  ┃     let (lazy x,) = (1,);
    ┃     ╋         ^
    ┃     ┗━━━━━━━
    ┗━━━━━┻━
```

## How to fix it

Move it onto something that accepts it.

# E4255

> constructor of the union type <> initializes no field

**Retired.** The message this code named was deleted from the compiler: no
code raised it any more. Nothing produces E4255 today.

The code is not reused and not reassigned to another diagnostic, so an E4255
printed by an older compiler still means what is quoted above. This page stays
as its record.

It was raised during **validation**, from `ValidateErrorMessage::UNION_CTOR_NO_FIELD`.

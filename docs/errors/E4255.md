# E4255

> constructor of the union type <> initializes no field

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::UNION_CTOR_NO_FIELD` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A union constructor initializes no field, so the value it builds holds
nothing.

## How to fix it

Initialize exactly one field.

# E4113

> main function takes at most one argument

Raised during **validation**, from `ValidateErrorMessage::MAIN_FUNCTION_ONE_ARG` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

The `main` function declares more than one parameter. It takes either nothing
or the command line arguments.

## How to fix it

Reduce it to at most one parameter.

# E4113

> main function takes at most one argument

Raised during **validation**, from `ValidateErrorMessage::MAIN_FUNCTION_ONE_ARG` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

The `main` function declares more than one parameter. It takes either nothing
or the command line arguments.

## Example

`test_resources/diagnostics/test141.yr`:

```ymir
// a main function taking a second parameter
fn main (args : [[c8]], count : i32) {
    let _ = (args, count);
}
```

```text
Error[E4113] : main function takes at most one argument
 --> test_resources/diagnostics/test141.yr:(2,25)
 2  ┃ fn main (args : [[c8]], count : i32) {
    ╋                         ^^^^^
    ┃
    = when validating test141::main -- (test_resources/diagnostics/test141.yr:(2,4))
    ┗━━━━━━━
```

## How to fix it

Reduce it to at most one parameter.

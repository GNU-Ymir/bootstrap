# E4141

> method <> is defined as mutable

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::MUTABLE_METHOD` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A mutable method is called on a value that is not mutable.

## Example

`test_resources/diagnostics/test55.yr`:

```ymir
class Foo {
    let mut x: i32 = 0;
    pub self () {}
    pub fn bar (mut self) { self.x = 1; }
}

fn main () {
    let f = copy Foo ();
    f.bar ();
}
```

```text
Error[E4141] : method test55::Foo::bar ()-> void is defined as mutable
 --> test_resources/diagnostics/test55.yr:(4,12)
 4  ┃     pub fn bar (mut self) { self.x = 1; }
    ╋            ^^^
    ┃ Note : implicit alias of type &(test55::Foo) is prohibited, it implicitly gives up on borrowings of mutable values
    ┃  --> test_resources/diagnostics/test55.yr:(9,5)
    ┃  9  ┃     f.bar ();
    ┃     ╋     ^
    ┃     ┗━━━━━━━
    ┗━━━━━┻━
```

## How to fix it

Make the value mutable, or call a constant method instead, cf.
[E4082](E4082.md).

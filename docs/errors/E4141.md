# E4141

> method <> is defined as mutable

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::MUTABLE_METHOD` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A mutable method is called on a value that is not mutable.

## How to fix it

Make the value mutable, or call a constant method instead, cf.
[E4082](E4082.md).

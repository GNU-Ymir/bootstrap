# E4086

> ref of type <> must be const, but is mutable

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::IMPLICIT_CONST_REFERENCE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A `ref` parameter is declared constant and a mutable value was passed. Passing
a mutable value as a constant reference would silently freeze it for the
duration of the call.

## How to fix it

Declare the parameter mutable, or pass a constant value.

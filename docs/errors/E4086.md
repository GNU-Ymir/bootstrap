# E4086

> ref of type <> must be const, but is mutable

**Retired.** The message is still raised, but only as a note under
[E4226](E4226.md), which documents it, and it no longer carries a code of its own.

The code is not reused and not reassigned to another diagnostic, so an E4086
printed by an older compiler still means what is quoted above. This page stays
as its record.

It was raised during **validation**, from `ValidateErrorMessage::IMPLICIT_CONST_REFERENCE`.

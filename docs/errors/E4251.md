# E4251

> the move has no effect

Raised during **validation**, from `ValidateErrorMessage::UNECESSARY_MOVE` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

`move` was applied where the source is not used afterwards anyway, so the move
changes nothing.

## Example

`test_resources/regressions/move_unnecessary_ctor_call/test1.yr`:

```ymir
entity A {
    pub self () {}

    __dtor (mut self) {}
}

fn foo ()-> A {
    move A ()
}

fn main () {
    let _ = foo ();
}
```

```text
Error[E4251] : the move has no effect
 --> test_resources/regressions/move_unnecessary_ctor_call/test1.yr:(8,5)
 8  ┃     move A ()
    ╋     ^^^^   ^
    ┗━━━━━━━
```

## How to fix it

Drop the `move`.

# E4237

> undefined operator <> for type <>

where `<>` stands for a value the diagnostic fills in.

Raised during **validation**, from `ValidateErrorMessage::UNDEFINED_UN_OP` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

A unary operator is not defined for the operand type.

## Example

`test_resources/char_type/test4.yr`:

```ymir
in test4;


fn main () {
    let a = 'r'c8;
    let b = 'r'c16;
    let c = 'r'c32;


    *a;
    !a;
    -a;
    &a;

    *b;
    !b;
    -b;
    &b;

    *c;
    !c;
    -c;
    &c;
}
```

```text
Error[E4237] : undefined operator * for type c8
 --> test_resources/char_type/test4.yr:(10,5)
10  ┃     *a;
    ╋     ^
    ┗━━━━━━━
```

## How to fix it

Define the operator on the type, or convert the operand.

# E4045

> discarding the constant property is prohibited

Raised during **validation**, from `ValidateErrorMessage::DISCARD_CONST` (`src/ymirc/semantic/validator/errors.yr`).

## What it means

An operation would drop the constant property of a value -- turning something
borrowed as constant into something writable.

## Example

`test_resources/lit_tuples/test13.yr`:

```ymir
fn main () {
    let dmut a = (copy [1, 2],);
    let dmut _ = a.0;
}
```

```text
Error[E4045] : discarding the constant property is prohibited
 --> test_resources/lit_tuples/test13.yr:(3,14)
 3  ┃     let dmut _ = a.0;
    ╋              ^
    ┃ Note : implicit alias of type mut [mut i32] is prohibited, it implicitly gives up on borrowings of mutable values
    ┃  --> test_resources/lit_tuples/test13.yr:(3,19)
    ┃  3  ┃     let dmut _ = a.0;
    ┃     ╋                   ^
    ┃     ┗━━━━━━━
    ┗━━━━━┻━
```

## How to fix it

Take a copy if the value has to be modified, or keep the operation constant.
The mutability of a borrowed value is part of its type and cannot be cast
away.
